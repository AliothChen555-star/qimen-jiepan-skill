# 起盘入口、来源识别与解盘流程改进

## 范围

同时改善流程与解盘质量、安装与版本识别。本次修改技能指令、参考资料、安装说明和合成评估用例，不改变排盘算法或规则版本。

## 设计

- 保持名称 `qimen-jiepan`，增加指令版本与上游来源元数据；区别声明来源、已验证 Git 来源和不可追溯的历史安装来源。
- 明确输入分流：已有盘面直接用，当前或指定时间调用内置入口，纯理论不排盘；允许对非关键缺失信息声明假设。
- 使用成功结果或已选定时刻固定同一问事，保留 JSON；时区、默认经纬度和真太阳时不混淆。
- 在解读前声明日干、年命与事项用神的角色，扩展风评类参考，要求相关正反证据，避免将象义说成现实事实。
- 安装保留私有环境；网络故障走宿主权限流程。仅更新选定技能，不自动删除相似技能。

## 方案取舍

只补入口说明改动最小，但覆盖不了版本混淆与空泛判断；本次选择贯通上述说明和评估。暂不增加自动更新器、其他排盘引擎或新格局算法，以免扩大验证范围。

## 验证与交付

检查 Skill 文件结构、引用和元数据；用现有程序复现固定时间并检查当前时间路径。用三个合成对话场景比较修改前后：当前时间与年命、指定时间仅排盘、指定仓库与旧技能冲突。模型评估只说明指令遵循，不验证术数预测的有效性。

评估记录、用户盘面及私有环境保留在仓库外或被忽略目录。提交可复用用例与改动说明，检查差异后常规提交并推送，不强推。
