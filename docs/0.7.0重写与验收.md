# 0.7.0 重写与验收

完成日期：2026年10月20日。按已确认方案保留排盘骨架，重写解盘协议、规则资料、分类方法与评估记录，并修复输入、时间和原盘保存的实际问题。版本不声明真实预测准确率已提高。

## 主要改变

| 模块 | 本次实现 |
|---|---|
| 流程 | 先定题及分项结果、校盘定法、固定角色，再全盘扫描、核心宫、关系、完整条件及反证、分项结论、取象与应期；不强迫全盘第一步定顺逆 |
| 取用 | 分类角色、天／地层次、主寄与实际落点明确；年命不设万能优先级，不因吉凶换符号 |
| 资料 | 单一JSON维护69卡、22有向干对选录、11来源、5方法入口；核读状态与事件适用状态分开 |
| 方法 | 合伙助益、贸易资本收益、开店经营分开；访人法有限支持；工作压力是明示现代有限入口，不编持续天数 |
| 条件 | 几何、原义、有利使用、事件适用、主客例外分目的三态；未知不当真，异源例外须显式选择 |
| 综合 | 每个结果有对象、阶段、期限、正反依据和未判范围；不计吉凶票、不造星门权重或通关链 |
| 取象 | 传统义、现代类比、待核事实分开；不凭象断现实行为，不由行业像推出成败 |
| 应期 | 一般状态、问题期限、精确日期分开；日历匹配不自动配事件阶段 |
| 金融 | 传统解释、现实核验、实验预测分开；传统不利不自动等于市场下跌 |
| 记录 | 初始化与校验原盘哈希、角色主寄、引用、关键未知、反证处置、期限与结果一致；校验不代判事实真伪 |

规则入口见[SKILL](../qimen-jiepan-skill/SKILL.md)、[规则卡](../qimen-jiepan-skill/references/规则卡.md)、[事类方法](../qimen-jiepan-skill/references/事类方法.md)。

## 程序修复

1. 完整盘输入校验从数量检查扩展到一次整体星干耦合、门神布列、符使原宫与寄宫、冻结时间、四柱、节气及元局的一致性。
2. 当前／指定时间显式二选一；日常入口不再创建环境或安装依赖；记录实际版本与UTC原盘时刻。
3. 日期候选处理缺失午夜、非整小时历史偏移、重复钟面和有效窗口终点；独立搜索起点不改原盘，日历日与24小时区分。
4. 独立复核发现并修复派生输出覆盖原盘的入口，包括同路径及硬链接别名。
5. 规则库接口拒绝非法geometry类型，防止几何unknown却解释资格true。
