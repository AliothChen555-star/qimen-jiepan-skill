# 奇门遁甲解盘攻略

本攻略面向本项目的“拆补法时家转盘奇门”。以下是常用读盘框架，不是排盘算法；遇到不同教材，应先确认起局规则是否相同。

## 一、先定规则，再读吉凶

每次解盘先记录：

1. 公历时间、时区、地点，以及标准时间或真太阳时。
2. 换日法：午夜换日或子初换日。
3. 阴遁/阳遁、上/中/下元、局数。
4. 旬首、旬空、值符、值使、马星。
5. 中宫寄宫、天禽归属、值使计数法。

规则不同会直接改变盘面。不要把置闰、拆补、飞盘、转盘的结果混在一起。

## 二、五分钟读盘流程

### 1. 把问题改成可判断的句子

限定对象、结果和时间，例如“我方在三十天内能否签约”“这次面试能否录用”。问题越具体，用神越稳定。

### 2. 选用神（常用取法）

先取问题核心，再取辅助用神：

| 问题 | 常用用神 |
|---|---|
| 求财、项目收益 | 生门；日干为求测者，时干或对方宫为事项 |
| 工作、职位、考试 | 开门；天辅、景门可作学习与文书辅助 |
| 疾病 | 天芮、死门为病象；日干为本人；九天/九地等作状态辅助 |
| 婚恋 | 乙奇常作女性，庚常作男性或阻力；六合、休门看关系过程 |
| 诉讼、竞争 | 日干我方，时干/对宫为对手或结果；惊门、白虎、伤门看冲突 |
| 出行、搬迁 | 开门、马星、九天；所往方向取对应宫 |
| 找人、寻物 | 六仪落宫、用神落宫及值使门，结合空亡、马星判断动静 |

程序首版不自动选用神。起盘前应先写明“为什么取它”；若有两个候选，预先写出选择判据，不要看完结果后再挑选。

### 3. 定我方与对方

日干落宫通常代表求测者或我方；时干代表所问之事、结果或对方，具体含义随问题调整。竞争类问题可把对宫、庚、值使门作为对手或阻力辅助，不宜只看一个符号。

### 4. 看宫位强弱

依次看：

- 宫的五行与季节（月令）关系：得令、相、生扶为有力；休囚、受克为弱。
- 门的状态：门生宫、宫生门、门克宫、宫克门；门迫、伏吟、反吟需按门派规则另行核验。
- 星、神、天干是否支持用神；同宫信息优先于远宫信息。
- 空亡、入墓、击刑、门迫、刑冲合害等减分或改变态势。

强弱只说明“能不能、顺不顺、快不快”，不能单独等同吉凶。门迫、击刑、入墓等属于常用经验层，当前程序未自动计算这些标记。

### 5. 读“门、星、神、干”四层

**八门（常用取法）：** 休门主休息、沟通、恢复；生门主生长、财利、机会；伤门主行动、竞争、损伤；杜门主阻隔、技术、隐蔽；景门主名声、文书、表现；死门主终止、压力、静止；惊门主突发、口舌、消息；开门主开放、工作、交易、出行。

**九星（常用取法）：** 天辅偏学习、策划；天心偏判断、医疗、制度；天任偏承担、稳定；天冲偏行动、突破；天英偏表达、名声；天蓬偏风险、欲望、隐情；天芮偏疾病、问题、细节；天柱偏阻力、口舌、损耗；天禽主中介、调和、承载。常用框架把星看作性质，把门看作事件表现，但各门派优先级并不完全相同。

**八神（常用取法）：** 值符主主导与贵人；腾蛇主疑虑、变化、虚象；太阴主隐私、谋划、女性助力；六合主合作、关系、撮合；白虎主刚烈、伤灾、压力；玄武主隐情、欺瞒、流动财；九地主管理、积累、低调；九天主远行、上升、快速扩张。常用框架把神看作环境和方式，不宜脱离门星单独下结论。

**天干：** 先看日干、时干和用神所在宫，再看生克、合冲、入墓、击刑。乙丙丁为三奇，通常增加机会、表达、行动或解决能力，但仍须看落宫和门星；庚常代表阻力、竞争、规则压力，辛常代表错误、损伤、细节问题，壬癸常与流动、隐蔽、信息有关，戊己常与资源、土地、手续、承载有关。

### 6. 判断成败与过程

用“我方宫”和“事项/对方宫”比较：

- 我生对方：我方付出多，结果尚可但费力。
- 我克对方：我方有控制力，但也可能造成冲突。
- 对方生我：得到帮助或资源。
- 对方克我：受制、压力大。
- 同我比和：势均力敌，重视门星是否得令。

再看值使门代表的事件通道是否通畅，值符代表的主导力量是否支持。多个指标一致才下结论；互相矛盾时，优先检查用神和时间规则。

## 三、特殊标记的实际用法

- **旬空/空亡：** 事情暂不落实、信息不实、力量落空或需要等待填实。空亡不等于必凶；冲空、填实、出空只能作为作用于用神、门或值使时的应期线索。
- **马星：** 主移动、变更、远方、速度和不稳定。本项目默认按时支取马星，也支持按日支；查看结果中的 `basis`，两种依据不可混读。马星临用神，多见主动变化；临阻力，常见奔波而未定。
- **值符：** 看谁掌握主动、资源和贵人；值符落用神通常增加主导性。
- **值使：** 看事情如何发生、通过什么渠道发生；值使门受克或空亡，过程容易卡住。
- **中宫：** 本项目中宫地盘干寄坤二；中宫仅显示天盘天干，九星、八门、八神留空；天禽随天芮显示。不要把中宫空白误判为缺项。
- **伏吟/反吟：** 判定依赖转盘、飞盘及具体门派规则，不能仅凭视觉上“重复”或“反向”判断；当前程序未自动标记。

## 四、应期怎么取

应期只给时间窗口，不应伪装成精确日期。常用取法：

1. 先看用神/值使所在宫、门星五行及对应地支（若采用该应期表）。
2. 看用神宫被冲、被合、填空、出墓的时间。
3. 看马星、九天、九地等显示快慢。
4. 以日、时、旬、月为不同精度，先给近端窗口，再给较远窗口。

例如用神空亡且受生，可倾向判断“有机会但尚未落实”；用神逢冲且值使得令，可把窗口收窄到较近的日或时。至少两个独立指标一致后再收窄应期；这仍只是倾向，不是必然应验。不同门派的应期表不能混用。

## 五、实用结论模板

```text
问题：
时间与规则：
我方用神及落宫：
事项/对方用神及落宫：
门：当前表现与渠道；星：性质与潜力；神：环境与方式；干：具体关系。
旺衰：得令/受生/受克/空亡/入墓/冲合。
过程：值使门与马星说明速度、渠道和变化。
结论：倾向成/不成/有条件；主要依据至少两项。
应期：给出时间窗口及触发条件。
风险与建议：只写能从盘面验证的行动建议。
```

## 六、常见错误

1. 只看一个吉门就断大吉，不看用神旺衰和生克。
2. 把日干固定解释成所有问题的“自己”，忽略求测者与事项的语境。
3. 把空亡直接当作坏事，把马星直接当作吉事。
4. 同一盘混用不同门派的局数、值使、寄宫和应期口诀。
5. 先有结论再挑符号，忽视相反证据。
6. 把预测倾向说成确定事实；涉及医疗、法律、投资，应以专业意见和现实证据为准。

## 七、资料与使用边界

本攻略依据传统奇门常用术语与结构，并参考项目保存的公开实现资料：`docs/reference-config.txt`（kentang2017/kinqimen 的节气局数、符头三元、值符值使、旬空实现）、`docs/reference-kinqimen.txt`（同项目的时家盘结构与马星字段）、`docs/reference-qimen.txt`（redrockhorse/qimenpaipan 的马星与宫位处理）。这些公开代码只作交叉资料，不能替代古籍版本、师承口径和人工案例校验。

本项目当前规则版本为 `chai_bu_v1.0.0`。正式使用前，应先用已知案例逐宫核对起局、寄宫、值使计数、空亡和马星；规则未核验时，只把结果作为传统术数学习和结构化分析工具。
