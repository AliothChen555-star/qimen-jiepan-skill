**奇门遁甲解盘速查表**

日期：2026年10月18日。配套《奇门遁甲解盘流程_文献核查版_2026-10-18.md》。适用重点为时家转盘人事问占；不同排法、古法不可无说明混用。

本表是整理者的操作建议，不是古籍原有的统一流程，也不代表已经验证其预测准确率最高。整理时未读取本机奇门遁甲 skill。

**一条主线**

定题 → 校盘 → 固定取用 → 全盘扫描 → 宫内状态 → 宫间关系 → 依题取象 → 条件与应期 → 反证 → 留档。

**全盘六查**

1. 值符星、八神值符、值使门分别是谁、落哪里。
2. 星与门分别有无反吟、伏吟。
3. 时令、力量、喜忌是否分开。
4. 关键用神是否见空、墓、刑、迫、马。
5. 时日关系特殊条目采用何种口径。
6. 相关用神落内或外，近远解释是否符合现实。

**一个宫怎么读**

角色是什么 → 是否有力及能落实 → 宫环境 → 门的行动渠道 → 星的性质条件 → 天地盘干组合 → 神的表现方式 → 刑空墓迫限制。

**宫间关系怎么读**

在宫五行层比较：事生人可提出帮助假说，人生事可提出投入假说，人克事可提出控制或取得假说，事克人可提出压力假说，比和可提出匹配假说。每项再看强弱及题意。

对宫轴另记一九、二八、三七、四六；天干五合另记甲己、乙庚、丙辛、丁壬、戊癸。干合不等于宫合，对位不等于五行相克，八神六合也不能与干合混为一层。

**取象三道限制**

- 先从题目限定领域，再从相关用神限定范围。
- 组合成少量能核实的解释，不把所有象义都往现实上套。
- 同一个五行关系的多个名称只算一条信息；神象不单独证明事实。

**结论五项**

当前状态／目标可成性／投入与代价／关键条件／应期与不确定处。

先确定时间尺度，再选有明示依据的应期规则；分清消息、启动、到账和最终完成。依据不足就只说快慢，不猜精确日期。

**交付前六问**

1. 是否提前写清问题、期限、成功标准？
2. 是否中途更换取用或排盘规则？
3. 是否把宫的旺衰、星的旺相、干的长生混为一谈？
4. 是否把本宫的凶象转嫁给无关对象，或去对宫寻找合意答案？
5. 是否保留反证和不能判断的内容？
6. 是否保留事前判断，等待事实反馈，而非事后改词？
