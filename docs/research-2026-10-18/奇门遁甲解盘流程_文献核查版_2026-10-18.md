**奇门遁甲解盘流程：文献核查与规范化实操稿**

整理日期：2026年10月18日。适用重点：时家转盘奇门的人事问占；另列择时择方分支。

本稿遵守用户要求，没有读取本机奇门遁甲 skill，也没有调用其程序或参考文件。术数材料来自本次外部检索。文末列出原文入口、馆藏书目及本次阅读范围。

先说明“最佳”的含义：本次核查没有找到足以证明某一流派、某一流程预测准确率最高的比较研究。这里推荐的是一套**取用稳定、体系一致、出处可查、结论可复盘**的工作流程。下文的术数解释属于传统占法内部的解释，不等于经验证实的因果规律。

标记约定：**【古籍】**为可核对的原文规则；**【现代归纳】**为后世常用的解释语言或应用引申；**【流程建议】**为本稿提出的操作规范。三者不能互相冒充。

**一、推荐的完整流程**

**定题与分流 → 校时校盘 → 固定取用 → 全盘扫描 → 用神宫内分析 → 宫间关系 → 依题取象 → 成败条件与应期 → 反证复核 → 留档反馈。**

这个顺序分两遍读盘。第一遍只扫描全局，知道动静、时令和主要角色位置；第二遍集中分析与题目有关的宫。全盘都要检查，但不必把每个宫都解释成求测者生活中的一件事。

| 步骤 | 要做的工作 | 必须留下的输出 |
|---|---|---|
| 1 定题 | 明确谁、做什么、对谁、何期限、何为成功 | 一句话问题及判断期限 |
| 2 校盘 | 固定时间、地点、节气、定局及寄宫等规则 | 可重复排出的同一张盘 |
| 3 取用 | 确定人、事、关系、必要辅证 | 角色与符号对应表 |
| 4 全盘 | 扫描符使、反伏吟、时令、空马、内外等 | 一段整体背景描述 |
| 5 宫内 | 看用神状态、门星神干及关键限制 | 各角色的能力、处境、行动方式 |
| 6 宫间 | 看双方及目标宫之间的生克、冲合、同宫 | 谁支持谁、谁耗费、阻在哪里 |
| 7 取象 | 将相关符号组合成符合题目的解释 | 少量可核实的具体假说 |
| 8 结果与应期 | 分开可成性、代价、条件、快慢和时间窗口 | 有条件的结论 |
| 9 复核 | 检查反证、重复计数、临时换法、取象过度 | 不确定点及不能推出的内容 |
| 10 留档 | 保留事前判断与事后事实 | 能核对成败的记录 |

此表是【流程建议】，并非声称古籍中存在完全相同的“十步秘诀”。

**二、先固定适用体系**

【流程建议】常规人事问占可选“时家转盘＋一种固定定局法”作为长期主线。若从零建立记录，拆补法便于统一操作；已长期采用置闰、茅山或飞盘体系的，应保持原体系，并记录其具体规则。没有依据把“排法简便”说成“预测更准”。

《神奇之门》公开目录明确区分定局、起局、符号含义、判断依据、取用、根本思路及应期，适合作为现代教学结构的参照；这并不代表本稿已读完其正文。[公开目录](https://www.sanmin.com.tw/product/index/002582691)

不同任务应分流：

| 问题 | 分析主线 | 不能直接套用的做法 |
|---|---|---|
| 已有明确事件，问现状、成败、关系 | 人物及分类用神、相关宫之间的联系 | 只因某方有吉门就断事件必成 |
| 选择行动时间或实际方位 | 在可行候选中比较时、方、主客和用事条件 | 把问占时的“吉方”当作所有行动都有效的方位 |
| 依某篇古籍作专门占法 | 按该篇完整的主客、三甲、干支、纳音等规则 | 只抽出一句口诀与另一套体系拼接 |
| 研究命局或长期人生 | 使用明确的命局体系并说明起点 | 把一次事件时盘直接解释为终身命运 |

《奇门遁甲秘笈大全·论主客》列出先动与后动、动与静、天盘与地盘等多种主客定义；《遁甲演义》卷三又有天盘星与地盘星的比较。由此可见，主客必须按具体用法确定，不能固定成“我永远为主、别人永远为客”。[论主客](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g2iu1fhne)、[遁甲演义卷三](https://zh.wikisource.org/wiki/遁甲演義_(四庫全書本)/卷3)

还要区分“阴遁”和某些现代流派所说的“阴盘”。前者是传统阴阳二遁中的一半，二者名称相近，不能据此视为同一种排盘法。

**三、定题与校盘：先保证研究的是同一件事**

问题建议写成：“某人，在某期限内，通过某行动，能否达成某可核实结果？”例如“本月能否收到正式录用通知”，比“我的事业怎么样”更能确定用神和应期。

同一个合作项目至少有四个不同问题：对方是否愿合作、合同能否签、资金能否到位、经营是否盈利。它们可共用背景盘，但应分别列出判断对象，不能用其中一项的吉象代替全部结果。

校盘记录至少包括：

- 起盘依据：问事时、事件发生时、约定行动时或其他明示规则。
- 公历年月日时、地点与时区；若校正地方时或真太阳时，写明算法。
- 交节时刻、阴阳遁、局数、上中下元、拆补或置闰等定局法。
- 子初或子正换日规则；旬首、旬空以及采用日旬空还是时旬空。
- 转盘或飞盘；天禽、中央寄宫、值使入中、神盘等处理方式。
- 驿马按哪一柱取；暗干等附加层是否启用。

这些选项属于【流程建议】的复现要求，不表示古籍对每项都有一致答案。接近交节、换日、换时边界且原始时间不精确时，应保留相邻盘并说明敏感处，不宜事后挑一张更合意的盘。

**四、取用神：先定角色，再看吉凶**

【流程建议】采用“分类取用为主、人物定位为辅、符使作背景”的结构。在看宫的好坏之前，把下列三层写下来：

1. **人用神**：这次问的是谁；若是双方或多人，分别如何标识。
2. **事用神**：真正要判断的对象是岗位、利润、合同、货物还是失物。
3. **关系用神**：媒介、审批、合作关系或其他关键联系，仅在题目需要时增加。

日干作为求测者是常用入口；但“日干为人、时干为事”只是总纲，分类占明确规定的角色应先在该分类法内落实。这里的问事日干也不能与某人的出生日日干混为一谈。

| 题目 | 可核对的取用入口 | 操作要点与出处 |
|---|---|---|
| 合伙是否对我有益 | 日干为我，时干为伙伴；另看生门 | 对方是否相助与项目是否有收益分开判断。[占合伙求财](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g24l9npyr) |
| 贸易、本钱与收益 | 甲子戊为资本，生门为利息 | 先分本金和收益；并非“盘里所有戊都代表同一笔钱”。[占贸易](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g24l9o2lv) |
| 开店 | 开门为店铺，日干为经营者 | 问店铺能否开、开后能否赚钱应分题。[占开店肆](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g24l9ndbn) |
| 科举、考试 | 日干为考生，景门、丁奇为文章，值符为主考 | 这是原篇角色；把开门用于现代岗位、天辅用于教育等，应另标应用引申。[占科举](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g23oqwfg2) |
| 传统婚配 | 庚为男家，乙为女家，六合为媒妁 | 这是特定婚配占法，不能把六合在所有题目中都当“伴侣”。[占婚姻](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g20v6kvtm) |
| 失物 | 日干为失主，时干为失物 | 原篇另以八卦区分物类；不可只见玄武便断被盗。[占失物](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g23oqq3w2) |
| 出行 | 日干为出行者，实际所往方为目标 | 方向必须有现实参照点。[占出行](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g23bcepe1) |
| 诉讼，采用卷十一该篇 | 日干为原告，时干为被告，值符作问官 | 此时不能又把值符同当原告；同书另有其他占讼法，应整套择一。[词讼占](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g278dcb3i) |
| 现代合同、宣传、文书 | 景门、丁奇可作内容或文本入口；六合可辅看关系 | 【现代归纳】由古代文章、上书、媒妁等义引申，不能冒称古籍已规定现代合同所有细则 |

**年命如何使用。**【流程建议】特定人物需要区分时，可预先约定以出生年干作辅助标识；不知年命时不必编造。年命不因“更个人化”就自动取代分类用神。若两个人年干相同，不得临时改换符号来制造区分；应承认当前映射分辨力不足，并补充现实身份信息或另立明确规则。

**甲如何处理。**盘面通常隐甲于六仪，须按所属六甲明确对应：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。遇到“日干为甲”时，采用哪一种遁甲定位办法必须写明，不可把所有甲都随意当戊。[景祐遁甲符应经纂](https://zh.wikisource.org/zh/欽定古今圖書集成/博物彙編/藝術典/第705卷)

**固定之后不换用。**用神空亡、入墓或落凶格，恰好是要解释的信息。不能因为结果不合预期，就改用年命、合干、对宫，直到出现吉象。《秘笈大全·临机变用》虽强调活用，也明确反对不断更换取占对象。[临机变用](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g2iu1gjkq)

**五、全盘看法：先扫描六个方面**

以下扫描次序是【流程建议】，其中反伏吟、主客、星门等概念有古籍依据，具体的现代事件语言则是应用解释。

**1. 符使。**记录当值九星、值使门及其落宫，作为主导背景和主要行事渠道的观察入口。须分清：作为当值九星的“大值符”、八神中的值符、值使门不是同一个概念；不能在不同推理步骤悄悄互换。具体占类可以赋予符使角色，例如科举之主考；脱离该占类时不要保留这一身份。

**2. 动静。**分别确认星伏吟、门伏吟、星反吟、门反吟，不因一层反伏吟就给全盘贴同一标签。古籍以本位重叠、对位加临描述反伏吟，并按用事区分适宜与否；例如《符应经》卷上将伏吟与收敛财货联系。将其解释为迟滞、反复、变动，是常见应用语言，不能一律译成“失败”。[符应经卷上](https://www.shidianguji.com/zh/book/SDZJ0533/chapter/1k2ku3jqyjcj7)

**3. 时令。**把当令、得生、受制等力量关系与喜忌分开。“旺”说明某种作用突出，并不自动有利于所问目标。九星另有专门旺相体系，见后文异说表。

**4. 空、墓、刑、迫、马的分布。**先做标记，判断时再看它是否落在主用、辅用、对手或无关宫。与题目无关的凶格不应无限上升为整个事件的否决条件。马的取法、空亡取法先固定。

**5. 时日特殊关系。**五不遇时属于时干与日干关系的传统条目。本稿采用时干克日干且二干同阴阳的口径，《遁甲演义》卷二“五不遇”亦有明确说明。它不等于“时干落宫克日干落宫”，更不能把所有宫间相克都称五不遇时。本文把它保留为注明体系的检查项，不当作跨流派统一否决器。[五不遇原文](https://zh.wikisource.org/wiki/遁甲演義_(四庫全書本)/卷2)

**6. 内外、近远。**常见分法为：阳遁以坎一、艮八、震三、巽四为内，离九、坤二、兑七、乾六为外；阴遁反用。古籍分类占已有用内外辅助判断远近快慢的例子。但近远是相对量，必须结合现实距离；问城区办事不应仅据“外”便说在千里之外。[占求财](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g24l9of8z)

全盘扫描结束只写背景，例如：“主要角色分居内外；相关门有反吟；事用有尚未落实的象。”此时不急于写人物性格、精确地点或具体结果。

**六、盘内看法：把每个用神宫看成有层次的组合**

这里把“盘内看法”同时拆为宫内分析和宫间分析；内盘、外盘的近远划分已在上一部分说明。

【流程建议】单宫先查“能否起作用”，再看“如何表现”。推荐顺序是：**用神及宫位 → 时令与落宫状态 → 门 → 星 → 天地盘干组合 → 神 → 刑空墓迫等综合限制。**各家可调整次序，但必须完整且可重复。

| 层次 | 实际要问的问题 | 解释边界 |
|---|---|---|
| 用神 | 这个符号本次代表谁、什么事物？ | 角色由题目和占法确定，不由吉凶倒推 |
| 宫 | 它处于什么环境、方位和承载条件？ | 宫位不是没有参照点的绝对地址 |
| 时令、宫与用神关系 | 得令、得生、受制、泄耗分别如何？ | 宫五行、星五行、干五行不能糊成一张表 |
| 门 | 事情通过什么活动、渠道或行动表现？ | 吉门并非适合所有题目，凶门亦有专用 |
| 星 | 在此占法中提供哪类性质、能力或条件？ | “九星为天时”不等于现代天文学证明其影响 |
| 天盘干与地盘干 | 本宫何干加何干，是否形成相关克应？ | 干的五行关系不等于宫与宫的关系 |
| 神 | 隐显、急缓、合作、威压等怎样修饰过程？ | 神象不能单独证明欺骗、事故等事实 |
| 限制与配合 | 空、墓、刑、迫及吉格影响哪一层？ | 先解释影响环节，不机械以吉抵凶 |

上层天、中层人、下层地的布局思想见《符应经·造式法》；将它组织成“环境—角色—行动—条件—表现”的读盘语法，是本稿归纳。[符应经卷上](https://www.shidianguji.com/zh/book/SDZJ0533/chapter/1k2ku3jqyjcj7)

三点必须单列：

- **吉凶与题目有关。**《符应经·八门所主》中，伤门用于渔猎讨捕，杜门用于遮拦隐伏，景门用于上书遣使，说明不能只按门名判断所有事情。现代合同、销售、培训等映射应由相应功能引申，并注明。[八门所主](https://www.shidianguji.com/zh/book/SDZJ0533/chapter/1k2ku3jqyjcj7)
- **门迫须看方向。**本稿统一采用《古今图书集成》所录“门克宫”为迫的口径；例如开门属金临震巽木宫。宫克门另记受制，不混称。该卷转录与部分《符应经》电子文本的概念句有差异，必须结合例子校读。[释门迫](https://zh.wikisource.org/zh/欽定古今圖書集成/博物彙編/藝術典/第705卷#《釋門迫》)
- **空亡须说明空在哪里。**【流程建议】把尚未落实、暂时无力、信息缺位等列为待验证解释；不能仅据空亡断某人或物绝对不存在。时旬空、日旬空分别记录，不把二者无区别叠加。

同宫若有多个角色，也不必为了区分而强行另找一宫。同宫可提示共享处境；具体人物仍需凭其已固定的干或其他身份标识区分。

**七、宫间看法：同时看方向、强弱、题意**

【流程建议】先画“人宫—事宫—关键相关宫”的关系，不急于把八宫都连成网络。若用神是门，比较的是该门所落宫与人宫；若采用天盘星、地盘星的主客古法，则按该古法比较星，不能悄悄换成宫。

| 关系 | 可先提出的工作假说 | 还需确认 |
|---|---|---|
| 事宫生人宫 | 目标或外部资源有利于本人 | 事用是否有力、落实条件是否具备 |
| 人宫生事宫 | 本人投入、支持或耗费较多 | 这种投入是不是完成目标所必需 |
| 人宫克事宫 | 本人可能控制、取得或约束目标 | 本人是否足够有力；求财与求和不能同读 |
| 事宫克人宫 | 要求、压力或约束主要落在人身上 | 是否属于必须完成的正常任务 |
| 比和 | 同类、匹配或处境接近 | 能否落实利益，不能仅凭比和断必成 |
| 天干五合：在干层另记 | 结合、协调，也可能牵制、拖延 | 两个参与干是否确实承担相应角色；不能把干合直接叫宫合 |
| 对宫轴：在宫位层另记 | 对立、移动、分开，也可能解除原有束缚 | 被冲的是障碍还是所需关系；对位不等于五行相克 |

这些解释是【流程建议】的语义入口，不能当统一断语。古籍具体占类有自己的成败规则。例如贸易之生门、资本宫关系，与婚配之乙庚关系服务于不同目标。[占贸易](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g24l9o2lv)、[占婚姻](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g20v6kvtm)

本稿固定的对宫轴为一与九、二与八、三与七、四与六；天干五合为甲己、乙庚、丙辛、丁壬、戊癸，只在已经定位的干层记录，合而是否化不作自动推定。地支六合、六冲若另启用，应单列具体支位及其对应角色；本稿最小配置不把这些关系合并成笼统的“宫合”。八神六合又是另一层符号。

对宫可作为有明确理由的补充，不能成为“本宫不好就去对宫找好处”的出口。坤艮皆土而处对位，也提醒我们：卦位相对与五行相克是两种关系，应分栏写。

天地盘也不宜一概解释成“天盘必为未来、地盘必为过去”。古籍天盘为客、地盘为主的用法有其语境；若借盘层叙述前后，须另说明采用的规则与根据。

**八、取象：先有限制，再有细节**

【流程建议】取象按六步做：

1. 先确定题目领域：人、事、物、文书、关系还是方向。
2. 只从该领域相关的用神与宫起步。
3. 先取功能或属性，再尝试具体物象；先说“文书环节”，后说“某份合同”。
4. 用门、星、干、神之间的组合关系组织语言，不把每个符号的所有象义都罗列出来。
5. 用其他相关层检查是否一致；来自同一关系的不同术语只算一条证据。
6. 将“较能支持的解释”“其他可能”“尚待核实”分开，保留能被事实否定的判断。

八卦物象可追溯到《周易·说卦》，《秘笈大全·占失物》又按八卦列物类。这能支持按性质分类的传统来源；将离火扩展到屏幕、把文书象扩展到电子合同，则属于现代类比。[说卦](https://ctext.org/book-of-changes/shuo-gua/zh)、[占失物](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g23oqq3w2)

下面是**现代整理的功能词表**，用于限制语义范围，不冒称各项都有同一古籍的逐字规定。实际取用仍以所选占法为准。

| 层 | 最少够用的取象词 |
|---|---|
| 八宫 | 乾：统领、规则、刚健；坤：承载、众多；震：启动、震动；巽：进入、流通；坎：流动、险隐；离：显现、文字；艮：停止、边界；兑：口舌、交换 |
| 八门 | 休：休整、协调；生：生长、收益；伤：损伤、追捕；杜：封闭、保密；景：表达、展示；死：终止、处置；惊：惊扰、争议；开：开放、经营 |
| 九星 | 蓬：险与流动；任：承担、稳定；冲：发动、推进；辅：教化、辅助；英：显现、明丽；芮：问题、学习等依占类而定；柱：阻隔、言争；心：统筹、医药等依占类而定；禽：居中、统摄 |
| 常见八神 | 值符：主导、权威；螣蛇：缠绕、惊疑；太阴：隐蔽、细密；六合：联系、撮合；白虎：强硬、损伤；玄武：隐情、信息不明；九地：沉静、潜藏；九天：高扬、外展 |
| 干象入门 | 乙：曲、柔；丙：明、显；丁：细、文；戊：厚、载；己：杂、曲；庚：刚、阻；辛：锐、改；壬：流、动；癸：隐、润。甲先按遁甲定位，不另造一个可任意放置的“甲宫” |

词表的局限：同一个符号在不同占类可以成为完全不同的角色；例如芮星不只在病占中出现，《符应经》也有交友受业的用事义。古本八神、九神以及勾陈、朱雀等配置与现代白虎、玄武配置并不总相同，不能把词表当通行一切版本的排盘说明。[九星所主](https://www.shidianguji.com/zh/book/SDZJ0533/chapter/1k2ku3jqyjcj7)、[基础研究摘要](https://eprints.lib.hokudai.ac.jp/repo/huscap/all/44606/)

一个取象示例：问题是“这份合同哪里需要复核”。景门、丁奇若被预先定为文本入口，玄武的隐情象可帮助提出“信息披露或条款理解是否完整”的检查假说。它不能单独推出“对方已伪造合同”。这是取象语法示例，未假定某张完整实盘，也不构成对真实对象的判断。

实物取象可先定形、质、色、用途、所在环境，再结合已知物品筛选。不能把“乾为圆、为金”立即缩成“金色手表”，也不能把“六宫”立即当六件、六千元或六个月。

**九、成败、条件与应期应分开写**

【流程建议】结果至少分成五项：

- 当前状态：已有条件还是尚在筹备。
- 目标可成性：支持与阻碍分别是什么。
- 代价与归属：谁投入、谁获益、有无附带负担。
- 关键条件：哪一个环节变化后，结论才可能改变。
- 应期：采用哪一条规则，对应哪一种事件变化。

“对方相助”“能签约”“能到账”“能盈利”是不同结论；“有变动”也不等于“目标成功”。

应期推荐按“先时间尺度、再触发条件、后候选窗口”操作：

| 处理 | 要求 |
|---|---|
| 定尺度 | 先按题目与现实流程确定看小时、日、月还是年，不从宫数倒推单位 |
| 找触发 | 在固定占法中选值临、出旬、填实、冲开等有明示规则的候选 |
| 分事件 | 分清应的是消息、手续启动、关系变化、到账还是最终完成 |
| 收窄 | 只保留少量候选，并写明为何优先这一项 |
| 保留不确定 | 依据不足时，写能判断快慢而不能判断日期 |

值临、冲合、空墓等应期解释在各家有不同使用条件。本文不把“空必冲实、墓必冲开、合必冲散”列为无条件公式。《神奇之门》的公开目录可以确认应期是其独立论题，但本次没有取得足够正文，不能把上述操作表冒充该书原文。[公开目录](https://www.sanmin.com.tw/product/index/002582691)

**十一、盘中信息冲突时怎样裁决**

【流程建议】以以下顺序排查，目的在于保持判断可解释，并非创造一条古籍统一权重公式：

1. 题目是否混合多个结果；先把签约、到账、收益等拆开。
2. 角色是否一开始就取错，或者在中途改变。
3. 是否混用了不同主客法、旺相表、入墓表或排盘体系。
4. 力量与性质是否混淆；有力的障碍并不因“旺”变成帮助。
5. 主用与辅证是否倒置；无关宫的神象不应支配主结论。
6. 有没有把同一事实重复算成多条支持；门克宫与该门迫在此口径下是一件事。
7. 若仍存在相反证据，分别写出有利部分、不利部分和待定条件，不强行凑成全吉或全凶。

推荐输出方式是：“可推进，但文书环节未落实”“伙伴愿助，但收益条件弱”“可能出现消息，尚不足以判断到账”。如果连这些层次也没有稳定依据，结论应是当前信息不足。

**十二、给定盘面的取用与宫间关系练习**

示例题：“与某人合作开店，能否正式营业，收益条件如何？”这是两个结果，应分别判断。以下借用《遁甲演义》卷三所举万历二十五年壬申日丙午时、阳遁二局的盘面演示读法，**这个合作开店题目是本稿另设的练习题，不是古例原有问事，也没有可核实的经营结局**。

练习限于角色定位、旬空标记及部分宫间关系；月令力量、完整门星神组合、全盘扫描和应期未在此例逐项展开，因此不将它作为完成全部步骤的完整占断。

原例载天心值符加离、开门值使加艮，丙奇至艮、丁至兑、乙至坤。按其盘序定位，可列本题所需的五项：[原例](https://zh.wikisource.org/wiki/遁甲演義_(四庫全書本)/卷3)

| 本题角色 | 定位 | 首先得到的盘面事实 |
|---|---|---|
| 我 | 日干壬，天盘离九 | 人宫属火 |
| 伙伴 | 时干丙，天盘艮八 | 伙伴宫属土；丙午属甲辰旬，寅卯空，艮八在本稿配置中标空 |
| 店铺 | 开门，艮八 | 店与伙伴同宫，同受该宫空亡标记；开门金与艮土为宫生门 |
| 资本 | 天盘戊，震三 | 资本宫属木，震三亦在本时旬空范围 |
| 收益 | 生门，巽四 | 收益宫属木；生门土受巽木克，记门受制，依本稿口径不称门迫 |

取用把合伙、店铺、资本、收益拆成了不同角色。这是【现代组合建模】，并非古籍原有的一套联合占式；各子题分别保留原来关注的关系，不用一项结果替代另一项。若采用的流派不接受这种组合，应分别按其完整占法作答。

现在逐项读关系：离火生艮土，先提出“本人向伙伴及店铺投入较多”的解释；巽木生离火，收益与本人有相生关系，是支持信息。但生门本身受所落宫制，资本、店铺又有空亡标记，支持信息附带落实条件。伙伴和店铺同宫的空不能算两条独立反证。

因此，这个练习可形成的结论是：“本人承担投入的倾向较明显；收益方向有支持，但资金与开业条件尚需核实，目前不足以认定营业和盈利都已具备。”再分别核查出资、场地、手续等实际事实。原例没有对应现实项目，不能给它编造三个月内开业或某日盈利的命中结果。

**十三、可以直接复制的记录单**

**成功标准与判断期限：**

**反证：**相反信息／体系冲突／重复计数检查。

**事后反馈：**事实、时间、资料来源；已应、未应和未判断均保留。

【流程建议】连续记录样本，保留失败例，判断标准应事先写下。比较两套取用法时，对同一批问题分别作事前判断，再核实结果。事后能讲通一个故事，与事前能稳定预测，是两件不同的事；记录的目的就是检验这一差别。
