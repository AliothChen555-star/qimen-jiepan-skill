# 0.4.0 修订对照

本版针对 0.3.0 审查中的八项问题逐条修正。六步顺序保持为：全盘、取用、宫位关系、宫内四盘、合并、结论。每步均保留盘面、规则与判断的依据。

| 问题 | 修正 | 核验 |
| --- | --- | --- |
| F01 九星月令法的差异说明不准 | 逐项列出《统宗》与《演义》正文法的旺、相、休等差异；工具提供显式选项，普通月令法独立 | 五行全表测试；同盘切换只影响九星字段 |
| F02 取用缺少分事目标 | 准备阶段先定成事标准，分事表覆盖求职、辞职、合作、买卖、借还、关系、风评等；人物、事项及年命分别定位 | 同盘求职与辞职回放，检查相同生扶关系为何不能直接推出相同结果 |
| F03 主客缺少可执行取法 | 区分角色宫法与方向宫天地盘法，明确谁往谁来；地盘本位星与天盘移动星分列 | 固定同一方向宫交换来去角色，复核支持方向；不临时换取法 |
| F04 格局缺少条件、例外和克应 | 保留有向干组合与复合格局，新增 20 条常用扩展释义、悖格及各甲柱定位；成立、适用限制与取象分字段 | 回首、跌穴的庚旬首例外；得使条件；甲柱与悖格测试及回放 |
| F05 星门入墓缺失 | 独立采用《奇门旨归》五行墓支表，分别标明天干、地干、星与门的墓位 | 五行墓位表测试；开门得宫生而同时入墓的固定盘回放 |
| F06 空墓激活解释含糊 | 先定作用对象，再定它影响什么；填空、冲空、冲墓按实际地支记录，残余限制继续保留 | 一支空不扩大为全宫全空；同一触发作用于本人和阻力的专项回放 |
| F07 应期缺少阶段和日期选择 | 先定阶段，再定单位、对象、候选和筛选；新增标准时日、时窗口换算工具 | 固定盘十日候选；换日、时区、夏令时及区间边界测试 |
| F08 行为用例缺少完整输入与回放 | 保存四份不重复的完整盘、哈希和来源；15 个场景按输入类型区分；实际回答与执行状态分别记录 | 两项六步完整回放、十项专项回放；三个环境场景列为未执行 |

## 文件分工

- [SKILL.md](../qimen-jiepan-skill/SKILL.md) 负责触发、资料路由和六步顺序。
- [解盘流程](../qimen-jiepan-skill/references/解盘流程.md) 定义每步任务、输出及整合方式。
- [用神与象义](../qimen-jiepan-skill/references/用神与象义.md) 定义角色与分事默认取用；[主客取法](../qimen-jiepan-skill/references/主客取法.md) 定义可选主客方法。
- [格局分析](../qimen-jiepan-skill/references/格局分析.md) 定义各层规则与格局条件；[空墓与应期](../qimen-jiepan-skill/references/空墓与应期.md) 定义动态解释与候选选择。
- [规则与出处](../qimen-jiepan-skill/references/规则与出处.md) 记录来源、采用口径和异说；[规则边界](../qimen-jiepan-skill/references/规则边界.md) 处理未覆盖项。

定义只在所属专题展开。流程通过引用使用定义，不把问事模板、古籍原句和程序字段塞进同一条长指令。例子用于展示用法，不自动升级为通则；同一宫的证据也不因角色重叠重复计权。

## 验证结果与范围

37 项确定性测试通过，原有 1,080 种排列与 81 种有向组合检查保留。完整命令见 [README](../README.md#验证与维护)。实际解读见 [回放记录](../qimen-jiepan-skill/evals/replays/0.4.0.md)，执行范围见 [状态文件](../qimen-jiepan-skill/evals/replay-status.json)。

冻结盘由本地起盘程序生成；本轮手工回放由同一助手执行。环境安装、实际时钟和多轮场景仍按状态文件列为未执行。日期工具提供候选窗口，最终应期仍需对照事件阶段与宫内条件。

排盘算法及规则 `chai_bu_v1.0.0` 保持不变。格局核验升级为 `qimen_patterns_v1.1.0`；新增日期工具 `qimen_timing_candidates_v1.0.0`。本版未把异书的飞盘规则并入转盘算法。
