# 奇门遁甲解盘

起盘、核验并按已明确采用的原法解读。**星门神本义、天地干格及其原有条件必须实际参与判断，不能只剩五行生克。** 原文没有的断法，不自行扩充为内核。

## 输入与起盘

- 首次使用说明实际技能路径。声明的上游、核实到的 Git 版本和未知的安装历史分别说明。
- 使用用户指定的版本或盘面。缺项不补造；理论咨询不主动起盘，只要求起盘时只展示盘面。
- 同一问事沿用已选时刻或第一次成功盘。补背景、年命、查出处和事后复盘均不重起。
- 要求当前时间起盘时说明取本次运行时刻，并用 `--now`；指定时间则使用带时区的时间。
- 默认 Asia/Shanghai 标准时；真太阳时须有用户认可的经度。保存原始 JSON、取时、时间模式及规则版本。
- 入口为 `scripts/qimen_cli.py`；初始化和依赖只用技能私有环境。失败时保留错误，不编造盘面。详见 [起盘程序](references/起盘程序.md)。

```text
python <技能目录>/scripts/qimen_cli.py chart --now --format json
python <技能目录>/scripts/qimen_cli.py chart --datetime <带时区的ISO时间> --format json
```

## 解盘

必读 [解盘流程](references/解盘流程.md) 与 [格局分析](references/格局分析.md)。按用户要求执行：

**整体看势 → 宫内详查 → 回归整体定结论 → 最后细节取象。**

前三步已经要读星门神的本义、吉凶及格局；最后才展开行业、人物、器物等具体对应。“天芮有病象”不是应当后置的行业取象。

- **金融问事必读 [金融解盘](references/金融解盘.md)**；金融角色、行业类比、产品与收益口径只在该专题维护。
- 其他事类取用见 [用神与象义](references/用神与象义.md)。
- 需要天地盘主客法时读 [主客取法](references/主客取法.md)，不得临时换主客趋吉。
- 涉及空墓或应期时读 [空墓与应期](references/空墓与应期.md)。
- 出处、异说及支持范围查 [规则与出处](references/规则与出处.md)、[规则边界](references/规则边界.md)。

已有完整内置 JSON 可运行：

```text
<技能私有Python> <技能目录>/scripts/inspect_patterns.py chart.json --output patterns.json
```

工具核验结构，不代替原文解读。九星默认 `tongzong`，显式选择时可用 `--star-season yanyi_prose`；不可按宫位吉凶混换。工具未收录某干格克应时查原文，不以五行方向补写格义。

## 内核约束

- 格局按实际天地顺序、主寄和完整成立条件读；原文的用途、限制、例外一并保留。吉凶本性与旺衰条件共同判断，不建立自创层级权重。
- 删除默认的“星→门→干”生克链和同宫五行通关、缓冲法。专门断法确有对应原文才按其范围使用。
- 相生关系不能改写已成立凶格，得令也不能把病星直接改成利好。明确不利时直接给不利主判，不用“不能据此必跌／必败”冲淡结论。
- 不把四盘强行固定成“外在、基底、行动、助阻”，不把地盘干自动定义成过去或资金底仓。
- 原文规则、用户指定的分析顺序、现代角色转译和末端类比明确分开；“本技能约定”不是新增传统断法的依据。
- 同宫共享一次核验；主寄分清，同源条件不重复计票。事后补读与原判断分开，不以已知结果改选断语。

默认中文，先回答主势及依据，再按需说明细节。未知情节只作可能对应。传统取象不能证明他人已实施某行为，也不能保证投资收益；涉及具体高风险行动时简要说明实际适用边界。
