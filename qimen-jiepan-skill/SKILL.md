# 奇门遁甲解盘

当用户要求起盘、解读奇门盘、分析九宫、判断某事成败或应期时使用。本 Skill 自带起盘程序：有时间参数时先调用 Skill 内程序，再解盘；已有盘面时直接解盘。

## 起盘集成

- Skill 安装或更新后，先用系统 Python 运行 `python <Skill目录>/scripts/setup_env.py`。该脚本只在 Skill 目录内创建 `.venv` 并按 `requirements.txt` 安装依赖，不得向系统 Python 执行 `pip install`。
- `scripts/qimen_cli.py` 是统一入口：若 `.venv` 不存在或依赖版本已变，它会自动调用上述初始化逻辑，然后用 Skill 私有 Python 重新执行。
- 用户说“按当前时间起盘”或未提供时间但明确要求起盘：运行 `python <Skill目录>/scripts/qimen_cli.py chart --now --format json`。
- 用户提供 ISO 8601 时间：运行 `python <Skill目录>/scripts/qimen_cli.py chart --datetime <时间> --format json`。
- 用户提供经纬度、时区、真太阳时等选项时一并传递；不要同时传 `--now` 和 `--datetime`。
- 起盘程序位于本 Skill 的 `scripts/qimen_cli.py` 和 `scripts/qimen/`，不依赖外部 qimen 项目；若虚拟环境创建或依赖安装失败，报告原始错误，不改用系统环境，也不自行编造盘面。
- 起盘后保留完整 JSON 作为解盘输入，并在回答中列出取时瞬间、规则版本和时间模式。
- 用户只要求起盘时输出盘面，不强行进行吉凶解读；用户同时提出问题时，生成盘面后继续执行下方解盘流程。

## 工作流程

1. 核对时间、时区、地点、盘式、阴阳遁、元局、规则版本、旬首、旬空、马星、值符和值使。
2. 发现拆补/置闰、转盘/飞盘、换日或中宫规则冲突时先列冲突，不混用规则。
3. 将问题改成可判断句，确认对象、结果和期限。
4. 先声明用神理由；首版不自动选用神，问题不清时询问或明确假设。
5. 按我方与事项/对方宫、旺衰生克、门星神干、值符值使、旬空马星、应期顺序分析。
6. 至少列两条支持依据和一条反向依据或不确定因素，再给倾向结论。
7. 应期只给窗口和触发线索；冲空、填实、出空、冲合或马星只有作用于用神、门或值使时才可引用。
8. 入墓、击刑、门迫、伏吟、反吟未提供或未计算时，明确写“未核验”。
9. 默认规则：拆补法时家转盘；马星按时支（horse.basis 可为日支）；中宫地盘干寄坤二；中宫只保留天盘天干，九星、八门、八神留空；天禽随天芮。
10. 医疗、法律、投资、安全问题只给倾向和核验建议，提醒结合专业意见与现实证据。

## 输出

默认中文。标准版依次给出：规则核对与用神、结论倾向、主要依据、特殊因素、过程与应期、建议与不确定性。简版 5—8 句；标准版约 300—800 字；教学版按层解释。
