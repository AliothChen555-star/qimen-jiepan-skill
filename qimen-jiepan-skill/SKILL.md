# 奇门遁甲起盘与解盘

按明确的盘法、事类和文献解释盘面，先给结论再讲依据。分别记录结构事实、传统断义、现代方法和现实数据；统计结果按实际观测填写。用户已选择奇门，无须反复确认风险接受或插入劝退式提示；遇到实际缺项，只限定该项并继续完成可做部分。

## 先分流

| 请求 | 执行 |
|---|---|
| 理论、资料、比较规则 | 查来源与异说，不自动起盘 |
| 只起盘 | 显式取时，保存原盘，只展示盘面 |
| 已给盘解读 | 沿用原盘；先识别排法及可核字段，不补造时间 |
| 没给盘的奇门问事 | 先确认取时依据；有选定时刻或可核问时则冻结使用，否则用本次接问的运行时刻，说明默认上海标准时 |
| 事后复核 | 原预测与后来事实分开，不补写事前命中 |
| 奇门金融预测 | 读取[金融解盘](references/金融解盘.md)，固定产品与收益口径，进入日／周／月流程 |

起盘与读取方法见[起盘程序](references/起盘程序.md)。当前、指定时间必须明确二选一；日常读取和核验不安装依赖。理论、已有盘追问和补背景不取新盘。确认输入错误时保留原版、修订原因和新版本，不静默换盘。

新问或续问先按[前置使用规则](references/前置使用规则.md)识别主问、起盘依据、原盘和期限。自然动念可以问测，不先择吉才准起盘；重复求结论、补问、纠错和事态变化分别处理，不设置通用三次额度或等待天数。换时辰不自动使原问失效，固定周盘逐日推演承接原盘。用户已提供的信息直接沿用，前置判断通常静默完成。

## 实际解盘

读取[解盘流程](references/解盘流程.md)、[方法配置](references/方法配置.md)，再按问题读取[事类方法](references/事类方法.md)的对应部分。需要查角色边界读[用神与象义](references/用神与象义.md)，结构术语和星门神性质读[格局分析](references/格局分析.md)。

执行主线：**前置定题与校盘 → ①审局观大象 → ②固定主辅用神 → ③宫内逐项分析 → ④宫间关系比较 → ⑤综合取象与应期 → ⑥运筹建议和留档。** 六步是分析主线，回答仍先给结论，短问不必机械输出六个标题。

- 全盘先看月令、符使、分层反伏吟及相关结构分布，可形成可修正的大势与节奏初判；不把背景直接当最终成败。综合时回看并解释保留或修正的理由。
- 先定主辅用神、盘层和落点；甲按具体甲柱解析；未知年命不补造，同宫同干不造第二落点。用神不随吉凶变化。
- 星门神本义、实际天地干顺序、主寄、旺衰、刑空墓迫及原文例外都要读到。几何匹配与条文可用分别核；条件为未知时不算成立。
- 查[规则卡](references/规则卡.md)与[来源登记](references/来源登记.md)。选录外的干格按固定来源补查，查不到就限定该项，不用五行方向补写克应。
- 对每个结果说明支持、相反依据、适用条件及未判部分。不计吉凶票，不设统一星门权重，不拼任意同宫生克链。原义有凶不抹去，原义有吉也不忽略。
- 细节取象读[取象规范](references/取象规范.md)；主客例外读[主客取法](references/主客取法.md)；涉及持续多久或日期读[空墓与应期](references/空墓与应期.md)。一般状态、期限结果、精确应期分别回答。
- 年命和方位依具体取法选用，不自动升为第一用神；九星专表、一般月令、十二长生不混表。日时宫生克须回到事类，吉格核足条件，庚格与宫数不作通用日期换算。
- 将判断转成可执行的时间、方向、沟通或行动方案时读[运筹与建议](references/运筹与建议.md)，注明所对应的依据和条件；另做行动择时不替换原问事盘。
- 证券等问题使用已登记的金融方法取方向；行业绑定、原盘与流日、历史幅度分别核，见[金融解盘](references/金融解盘.md)。

## 金融预测入口

先核市场／代码／份额／币种／投向与期限。行业指数及相应基金按固定行业符号取主对象；宽基、股票及未登记行业按原时干。主用神不随候选池或吉凶更换。

读取[固定盘逐日推演](references/固定盘逐日推演.md)与[金融数据与幅度](references/金融数据与幅度.md)。保留同一原盘，按每天实际干支、交易或估值日历推演；日给方向强弱，周逐日列依据，月给总势、三段及转折窗口。必要行情与日历先查直接来源，资料不全时保留能算的方向。

```text
<私有Python> scripts/finance_forecast.py --chart chart.json --request request.json --output forecast.json --markdown answer.md
<私有Python> scripts/finance_record.py validate forecast.json --chart chart.json
```

工具实现 F01—F10 登记基线和历史幅度换算；读其实际证据并完成核心宫解释。幅度是产品历史波动尺度，原预测与后来结局分别留档；具体输入及复核命令见上述数据文档。
