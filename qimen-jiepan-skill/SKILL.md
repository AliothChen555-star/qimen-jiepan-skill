# 奇门遁甲起盘与解盘（v1.0 基本版）

> 模型建议：建议使用 Qwen 或 Gemini。

采用**拆补法时家转盘奇门**（默认东八区标准时、午夜换日、中五寄坤二、天禽随天芮、马星按时支）。先用脚本起盘，再按固定框架解盘，结论明确、依据清晰、不堆砌套话。

## 一、起盘与调用

本 Skill 自带排盘脚本 `scripts/qimen_cli.py`，严禁手算或编造盘面。

- **按当前时间起盘**：
  ```bash
  python <Skill目录>/scripts/qimen_cli.py chart --now --format json
  ```
- **按指定时间起盘**（须带时区偏移，与 `--now` 二选一）：
  ```bash
  python <Skill目录>/scripts/qimen_cli.py chart --datetime 2026-11-26T22:00:00+08:00 --format json
  ```
- **可选参数**：`--timezone`、`--longitude`、`--latitude`、`--time-mode true_solar_time`、`--day-boundary zi_start`、`--horse-basis day`、`--format text`。
- **首次缺依赖**：如提示缺少 `lunar-python`，先运行一次 `python <Skill目录>/scripts/setup_env.py`（仅在 Skill 目录内建 `.venv`，不污染系统 Python）。
- **分流原则**：
  - 用户只要求起盘：直接输出完整盘面，不强行断吉凶。
  - 用户已给盘面或追问同一盘：沿用原盘，不重起新盘。
  - 用户只问理论或格局含义：直接解答，不自动起盘。

## 二、解盘流程

盘面基础符号、门迫、击刑、入墓、五不遇时及常见十干克应，按需查 [基础速查](references/基础速查.md)。

### 1. 审大势
- 核对四柱、节气、阴阳遁局、值符、值使、旬空与马星。
- 先看全局异象：是否**伏吟**（主迟滞、守静、重复）、**反吟**（主反复、急变、先成后变或折腾）、**五不遇时**（主大势阻滞、多磨）。

### 2. 定用神（先定后看，不随吉凶改换）
- **通用基准**：日干为问事人（我方），时干为所问之事（或对方）；值符为大势/贵人/上司，值使为执行/过程/关键节点。
- **常见事类主用神**（在日时干之外重点兼看）：
  - **求财/投资/生意**：生门（利润）、戊（本金/资金）
  - **工作/求职/事业**：开门（职位/公司）
  - **合作/谈判/感情**：六合（关系/中介）；感情兼看乙（女方）、庚（男方）与日时
  - **健康/疾病**：天芮（病症）、死门（病势），天心与乙奇（医药/医生）
  - **出行/变动**：开门、马星、九天
  - **竞争/官非**：值符（裁判/官方）、伤门（竞争/博弈）、景门（文书/证据）
- 问事对象或期限不清时，先用一句话说明当前采用口径再断，不反问琐碎表单。

### 3. 查核心宫状态（强弱与病症）
对日干宫、时干宫及主用神宫逐一核对：
- **月令旺衰**：按月支五行看各宫旺相休囚死，判断底气强弱。
- **宫内四层**：八门（人事顺逆，最直接）、九星（天时性情）、八神（隐性助力或干扰）、天盘干+地盘干（核心十干克应吉凶格）。
- **关键异常**：
  - **空亡**：虚象、未落实、减力或计划落空（凶星凶格逢空亦减凶）
  - **入墓**：受困、隐藏、能量发不出来
  - **击刑**：别扭、内耗、受损、推进拧巴
  - **门迫**：受制、压力大、事倍功半
  - **马星**：动象、加速、奔波、变化快

### 4. 比宫间生克（定成败与主客）
比较我方（日干宫）与所问之事/主用神宫的五行关系：
- **用神/时干生我，或我克用神且我旺相**：偏有利，主动权在我或事来就我。
- **用神/时干克我，或我生用神（耗泄大）**：阻力重，或付出多回报少。
- **比和或同宫**：关联紧密、势均力敌，看宫内吉凶定好坏。
- 综合**宫内吉凶 + 宫间生克 + 值使门状态**下判断，不单凭某一个凶神或单一相生武断下结论。

### 5. 看应期与建议
- **应期思路**：抓住核心卡点定触发窗口——逢空看冲空/填实，逢墓看冲墓，逢合看冲，逢冲看合；伏吟主慢，反吟与临马主快。只给合理时间窗口和触发线索，不强行编造精确小时。
- **行动建议**：紧扣盘面症结，给 1–3 条具体可执行的进退策略（宜推进、宜暂守、需补短板或防哪类风险）。

## 三、回答规范

默认中文，结构简洁直接：
1. **直接结论**：开头 1–2 句给出明确倾向（偏利 / 偏不利 / 有条件可成）与核心原因。
2. **盘面要点**：简列时间、局数、符使、空亡、马星与全局状态（如伏吟/反吟/五不遇时）。
3. **关键依据**：列出所取用神及其落宫状态、宫间生克；同时点出主要**不利/反向因素**，不报喜不报忧。
4. **应期与建议**：给出时间窗口、关键节点与实用建议。

短问精简回答，复杂问题展开分析；不输出冗长的免责套话或与盘面无关的说教。
