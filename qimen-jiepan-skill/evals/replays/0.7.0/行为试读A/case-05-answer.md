按你给出的局部条件，开门在震三是门迫；休门在坤二是受制。星盘与奇仪盘均为整体伏吟，门盘仍转动，不能把它们一概写成全盘伏吟，更不能叫全盘反吟。下面只作局部规则核验，不另起盘，也不假装已校验你未交出的完整kun2原盘。

开门属金，震三属木，金门克木宫，所以是门迫。开门本有入官、开通、谋事、交易等吉用，但吉门迫说明这些用途受到限制；不能据“开门吉”省略迫，也不能只见一个凶名便推整件事必败。

休门属水，坤二属土，土宫克水门，所以是受制，不是门迫。休门有休养、接洽等吉用，受制使其功能受约束；未知月令与所问用途，不能补成水弱到完全无用，或把它解释成现实阻力已经发生。[《旨归》卷四，迫制](https://www.shidianguji.com/zh/book/CADAL02031557/chapter/1l6y1gl6jszza)

反伏吟要分层看全体位置：九星均回本位，是星盘整体伏吟；天禽按kun2随芮寄坤二，不另造中五独立星位。全部奇仪回地盘对应位置，是奇仪盘整体伏吟，它随星同源转动，不能再凑成另一张独立凶票。八门既然整体还在转动，就不是门盘伏吟；它是否整体到对宫，仍须看全体门位。就本题给出的开门震三而言，开门本位乾六、对宫巽四，它也不在对宫，所以在这些条件同时成立的前提下，门盘整体反吟也不成立。休门坤二同样不是其本位坎一的对宫离九。[《旨归》卷四，反伏吟](https://www.shidianguji.com/zh/book/CADAL02031557/chapter/1l6y1gl6jszza)

伏吟的静守、重复、推进不易等传统解释可以保留，但它对急于变动与需要守成的事情意义不同。迫、制、伏吟是结构与性质，事情吉凶还要固定对象、目的、月令、相关宫的实际星门干神和条文条件。此题可确定这些结构名目，不能据此直接判你的整件事坏。
