不能只凭“艮土生开门金”就说通道很好。这个宫的门状态是：开门本为吉门，宫生门，但子月处休，且有开门入墓的结构。

| 核验项 | 结果 |
|---|---|
| 本性 | 开门为吉门，有开通、入官、谋事等原义。 |
| 月令 | 原盘子月属水；金生水，按普通门月令法为休，不套九星旺相表。 |
| 门宫关系 | 艮八土生开门金。不是门克宫的迫，也不是宫克门的制；两项均不成立。 |
| 门墓 | 开门属金，星门五行墓为丑；丑属艮八，故开门入墓结构成立，来源为 ZG-4。不能套某个阴阳天干的墓表。 |
| 空亡 | 原时旬空午、未；艮八丑、寅不在其中，开门所在宫不空。 |
