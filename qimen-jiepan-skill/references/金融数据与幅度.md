# 金融输入、幅度与记录

## 运行入口

```text
<私有Python> scripts/finance_forecast.py --chart chart.json --request request.json --output forecast.json --markdown answer.md
<私有Python> scripts/finance_record.py validate forecast.json --chart chart.json
<私有Python> scripts/finance_record.py evaluate --records forecast.json --outcomes outcomes.json --output evaluation.json
```

使用现有私有环境，无新增依赖。文件已存在时不覆盖；修订另用文件名。一般占事继续使用 `reading_record.py`，金融使用独立的 `qimen_finance_record_v1`。截图或外部排法无法通过完整盘核验时，可依已知盘面人工推演；不伪造缺失元数据来调用程序。

## 请求与产品档案

下面是结构示例，TEST 是虚构标的，没有真实行情含义。实际执行须换成已核产品，日期换成本次预测范围。

```json
{
  "issued_at": "2026-10-31T10:00:00+08:00",
  "start": "2026-11-02", "end": "2026-11-08",
  "horizon": "week", "period_style": "rolling", "star_season": "tongzong",
  "assets": [{
    "id": "XSHG:TEST", "name": "合成行业指数", "market": "XSHG", "code": "TEST",
    "currency": "CNY", "instrument": "index", "return_basis": "price_return",
    "metadata_source": "synthetic example", "metadata_checked_on": "2026-10-31",
    "sector": "semiconductor", "classification_source": "synthetic industry", "exposure": "sector"
  }]
}
```

`horizon` 为 day/week/month，日期包含首尾；`period_style` 为 natural/rolling。程序接收明确日期，语言中的“下周”“五个交易日”先依据官方日历转换。`instrument` 为 index/stock/etf/fund；fund 指场外基金，必须提供 `share_class`、`valuation_timezone`，收益用 nav_total_return。指数区分价格／全收益口径；场内基金区分交易价与净值。

市场内置 XSHG、XSHE、XHKG 的 2026 年日历。港股普通日按收市竞价最晚16:10、半日12:10作为窗口终点。产品真实收市规则若不同，以产品日历覆盖。其他市场、年份、临时停牌和特殊交易日，先从官方核实后提供 `calendar`；不默认“周一至周五都开市”。`calendar_market` 只在产品确实遵循该市场日历时设置。

```json
{"timezone":"America/New_York","valid_from":"2026-11-01","valid_to":"2026-11-30",
 "open":"09:30","close":"16:00","source":"本次已核的官方日历 URL",
 "holidays":["2026-11-26"],"half_days":{"2026-11-27":"13:00"},"overrides":{}}
```

日期应按实际核查填写；上例不自动作为美股内置配置。覆盖单日可用 `overrides: {"YYYY-MM-DD": {"closed": true}}` 或 open/close。日市适配器不处理跨午夜夜盘、期货连续合约或期权价格模型。日历快照随记录保存，核实范围之外需更新后使用。

QDII 与跨市场 ETF 记录 `tracked_index_id`、底层市场和币种、每日重置／杠杆属性；上市地价格使用上市地日历，基金净值使用管理人估值日历，不能用底层港股日历替代上海上市 ETF 的交易日历。`valuation_windows` 逐归属日提供 `{start,end,source}`，应覆盖这一天所有底层市场采价期间；若底层分段另附 subwindows，整体 start/end 取最早／最晚。未核采价窗口只影响前瞻时点分类。

已核空墓示例：`role_context: {"primary": {"void_active": true,"void_branch":"卯","void_evidence":"本次已核角色支位与实际空亡作用"}}`。字段支持 void_active/void_branch/void_evidence、tomb_active/tomb_branch/tomb_evidence、other_suspensions；默认不把几何匹配升级为实际悬置。角色包括 primary、direction_door、capital、profit、hour_background、已存在的 sector；direction_door 用于主对象宫门的实际空墓。墓的依据要说明采用口径，未核六仪墓不填 active。

## 历史行情

`history` 包含 asset_id、currency、return_basis、source、mode、rows。默认 mode=returns，每行 `{date,available_at,return_pct}`，单位是百分比，1.2 表示1.2%。available_at 是该日完整数据当时可取得的时刻，不能拿抓取时刻倒填。只采用早于 issued_at 的数据；被排除的行数另存。重复日期、非有限数、可得时刻早于收市、币种或口径不符会报出具体问题。

mode=values 每行 `{date,available_at,value}`，value 为可比收盘或单位净值。价格收益用可比前值，除权日可给 `reference_value`；否则用上一条 value。含分红收益另需每行 `cash_distribution`（按期初份额计的现金分配）与 `share_factor`（期末／期初份额因子），无分红／拆分时分别为0、1。

收益百分比：`((value × share_factor + cash_distribution) / reference_value − 1) × 100`。首条没有 reference_value 时只作基准。累计净值不能当单位净值，不能直接将累计净值相除。多个币种先按事前明确汇率口径换算；杠杆产品用产品本身历史，不把底层月收益乘杠杆倍数。

按发布时间前最近60个有效日收益，至少20个，计算绝对收益 A20/A50/A80/A95。窗口和样本数固定在方法版本，整份日／周／月预测共用一个快照。

| 档位 | 幅度参考带 |
|---|---|
| +2 | [A50,A95] |
| +1 | [A20,A80] |
| 0 | [-A50,A50] |
| -1 | [-A80,-A20] |
| -2 | [-A95,-A50] |

中点称“情景中点”；历史分位数用于百分比尺度，不给区间附加未经校准的概率。负端最低 -100%。输入不足仍输出方向，幅度置空。采用代理必须是档案中明确的 tracked_index_id，历史 asset_id 指向该指数，币种／口径一致，另给 proxy_reason；答复写明是指数代理幅度。

盘中已有涨幅放 `observed_components: {"日期": {"return_pct":0.5,"as_of":"含时区时刻","source":"行情来源"}}`。程序保留全天情景，并按 `后续收益=(1+全天收益)/(1+已发生收益)-1` 换算对应后续区间；这一条件情景不是完整全天前瞻。没有实时行情不编已发生部分。

## 周月汇总

每日中点和上下端点分别用 `∏(1+r)−1` 复利连接，称路径情景包络。它表达同一路径假设，不是已校准置信区间。跨市场分别按各自交易日计算，不把假期补成0%收益样本。

月方向以复利中点判断，近零带为 `0.2×A50×sqrt(交易日数)`（百分比单位）。自然月1—10、11—20、21—月底分段，滚动月按自然日期近似均分三段。没有历史尺度时只报盘势基调及逐日作用，不称已经算出月末收益。转折须相反方向持续至少两个交易日；中性本身不算反转；最多三处，优先直接触发和持续长度。

同市场、币种、收益口径的多个标的，`rankings` 按方向档位降序且保留并列。这是方向强弱排名，幅度参考另列；不把不同波动尺度当作相同含义。

## 记录复算与结局

记录含原盘、原请求、方法和日历快照、角色、每日日环境、原盘／当日基调、条件、正反关系、档位、幅度和汇总。`record_sha256` 校验全文，`finance_record.py validate` 还从输入复算，改一个数并重新算哈希也无法绕过复算。升级方法后用原版本复核旧记录。

`issued_at` 为声明发布时间，`created_at` 为实际生成时刻，分别保留。真实结局另存数组，每项包含 record_sha256、asset_id、date、currency、return_basis、return_pct、available_at、source。结局不得回写原预测；同一记录、资产、日期只收一个确定版本，修订另存。

评估只纳入 full 且实际创建早于采价开始的行；盘中、事后、采价未核、缺失结局分别统计。本地文件时间不是第三方存证，正式长期评估另保留不可改时间戳。报告方向三类（涨／平／跌，实际0单列）、训练样本A50×0.2中性带、情景中点MAE、区间覆盖与宽度、并列排名、押涨／零收益／历史均值／动量基线。同盘与重叠标的日期按组报告，行数不当独立样本量。无真实结局时统计留空，不阻止使用预测。
