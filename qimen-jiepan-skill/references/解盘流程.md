# 时家转盘六步解盘流程

主线是：**前置定题校盘 → 审局观象 → 取用定位 → 宫内分析 → 宫间比较 → 综合取象与应期 → 运筹与留档。**

六步用于组织分析，回答仍先给结论，再展开依据；短问可合并呈现。此流程是本技能选择的工作方法，不宣称所有古籍都按同一顺序。分类条件见[事类方法](事类方法.md)，固定口径见[方法配置](方法配置.md)。

## 前置：定题、续问识别与校盘

先按[前置使用规则](前置使用规则.md)确定用途、主问、对象、角色、结果与期限，判断继续原盘、纠错或关联新盘。已知事实直接使用，关键歧义才补问。

校对原盘来源、时间依据、时区及钟法、换日、四柱、节气三元、阴阳遁局数、旬首、符使、空马和寄宫。内置JSON用工具核验；外部盘按已知字段读，不把缺字段补成程序已核。方法先冻结，结果不合预期也不临时换表。

同一主问包含多个结果时，先区分阶段，例如洽谈、签约、开业、回款和净收益；阶段互不替代。用户问“多久减轻”时，从上下文明确减轻指什么，不把盘数直接换成天数。

## 一、审局与观大象

**看什么：**

- 时令及旺衰基准：节月、阴阳遁、所选九星专表与一般宫门干月令法。
- 九星、八门、奇仪各自的伏吟或反吟；全盘、局部和某个符号的状态分开。
- 值符星、值使门、时干及相关格局的落点和分布；值符星与八神值符分开。
- 空墓刑迫、马星及特殊格局集中在哪里，是否落到本问相关对象，哪些条件还需核对。

**形成什么：** 给出可修正的盘势和节奏初判，例如静守、反复、推进受阻、动而未定；解释依据及适用范围。星门性质在这里就参与，不等到最后才读取。

伏吟常提供守静、迟滞等背景，反吟常提供反复、变动等背景；快慢需结合事类和核心用神，不把“反吟快”直接等同成功，也不要求星门干全部同时伏吟才承认某一层伏吟。

符使可作全局枢纽，但领导、来意、执行、审批和最终成败各按事类定位，不能由一个称谓包办。初判有依据就说清楚；尚不足时保留待核点，不先锁死最终顺逆。

## 二、精准取用与固定主辅角色

**顺序：现实对象 → 事类方法 → 主用 → 必要辅用 → 盘层与实际落宫 → 角色间待比较的关系。** 具体入口见[用神与象义](用神与象义.md)。

- 常用日干定位自问者，时干依该题定位事情、对方、产品或其他对象；每个子问题的时干只有一个主要角色。
- 专项用神按事类选取。年命、方位、合干可按已选方法作主用或辅证，不自动取得跨事类优先权。
- 每个角色写明符号、天盘或地盘、主干或寄干、实际宫位、用途和来源。甲按具体甲柱遁仪，不一律套本时旬首。
- 同干同宫不虚构第二个落点；未知年命不补造。补背景可以修正角色理解，但须说明原因并保留原解释，不能只因凶格而改主用。

“多维交叉定位”是比较同一对象不同依据的适用关系，不是堆越多符号越好。支持同一对象的独立信息可互相校验；星随干转、同一凶格的多个名称等同源信息不重复加票。

**本步产物：** 一份简短的角色表，后续所有断语都能对应到其中的对象与结果。

## 三、剖析核心宫内部结构

每个相关宫核一次；多人同宫共享结构事实，角色意义分别解释。顺序可按具体方法调整，但以下内容要覆盖：

| 层次 | 具体检查 | 形成的判断 |
|---|---|---|
| 地宫与时令 | 宫卦、地盘干、季节、主寄及作用对象 | 所处条件、得令得地与否 |
| 天盘 | 九星、天盘干、所选星旺衰、传统分事宜忌 | 对本问的天时和性质；九星不专属“长期” |
| 人盘 | 八门本性、适用事项、门宫迫制与生助 | 行动、人事通道及执行状态 |
| 神盘 | 八神性质及当前对象上的具体作用 | 助力、隐情、惊扰等可核方向，不直接当已发生事实 |
| 奇仪格局 | 实际天X加地Y、主寄组合、原义与附加条件 | 当前矛盾、有利条件及其例外 |
| 刑空墓迫马 | 对象、层次、具体支、严格或扩展口径 | 哪项条件受限、作用于哪一阶段 |
| 十二长生（采用时） | 完整表来源、阴阳顺逆、土法及宫内具体支 | 阶段状态的辅助；不取代月令法或星旺衰表 |

宫内细则见[格局分析](格局分析.md)。力量、吉凶与结果分开；临旺不等于有利，凶义不能用同宫相生抹去。四害是便于归纳的常用称呼，不表示凡见一项就自动败局，也不是只查四项便足够。

戊加丙等吉格先确认结构，再核迫墓刑及原文例外；辛加乙等凶格保留原凶义，再核主客适用。用神缺一个已核条件时说明该条件，不把整宫其他已知信息一并作废。

**每宫落一句宫内结论：** 这个对象现在有何条件、主要阻力是什么、作用于哪一步。不要仅列符号，也不要在尚未比较对方时提前宣布全事成败。

## 四、横向比较关系与成败条件

把本题相关宫放在一起比较。先说比较的是宫、门、星或天地干，方向写清。专法比较星时不偷换为宫；日时关系也不自动等于天地盘主客，见[主客取法](主客取法.md)。

- 相生可说明支持、供给或依赖方向，再结合该事类判断受益、付出或牵绊。
- 相克可说明控制、制约或冲突方向，再判断主体是否有力、控制对象是否正是所求、原法如何断。
- 比和或同宫可说明关联，但是否公平、停留、纠缠或难以区分，须回到具体问题。
- 财本与财利、人与职位、原被告与裁判等各按专项角色比较。不能由“时生我”直接推出任何事都成，也不能由“我克事”直接推出一定能解决。

对每项主依据核三件事：是否同一结果与阶段；条文前提是否齐全；相反依据是否真正与它冲突。来自另一个结果的阻力应独立保留，不一概抵消。未知条件不默认成立。

**本步产物：** 对各结果说明谁支持、谁制约、哪项条件决定进退，而非吉凶票数。

## 五、综合权衡、收敛取象与定应期

### 先回看全局，再给分项主判

将宫内结论与宫间关系放回第一步盘势，明确初判保持还是修正，并解释原因。一般判断可为偏有利、偏不利、条件成立后可成或该项未判。条件足够时直接给主判，不用无关套话回避；多个结果不强行压成一个“总体一般”。

没有统一星门权重、凶格票数或任意同宫五行通关。金融方向遵循其已登记F01—F10规则，不能在此临时换成普通日时生克口诀。

### 取象服务于已固定的对象和结论

星门神性质在前四步已经参与；本步把少量相关象义收敛为人物状态、器物、流程或具体表现，见[取象规范](取象规范.md)。说清哪些为盘面、哪些为传统义、哪些为现实类比，避免遍取九宫编故事。

### 应期先定事件和单位，再选规则

明确问的是开始转动、解除阻碍、签署、回款还是结束；一般状态、期限结果和精确日时分别回答。按[空墓与应期](空墓与应期.md)核所选事类的填冲、墓、马、庚格或数法，再生成日期候选。

“病药”可用于解释与所问阶段有关的阻力及触发条件，但并非所有应期都必须先找四害，也不是一冲墓就保证成事。宫数没有事前确定的数系、对象和单位时不换算日期；庚格不推广到所有工作、婚姻或行情问题。

**本步产物：** 结果、主要依据、相反依据、成立条件、具体表现及有依据的时间窗口；没有精确应期不妨碍已有的状态或期限判断。

## 六、运筹建议与留档

按[运筹与建议](运筹与建议.md)把判断接到可调整的行动：先做什么、找谁核实、如何安排流程、适合主动推进还是暂守，以及有明确依据的方位和时间。每条建议对应前面发现的一个条件，不追加脱离盘面的泛泛清单。

另做择时要先列候选行动时间、主体和现实限制，按同一方法比较；行动盘与原问事盘分别保存。属相、吉门名或一条相生关系不单独替代完整人选或择时判断。

按[记录与复核](记录与复核.md)保存原题、当时信息、盘、方法、角色、依据与结果；金融用专用记录。事后反馈另存，不能补写事前命中。交付前核对首句、正文和末尾的对象、期限及主判一致。

## 回答组织示例

默认先用一两句回答主问，再给大势、关键宫与关系、取象和时间，最后给最有用的行动建议。详细解盘可展示六步；只问某个结构时回答该结构并交代相关条件，不强迫重复整套流程。
