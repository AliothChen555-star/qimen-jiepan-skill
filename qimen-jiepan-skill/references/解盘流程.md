# 解盘流程

**整体 → 宫内 → 回归整体 → 最后细节取象**是用户指定的分析顺序，不声称是某古籍的一套固定程序。术理使用 [格局分析](格局分析.md) 中已有出处及已选定口径；不用自创权重把原法改造成五行连锁算法。

## 准备：固定问事与方法

核对原盘的取时、时间模式、四柱、遁局、旬首、符使、空马与寄宫。固定主体、对象、期限及所求结果，沿用原盘。

查本事类取用：金融读 [金融解盘](金融解盘.md)，其他读 [用神与象义](用神与象义.md)。先约定取法，实际取用随第一步全局核对落点。不因看到吉凶更换用神；不借取用提前选行业。

按“实际盘面 → 采用的原文规则或明示约定 → 本问判断”保留依据。原文未核实、异文未定或条件不足，准确指出缺口，不自行补规则。

## 一、整体看势

先看全盘，再看与本问有关的主线：

- **月令与符使：** 值符星、值使门是什么，其本义与吉凶如何，落宫、得令及迫刑空墓怎样。八神值符与值符星分清。
- **全局结构：** 分别核星、门、奇仪的整体反伏吟，核五不遇时等已支持规则，检查重要吉凶格的分布与完整条件。
- **核心取用：** 固定主体、所问事项及必要辅助用神的盘层、落宫；把所在宫的星门神与天地干格放回全局看。
- **宫间关系：** 按本事类原法比较核心用神所在宫的生克、比和、同宫等关系。说明比较的是谁，不能把门土与戊土比和写成两个落宫比和。
- **相关性：** 不数八宫吉凶多少，不拿无关吉宫替代所问主体，也不让无关凶宫替代全部判断。

此步形成大势初判：整体偏顺还是偏逆，主要风险或助力落在哪里，哪些条件须进宫核实。星性、门性、神性和已成立格局从此步就参与判断，不等到取象时才出现。

## 二、宫内详查

每个核心宫核一次；主寄、同宫多角色分别交代，不能虚造第二落点。

| 必须读到的内容 | 核验要求 |
|---|---|
| 九星 | 先保留该星本义、吉凶和本事类用途，再核所选星法的旺衰、落宫及限制；不能只写“土星有力”而漏掉天芮病性 |
| 天盘、地盘干 | 写明实际主寄和“天 X 加地 Y”；查该有向干格原断，连同门星、主客等条件一起读 |
| 八门 | 保留门性、吉凶和事类宜忌，再核得令、门迫、宫制等；生门不是保证获利的标签 |
| 八神 | 保留原有性质与条件；白虎的杀伤、腾蛇的虚耗惊疑等不能改写成中性“执行力、灵活性” |
| 宫与相关条件 | 核宫卦、所用原法中的生克、空墓刑迫等；区别结构成立与对本问的具体影响 |

格局的原断不是可有可无的备注。例如壬加辛，按 MJ-2 先读“螣蛇相缠”及吉门亦难安的限制；不能先据地金生天水判支持，再把凶格附在末尾。条文本来有缓解或主客例外的，核实该条件后使用；条文没有的，不自造消解路径。

不用同宫“星克干、门生干”拼一条通关路线，也不设“四盘分别负责外在／基底／行动／助阻”的固定解释。专门断法若确有跨层比较，必须查明对应原文、对象和条件，不能推广为全宫通则。

每宫说明：这个核心角色当前是什么性质和状态；哪些原断有利、哪些不利；具体修正了整体初判的哪一部分。此时不把行业匹配当作上涨、成功或获利证据。

## 三、回归整体定结论

将宫内结果放回月令、符使、全局结构及核心宫间关系，回答原问题。

综合遵循所用原法的具体条件，不另设“宫内生克最大”“某星永远压过门”“凶格无条件否决全局”等统一排名。出现矛盾，核对它们是否属于同一对象、同一事项、同一阶段；再按条文适用范围作结，不以相生一笔抵消凶象。

给出当前主判和主要依据。证据指向不利就明确说不利，不以“没有绝对把握”改成机会判断；有局部助力则限定其范围，不能把局部动象或一次修复升级为整段向好。确实缺乏关键依据时，只限定不能判断的具体部分，不编逐日路线或量化权重。

主势不支持所求行动，可以到此结束；不为满足推荐名单而继续搜吉象。

## 四、最后细节取象

这里才把已经判明的势细化到人物、行业、业务、器物或情节。先核实际对象，再用相应卦象和星门干神收敛候选；归属描述与吉凶判断分开。

**性质参与定势，具体对应后置。** 天芮的病损、白虎的伤害、生门的生发从前三步就要读；医疗器械、某种机械、某只基金等具体对应属于末端细节。不能用后者推翻前者。

现代行业没有古籍规定的唯一归宫。对应不唯一就保留候选，不从基金名称、代码或已知涨跌倒找象义。

## 交付核对

- 整体初判、宫内详查、回归整体是否都实际完成？星门神及干格原断是否被读到？
- 生克方向、主寄、旺衰口径、条文例外是否一致？有没有临时换来源来趋吉避凶？
- 是否把现代类比、日历候选或工具关系字段误当成传统断语？
- 结论是否回答原问题，并与事前原判断、事后补读分清？

需应期时另读 [空墓与应期](空墓与应期.md)，先有本事类规则再定时间，不把日历匹配直接当应验。
