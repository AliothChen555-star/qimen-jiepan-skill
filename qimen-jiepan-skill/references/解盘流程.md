# 解盘流程

本流程的输出顺序固定：全盘分析 → 取用神 → 用神宫位关系 → 用神宫内四盘细析与宫内结论 → 合并分析 → 最终结论。准备时可以明确问句，但不得提前挑用神、先报断语，再倒着补依据。

## 准备：固定盘面和问题

按 SKILL.md 取得已有完整盘面或内置 JSON，沿用第一次成功起盘的取时。核对时间模式、盘式、阴阳遁、元局、旬首、值符值使、旬空、马星及寄宫。问句只说明“谁、何事、现状或未来、范围、已知期限”；缺少非关键背景时声明最小假设继续。

依据链使用“盘面事实 → 规则/象义 → 判断”。例如“景门在离九”为字段，“景门取公开表现”为取法，“外在形象较显露”为推断。三者可以在一句话内写清，不需要重复解释它们的区别。格局成立写明天/地盘方向、干或门星神、所在宫及条件；未满足条件就不套名称。

## 一、全盘分析：先得到共同背景

不指定本人、事项用神，先扫描整个盘。外八宫每宫至少核对宫五行、天干/地干、星、门、神、空马、刑墓及寄干；中宫按寄宫规则处理。可在内部保留逐宫核验表，正文以总体结构和关键分布为主。

1. **时令气势。** 以月支和节令判断哪些五行得令，哪些宫、门、干受生或受制；九星旺相按所声明的专门口径，不和一般五行旺衰混算。说明强弱聚在哪些方位或宫类，不能数一数吉门就称全盘旺。
2. **符使主线。** 值符星及其宫看主导背景，值使门及其宫看主要行动通道；看两宫生克及空、迫、刑、墓，说明整盘是主导清楚、执行顺畅，还是有主导而通道受阻。八神“值符”与值符星分别标清。
3. **动静结构。** 分别核验星盘、门盘、奇仪盘是否整体伏吟或反吟。某一宫干同干仅作局部伏吟，不冒充全盘。无反伏吟时看旋转分布和马星，并保留“马在哪宫、未必作用于本问”的范围。
4. **格局分布。** 查五不遇时、逐宫干加干、门迫、六仪击刑、奇仪入墓、三奇与门神会合等实际成立的条件。统计只是识别主要结构，单宫格局不能直接定义全盘成败。
5. **全盘小结。** 用盘内依据概括动/静、快/缓、显/隐、顺/阻及主客背景；可以并存，如“星盘伏吟而门盘转动，背景守旧，行动通道仍有调整空间”。主客只在已经明确静守/主动角色及相关天地主客条件时使用，不从阴阳遁直接推主客胜负。

全盘阶段不得提前断“本人吉/凶”。此时建立的是所有人物和事项共享的背景，下一步才把它落到所问对象。

## 二、取用神：按事类定角色

读取 [用神与象义.md](用神与象义.md)。列出“角色—用神—取法理由—盘层—落宫—主辅”，只取能回答问题的角色。本人、事项、对方通常构成核心，不为了丰富文字无限加用神。

用神默认按天盘定位，地盘另作根基和承接。日干与年命明确主辅；甲按已采用的六甲遁仪规则，不把所有甲都当戊。寄干位置使用寄宫并注明原中宫。多个角色同宫时仍分别声明角色，但只做一次宫内分析。

## 三、用神宫位关系：先看互动结构

核心用神逐对比较；必要辅助用神仅比较与核心角色有关的关系。先不展开各宫内部的门星神格局。

| 关系 | 必须说明的依据 | 关系层可得的判断 |
|---|---|---|
| A 宫生 B 宫 | A/B 宫号、五行、相生方向及各自旺衰 | A 向 B 提供支持或付出；对 A 也可能是泄耗 |
| B 宫生 A 宫 | 同上，不能把方向写反 | A 受到 B 的扶助或承接 |
| A 宫克 B 宫 | 谁克谁、强弱是否足以发挥 | A 对 B 有约束、推进或压力；不是自动获胜 |
| B 宫克 A 宫 | 同上 | A 承受 B 的压力或限制；需看后续通道与条件 |
| 比和 | 两宫同五行但不同宫 | 同频、并行或竞争，按事类解释 |
| 同宫 | 哪些角色共同落入一宫 | 事情与人物牵连、同一环境；不自动等于和合或成功 |
| 对宫 | 坎离、坤艮、震兑、巽乾 | 对峙、两端拉扯或变动，须与五行关系分别解释 |

同一对宫可同时成立相生/相克和对宫关系，例如坎离既是对宫，也有水克火；两个层次不能相互替代。干合单列为天干层的牵连，不能称宫合；六合神也不能替代宫位关系。不把宫中两个地支任取一个编成六合、三合、刑害。

本步先给关系小结，例如“事项宫生本人宫，承接方向有利；两宫同为得令之气，支持具备力度”。这仍是关系层的判断，尚未说明事项能否执行或落地。

## 四、用神宫内四盘细析：每宫必须合并

读取 [格局分析.md](格局分析.md)。对每个不重复的核心用神宫按下表分析；辅助宫只展开会改变结论的部分。

| 层次 | 核对内容 | 回答的具体问题 |
|---|---|---|
| 天盘 | 九星的五行、时令状态、落宫生克；天盘主干与寄干，干的墓刑及取象 | 外在走势、所呈现的能力/状态、事情怎样发展 |
| 地盘 | 宫卦、方位、五行和时令；地盘主干/中宫寄干，各自状态 | 基底条件、原有状态、承接环境与落地条件 |
| 天地叠加 | 天盘干加地盘干的有向组合、五合、生克、局部伏吟及命名格局；多干逐对核验并区分主寄 | 表层怎样作用于基底，哪种格局成立，适合主动还是静守 |
| 人盘 | 八门五行和时令、门宫生克、门迫/受制、与奇仪及星神的配合 | 行动通道是开放、闭藏、争竞、表现还是收束；执行有何阻力 |
| 神盘 | 八神取象、与其他三层一致或相反之处 | 助力/阻力以公开、隐蔽、合作、急烈、疑虑等何种方式出现 |
| 修正 | 空亡、驿马、刑墓、门迫、寄宫及复合格局的限制 | 上述条件现在能发挥多少，何时或在何条件下转实/松动 |

不能只列“某星吉、某门凶、某神凶”。每层都说明本宫字段、规则和对应问事的作用；不相关的象义不堆入正文。地盘干是静态根基，其入墓定位或受制不能无条件等同天盘用神陷墓。

多干宫：主天干×主地干先分析；寄天干×主地干、主天干×寄地干及寄×寄依实际字段列出，只展开与用神及关键格局有关的组合。中宫展示的天干不作为又一个独立的天盘落点。某组合来自寄干必须明说；不能把所有组合当成多份独立证据。

每宫结束用两三句得到 **宫内结论**，合并以下内容：

- 地盘能承接什么，天盘呈现什么走势。
- 人盘有没有执行通道，神盘以何种方式助阻。
- 刑墓、空马、迫及复合格局如何加强、限制或改变这个判断。
- 本宫对应角色的状态与可能取象；同宫多个角色分别解释其作用，共享一份宫内证据。

例如：“此宫底层能承接，表层有开展意向；开门通道尚在，但门受宫制、用神逢空，故偏向先有接洽而后实质落实。若出空且门制缓解，原有有利格局才更容易发挥。”示例只演示合并方法，实际解盘须换成当前盘的真实组合。

## 五、合并分析：解释结构而非计票

综合时明确接回三个来源：**全盘背景 + 用神宫位关系 + 各宫结论**。

1. 全盘定气候和节奏，不无条件抹掉局部通道。整体伏吟而局部有吉格，常形成“有条件、有助力，但推进偏缓”。
2. 关系定作用方向，宫内条件定作用方式与兑现能力。相生但空、墓、迫，可以有意向而暂难承接；相克但有制化、通道及助力，可以是竞争压力而非必败。
3. 比较矛盾时说清哪个层次发生矛盾，以及对本问哪一层更直接；事项执行通常看相关门和格局，人物状态看人物用神，落地看承接、空墓等，不设“所有问题永远星先于门”的硬排名。
4. 命名吉格与凶格可以同宫成立，如三奇得使与青龙逃走并见。解释交集与限制，不任选一个名称，也不把三条同源格局当三票。
5. 区分“有气势、肯投入、有行动、能落地”。局部吉象只支持它对应的一层，不自动推出最终成功；局部凶象也只限制相应机制，不自动推出整体失败。

建议在内部给依据简短编号（全、关、宫）；正文可自然引用，无需写成技术报告。合并段应能具体回答：“为什么这些局部结论经由这种宫位关系，在这一全盘背景下，得到这一大势？”

## 六、最终结论：大势、条件、取象

直接回答所问，依次写主要趋势、关键矛盾或转折条件、最相关的可能取象。取象围绕题目，例如风评中的“被看见、评价两极、先议论后定调”，不扩写未问的健康、财务、家庭故事。

可以用条件表达限定判断，不必另起“现实误差/免责声明/不确定性”段落，不固定附“仅供参考”。只有盘面字段或相关格局尚不能核验时，局部说明缺项；高风险行动仅按 SKILL.md 保留必要一句。

现状问题不强定应期。未来事件若需应期，必须说明触发的用神/门/值使、地支及冲空、填实、出空、合冲或马星机制；干支日转公历先核验日历。没有依据则止于大势和条件，不编精确日期。

## 输出骨架与自查

输出：取时与规则一行；①全盘大势及依据；②取用理由与定位；③宫位关系及关系小结；④各用神宫的四盘、天地格局及宫内结论；⑤三层整合依据；⑥最终趋势、条件和取象。

交付前检查：

- 是否真的先全盘后取用，最后才定结论？六步各自有没有依据？
- 是完整扫描后提炼全盘，还是把一个局部宫冒充全盘？
- 用神角色、主辅、盘层、寄干是否清楚？有没有看吉凶后改取用？
- 宫生克、对宫、干合是否区分？生克方向与旺衰是否正确？
- 每个核心宫是否涵盖四盘、天干加地干和宫内合并结论？
- 格局有没有列条件？门迫、宫克门、局部伏吟、整体反伏吟、格名入墓和落宫入墓是否区分？
- 合并有没有同时用到全盘、关系及宫内结论，有没有重复计证或只报吉凶数？
- 最终结论是否有对应依据，取象是否相关，是否出现过量现实提醒或强凑反证？
