# 解盘流程

顺序固定：全盘 → 取用 → 宫位关系 → 宫内四盘 → 合并 → 结论。每步产物供后一步使用，规则定义只在对应专题维护。

## 准备：固定问题和原盘

核对取时、时间模式、四柱、遁局、旬首、符使、空马与寄宫。沿用已选定原盘。

明确主体、是否代问、问题范围、期限及已知行动状态。再写清“本问要判断的结果”。换工作整体走势可分机会、接洽、落实；辞职获批则以能否离开为目标。用户已明确的目标直接沿用。

非关键背景可作最小假设。只有对象或方法无法合理确定时才补问。此阶段不定位用神。

依据使用“盘面字段 → 规则 → 判断”。复用同一条规则时引用其作用，不重复抄定义。

## 一、全盘分析

扫描外八宫及中宫寄宫信息，正文提炼共同背景。

- 时令：说明得令五行和主要强弱分布。星法与一般门干宫旺衰分列。
- 符使：说明值符星及值使门所在宫的状态。八神值符单列身份。
- 动静：分别核验星、门、奇仪的整体反伏吟。局部同干只作局部组合。
- 格局分布：提取会影响节奏、通道或主导条件的结构。单宫现象保留所在范围。
- 空马：记录实际支和宫位。尚未取用时不预判其与本问有关。

产物是全盘动静、显隐、顺阻的背景判断。此时不判本人得失。阴阳遁不直接决定吉凶。

## 二、取用神

读取 [用神与象义](用神与象义.md)，按问题目标选定角色。列出角色、用神、取法、盘层、落宫和主辅。

需要主客法时读取 [主客取法](主客取法.md)。先固定方法及现实中的主动、等待关系，再落盘。普通状态问题可以只用角色宫位法。

一个符号同时涉及多个角色时保留这种牵连。不能另造第二个落点。角色信息不足时缩小能判断的范围，不按吉凶更换用神。

## 三、用神宫位关系

比较核心角色之间的宫位。辅助角色只比较与问题相关的连接。

| 关系 | 要说明的内容 |
|---|---|
| A 生 B | 相生方向；谁提供支持、谁可能付出；强弱能否支持这种作用 |
| A 克 B | 约束方向及力度；它对所求结果是推进、阻碍还是分离条件 |
| 比和 | 同五行、不同宫；按事类解释协同或竞争 |
| 同宫 | 共同环境或牵连；角色仍分别成立 |
| 对宫 | 坎离、坤艮、震兑、巽乾的两端关系；另列五行生克 |

天干合是干层，六合神是神层，均不称宫合。不能从双支宫任挑一个支拼出有利合冲。

本步形成关系初判。相生说明作用方向，不先保证目标达成。天地盘主客法双方同宫时，此步记同宫，上下盘细节留第四步。

## 四、宫内四盘与格局

读取 [格局分析](格局分析.md)。每个不重复的核心宫分析一次；辅助宫展开会改变判断的部分。

| 层次 | 内容 |
|---|---|
| 天盘 | 星及主、寄天干；月令、宫生克和已采用的刑墓状态 |
| 地盘 | 宫卦五行、主寄地干及状态；主客法所需的本位星 |
| 天地叠加 | 实际有向组合；格局成立、适用领域和例外条件 |
| 人盘 | 门的月令、宫生克、迫制及星门墓 |
| 神盘 | 神的助阻方式及与其他层的配合 |
| 发挥条件 | 空墓等限制影响哪个角色、哪一种作用；有无明确解除条件 |

四盘对应外在、基底、行动和助阻方式，是默认解释角度。具体符号在本问中的角色由第二步确定，不用这组角度替代分事取用。

主天干×主地干先分析。与用神相关的寄干组合随后展开。中宫展示不另算一个天盘落点。多种格局来自同一组合时共同解释，不计多票。

先核验条件，再解释用途。表名中的“入墓、太阴、玄武、伏吟”等不替代实际墓位、神盘或整体动静。

每宫结论说明对应角色的状态、可用通道、主要限制及可能取象。需要解释空墓发挥时读 [空墓与应期](空墓与应期.md)。

## 五、合并分析

从问题目标出发，接回全盘背景、第三步关系及各宫结论。

先确定哪项证据直接作用于所求结果，再说明其他证据怎样助成、限制或改变它。人物意向、行动通道、资源条件、最终落实分别判断。

关系相生而接收方受空墓限制，可表现为有意而暂难兑现。去留问题中，相生也可表现为挽留。只有接回目标，才能判断这些作用是否有利。

用“主因—作用方式—限制—转折条件”解释矛盾。采用规则已有明确例外时先处理该例外。没有通用的星、门、干、神固定吉凶排名。

同宫多角色、主寄组合及同一次星干转动均检查同源关系。不同层可以互相印证，不把同一机制反复累计。

## 六、最终结论

直接回答主要趋势、关键条件和最相关取象。每项结论能回到前面已经分析的依据。

未来问题需要应期时，先判可能发生的阶段，再按 [空墓与应期](空墓与应期.md) 选择时间单位和候选触发。时点不够明确时给条件或窗口。

## 交付前核对

- 问题目标、角色、方法是否前后一致？
- 全盘、关系及宫内结论是否都进入综合？
- 天地方向、主寄、旺衰口径及格局例外是否正确？
- 取象是否只回答本问？关键结论是否有盘面依据？
