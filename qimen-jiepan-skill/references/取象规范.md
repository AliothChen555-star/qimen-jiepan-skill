# 取象规范

取象用于解释已经定位的对象和性质，不能创造事实或替代成败依据。星门神的性质在分析中读取，人物、行业、器物和具体情节在相关条件核清后收敛。

## 执行方法

1. 从原问题限定领域与实际对象。人物状态、合同内容、店铺经营、市场价格各自取象。
2. 只从已绑定用神和必要相关宫起步。优先解释该对象的功能、状态及环境，不遍取八宫编故事。
3. 读取原有性质和本事类用途，再组合成少量可能表现；不把凶性全部中性化，也不脱离事类一概判坏。
4. 每个具体解释写出可以核实的事实与能区分备选的条件。没有依据时不猜性别、外貌、隐私、金额或确切数量。
5. 将来自同一结构的多个叫法合并。行业像、名称像、宫数像不增加成败证据。

| 层次 | 记录内容 | 例子 |
|---|---|---|
| 盘面事实 | 实际符号、主寄、层次、位置 | 某已绑定角色同宫见玄武 |
| 传统义 | 选定原文的性质、用途和条件 | 玄武相关的暗昧、隐情等义 |
| 现代类比 | 可能对应的现实检查方向 | 信息披露、口径或条款是否完整 |
| 现实事实 | 用户已述或独立核实的信息 | 已查到某条款，或仍未知 |

玄武不能单独证明欺骗已发生；白虎不能单独证明伤病；天芮的病损和师学等用途按事类读，不能因为医疗或教育行业贴合就判吉；九天不证明上涨，九地不证明安全。格名含“入墓”与某干实际落墓宫也不同。

工作压力可用惊门的惊扰、伤门的损伤等传统义提出“任务催促、争议、返工”等待核假说，但不能据此宣称领导正在针对、同事已经陷害，或诊断心理疾病。哪一种情节成立要以现实信息核实。

不把宫数直接换算为几天、几月、金额、人数或收益率；有专门数法须先明确其原文、对象和单位。事后知道的情节另记补读，不补成先前预测。
