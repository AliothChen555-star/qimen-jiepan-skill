# 规则来源索引

本技能的来源登记和核读范围见[来源登记](来源登记.md)，逐条几何、完整条件、例外和核读状态见[规则卡](规则卡.md)及[机器规则资料](../assets/rules.json)。这里不重复维护另一套出处表。

实际方法先按[方法配置](方法配置.md)冻结，再使用[事类方法](事类方法.md)中适用部分。不同电子版本和转抄不是独立证据；作者题署、目录、宣传摘要不能代替规则正文。只核某段不称通读全书。

新规则须有原文位置、真实比较对象、成立条件、用途及例外。补查未收录干对时先按已登记来源，新增核读记录与当前判断一同保存；查不到不靠模型记忆或一般五行方向补写。不同版本的解释分开，不能临时择吉。

版本迁移记录放在仓库变更说明，不进入通用断法。出处可追溯、程序回归、模型行为和真实效验分别核验，见[评估方法](评估方法.md)。
