# 运筹与建议

六步流程的最后一步，把已经形成的判断转成用户能实施的选择。先给主判和应期，再给与具体条件对应的建议；不把一般常识包装成盘面直接计算出的结果。

## 从条件到动作

| 前面已经识别的条件 | 可提出的行动方向 | 回答时说明 |
|---|---|---|
| 执行通道受阻、流程反复 | 先处理卡点、缩小一次推进范围、预留复核节点 | 卡点是盘象推断还是已知事实，哪一步会受影响 |
| 关键角色有支持但落实条件未齐 | 明确谁有权限、先确认承诺或资源 | 支持与签署、拨款、交付不是同一阶段 |
| 用事宜守或主动有不利条件 | 比较等待、调整顺序或主动推进的可选方案 | 谁是主客及每种方案对应的条件 |
| 窗口或方位有可核的有利组合 | 在可行范围内建议时间、方向或会面位置 | 具体盘、主体、方向参照点、适用事项与限制 |
| 财本、收益或产品表现出现差异 | 分别说明资金投入、经营收益与价格情景 | 使用的产品和收益口径，不由一个吉门换算持仓比例 |

每条建议应能回答“依据哪项判断、改变哪个条件、何时观察是否落实”。通常只保留最影响主问的几条，不按六步标题机械生成六条建议。

## 另做择时择方

1. 明确要做的动作、执行人、地点或方向参照、允许调整的时间段以及不可变的现实限制。
2. 在看盘前固定排法、取用、可比较候选和选择条件。需要排候选行动盘时，按[起盘程序](起盘程序.md)保存为不同记录。
3. 按事项核符使、主体、门星奇仪、旺衰、刑空墓迫与主客；三奇得使、玉女守门等须满足所选规则卡条件，不只凭格名推荐。
4. 比较候选的适合之处和代价，说明何时需要重新检查。原问事盘继续保存，行动时间变更不改写原预测。

MJ-P凡例有按事项选门与旺衰配合的依据；本文件的候选比较与留档顺序属于现代操作约定，不声称古籍规定同一套流程。

## 合作对象与取象

如采用有来源的年命匹配法，先核实际候选人的年命和在本题中的角色，再结合主体、任务和关系条件分析。不单凭生肖、出生年、某一吉门或相生，就断定一个人可靠或必能成事。

取象转成工作建议时，允许把惊扰、文书反复等归纳为需要核实的流程点；用户已知的事实与盘象候选分开。涉及医疗、法律或金融的现实操作，不能把符号类比冒充已核事实或专业程序。

## 输出与复核

给出“推荐动作—对应条件—观察节点”。有明确方向就直接说；缺方位或候选时间时只限定该项，不要求整次占问停止。简短问答无需附固定劝退段落，也不让用户反复确认信念或风险接受。
