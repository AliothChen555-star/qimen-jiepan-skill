# 格局分析

先按原文读性质、格局与完整条件，再依本问综合；不把四盘压缩成五行相生相克。分析顺序见 [解盘流程](解盘流程.md)，来源编号见 [规则与出处](规则与出处.md)。

目录：四盘与本义；符使与大势；旺衰和十二长生；反伏吟；迫刑墓；天地干格及例外；复合格；工具边界。

## 四盘与本义

天盘为九星及随星转动的奇仪，地盘为宫卦和原布奇仪，人盘为八门，神盘为八神。地盘本位星只供明确采用的相关原法使用，不另转一套盘。

以下是已核原文的简要摘义，不是完整事类断语。**本义、吉凶和分事用途在整体定势时就要参与，不能等到行业取象才读。** 生克、旺衰不能代替它们。

### 九星

分类据 TZ-1 总赋，所主参考 TZ-1、YY-3；病神用法另据 ZG-9。

| 星 | 原有分类 | 本义与分事要点 |
|---|---|---|
| 天辅 | 上吉 | 设教、修道、文教与谋事；具体吉凶仍核时令等条件 |
| 天禽 | 上吉 | 祭祀祈福、赏功、谋事等；寄芮不把两星合成一颗纯吉星 |
| 天心 | 上吉 | 谋事、用兵、疗病合药；医者用法有出处，不等于任何医疗资产上涨 |
| 天冲 | 次吉 | 征伐、报仇、行动；原书对商贾等另有不宜，不能见次吉就普断求财吉 |
| 天任 | 次吉 | 治民、请谒、通财等；分事宜忌不能省略 |
| 天蓬 | 大凶 | 险害、盗耗等不利性质；安边、固守等有特定用法，不直接作冒险获利星 |
| 天芮 | 大凶 | 病神、病患；兼有尊师受业之用，不能把病性改成求财利好 |
| 天英 | 小凶 | 火与文书等；献书等有用，商贾有不宜，不凭明丽就判上涨 |
| 天柱 | 小凶 | 固守、隐迹等；出行、商贾多有不宜，不只抽取表达、技术等中性类象 |

星的分类不是脱离事类的一票判决。原文对条件与轻重存在不同表述，按选定条文完整使用，不自创“凶星旺就变吉”“土旺所以芮星利好”之类规则。天芮与天禽同宫时两者都读，不以寄禽掩去芮病。

### 八门

| 门 | 原有性质及所主 |

| 休 | 吉门，休息、谒贵、接洽等；原有不宜行刑等限制 |
| 生 | 吉门，生发、谋事与财利等；不宜治丧，不能保证任何交易盈利 |
| 伤 | 凶门，损伤；捕猎、讨捕、索债等有特定用途 |
| 杜 | 闭塞、隐伏；逃藏、捕盗等有特定用途，不能泛改为项目顺利 |
| 景 | 文书、显露；上书献策等有用，不作普遍财利吉门 |
| 死 | 凶门，死丧、闭塞；埋葬、刑决等有特定用途 |

### 八神

参照 TZ-1 类神，具体条件可对读 FQ-3 八神吉凶主断；不另引神五行连锁算法。

| 神 | 必须保留的性质 |
|---|---|
| 值符 | 尊贵、统领与吉助；有原文限制，不能据此宣布同宫凶格全部消除 |
| 腾蛇 | 虚耗、惊疑、缠绕、怪异，保留不利底色；不只写灵活、变化 |
| 太阴 | 阴佑、隐匿；阴私等须结合原有条件，不一概作贵人助成 |
| 六合 | 和合、交易、婚姻与媒介；有和象不保证事情成功 |
| 白虎 | 杀伐、伤病、争讼、道路等凶性；不只改写成勇猛执行 |
| 玄武 | 暗昧、盗失、欺诈等；不能据象确认现实犯罪或内幕 |
| 九地 | 伏藏、柔静等，按事项读吉凶；不自动等于稳健、安全或底部 |
| 九天 | 刚动、显扬、远行等；有原有条件，不等于任何走势向上 |

## 符使与大势

区分三种对象：九星中的值符星、八门中的值使门、八神中的值符。符使可标记全局关键位置，但不能据此把值符固定等同所有领导或贵人，把值使固定等同审批结果。采用工作法、诉讼法或来意法时，依该法重新核其现实角色。

读星门反伏吟时分别说明层次：星回本位、门回本位、天干与地干同干不能互相替代，局部同干也不是全盘伏吟。先给动静、反复等盘势，再核本问核心宫；快慢、成败、是否适宜行动分别判断。星干同源旋转不算两条独立支持。

## 旺衰与十二长生分开

月令、落宫生克、九星专用旺相表及十二长生各自回答不同层次的问题。见[方法配置](方法配置.md)。不能把一种表中的“旺”复制到另一种，也不能把力量强直接改写成事情有利。

十二长生作为选定方法的辅助时，要先确定阳顺阴逆等排法、阴干口径、戊己土法、所看天干和具体地支。四维宫有两个地支，不随意挑一个阶段；寄干另标，不拿一个主干阶段覆盖全宫。

长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养是阶段名称。不得把“长生至帝旺全部旺、死墓绝胎全部衰”作为本技能通用评分表；沐浴、胎养等须依本题与具体表解释，不能由名称直接定吉凶。

当前内置结构工具未实现完整十二长生计算。只有核得完整来源及对应位置时才人工增补，并注明人工推读；否则保留已经可核的月令、宫位和墓项，不假称程序已经算出十二阶段。

## 刑空墓迫的读法

“四害”作为空亡、入墓、击刑、门迫的常用归纳，不设置一项即否决的机制。空先核具体旬与支位、墓先核对象和层次、刑先核严格旬首或扩展法、迫先核确实为门克宫。宫克门另称受制，不互换。

这些结构可以提出未落实、受困、冲突、损耗等解释方向，但具体落义须回到事类与原文。看到空亡不能直接断某人说谎，看到击刑不能直接认定现实伤病或刑罚；同样不能只用一句“冲开即吉”抹去其他不利条件。

## 结构核验的读取次序

完整配置见[方法配置](方法配置.md)，单条来源、几何、限制及例外统一见[规则卡](规则卡.md)与[来源登记](来源登记.md)。`assets/rules.json`是维护规则条件的唯一资料源，不在此另抄一版格局表。

1. 分层核星、门、奇仪全部本位或全部对宫；单干同干只作局部伏吟。星干同源转动不重复计证据。
2. 门克宫为迫，宫克门为受制；生门为吉名不证明门宫条件无损。
3. 击刑输出扩展几何与本旬标记；严格法再筛本旬。奇仪墓、星门墓、天地层次与原时柱入墓分开，已核三奇子集不能认证全干墓表。
4. 每个实际天X加地Y核主寄和方向，读取原义及完整限制。五合、同干、生克另记，不能代替克应；格名含太阴、入墓不证明另一层实际字段。
5. 九遁等复合格先看几何，再看条件状态。工具 `eligibility` 分开传统解释、有利取用、事件适用和主客例外；未知不当成立。
6. 再按事类核各对象之间指定关系。原文主客例外先有身份和来源，不能为了用吉临时改主客或择异文。

工具 `rule_matches` 是来源明确的匹配与待核条件，不是自动断语。`stem_pairs` 中旧式命名及条件是兼容结构字段，详细适用以规则卡和本次记录为准；同一匹配在多个字段出现仍只是一条结构。

力量、喜忌和结果分开。保留凶义，也保留相反吉义与分事例外；没有统一星门权重、凶格无条件否决或任意同宫生克通关。综合步骤见[解盘流程](解盘流程.md)，细节对应见[取象规范](取象规范.md)。
