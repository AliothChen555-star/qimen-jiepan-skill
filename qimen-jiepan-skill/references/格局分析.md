# 格局分析

本参考把“格局成立”与“在本问中怎样发挥”分开。先列实际字段及成立条件，再看事类、月令、宫位、门星神、空刑墓迫，最后纳入宫内结论和全盘。吉格不直接保证结果，凶格也不直接定义任何问事的结局。

目录：四盘与生克；旺衰；反伏吟；门迫、刑墓、空马；天地干加干；复合吉格；全盘与主客；程序核验及来源。

## 四盘与有向关系

- 天盘：九星及随星转动的三奇六仪。地盘：九宫、卦、五行及原布三奇六仪。人盘：八门。神盘：八神。
- “X 加 Y”固定指 **天盘 X 加地盘 Y**。乙加辛与辛加乙是两个有向组合；不能倒读，也不能把不同宫两干称干加干。
- 地盘没有另转一套八门八神；需要分析的是地盘基底、地盘干本身状态，以及天盘落到其上的格局。不得凭空补地盘星门神。
- 一般五行生克：木生火、火生土、土生金、金生水、水生木；木克土、土克水、水克火、火克金、金克木。
- 宫对干/门/星与干/门/星对宫是相反方向。分别解释“得宫生、比和、泄于宫、克宫、被宫克”，不能统称受克。

| 五行 | 干 | 门 | 星 | 宫 |
|---|---|---|---|---|
| 木 | 甲乙 | 伤杜 | 天冲天辅 | 震三巽四 |
| 火 | 丙丁 | 景 | 天英 | 离九 |
| 土 | 戊己 | 生死 | 天任天芮天禽 | 坤二艮八中五 |
| 金 | 庚辛 | 开惊 | 天心天柱 | 乾六兑七 |
| 水 | 壬癸 | 休 | 天蓬 | 坎一 |

八神主要取助阻的方式：值符主主导/权威，腾蛇主缠绕/虚惊，太阴主细密/隐蔽，六合主协作/牵连，白虎主急烈/冲突，玄武主隐情/暗流，九地主沉稳/伏藏，九天主扩展/显扬。神的名称不能单独当成现实行为证据，也不用神的任意五行替代已声明的门星干生克。

## 月令与旺衰口径

本技能默认月支五行：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。它是本技能的节月简化口径；如用户指定土旺十八日等细分法，另行声明，不能混算。

宫、门、奇仪一般五行：与月同类为旺，月生我为相，我生月为休，我克月为囚，月克我为死。既看得时，也看落宫受生/克，不用“月旺”替代所有状态。

九星默认采用《奇门遁甲统宗》“九星旺相”的专门规则：**星生月为旺、同类为相、月生星为死、月克星为囚、星克月为废**。例如水星在木月旺、水月相、金月死、土月囚、火月废。这套称谓不能套在门、干、宫上。《遁甲演义》对部分衰态称谓有异文，若改用该本须明说，不在同一盘中悄悄切换。

旺衰只表示该层力量，不等于固定吉凶。得令的惊门可放大交涉声势，也可放大口舌；衰弱凶星未必有力，衰弱吉星也未必能扶助。

## 伏吟与反吟：分层、分整体与局部

本位：坎一蓬休、坤二芮死、震三冲伤、巽四辅杜、乾六心开、兑七柱惊、艮八任生、离九英景。天禽原中五按本盘寄坤二，不作为独立外宫。

对宫：一九、二八、三七、四六。

| 类型 | 成立条件 | 取象范围 |
|---|---|---|
| 星伏吟 | 所有外宫星回本位，天禽按寄宫同步核对 | 背景重复、守旧、内积、发展缓慢；静守题未必不利 |
| 星反吟 | 所有星到本位对宫，天禽按寄宫核对 | 背景翻转、往复、动荡、调整 |
| 门伏吟/反吟 | 全部八门分别回本位/到本位对宫 | 行动通道停留/反复变化，可与星盘状态不同 |
| 奇仪盘伏吟/反吟 | 外宫天干与其地盘原落宫（含寄干）全部同位/全部对位 | 表层与基底重叠/翻转；必须有实际逐干位置依据 |
| 局部干伏吟 | 本宫某一天干等于某一地干 | 仅该组合重复、自缠；不能声称星门或全盘伏吟 |

转盘中的“旋转半圈”不应只按宫号加四判断，必须用上述对宫映射。某星或门恰好在本位/对位，其他未满足，只说明局部，不能称整体反伏吟。

## 门迫、受制、击刑、入墓与空马

### 门与宫

**门克宫才是门迫；宫克门是门受制。** 宫生门为通道得助，门生宫为通道泄气，比和为同气。

门迫核验：开/惊金门临震三、巽四；休水门临离九；生/死土门临坎一；伤/杜木门临坤二、艮八；景火门临乾六、兑七。以五行条件为准，不把古籍个别省列当作排除同类宫。吉门迫，作用易受阻或成本增加；凶门迫，冲突或破坏之象可加强；仍须接回事类。

### 六仪击刑

本技能默认逐个**天盘六仪**核验的扩展口径，并标注是否为本旬旬首遁仪。古籍主要以六甲值符加刑地论；用户指定严格旬首法时，只将本旬遁仪符合者正式称击刑，其他列“扩展法宫刑”，不要混口径。

| 天盘仪（所遁六甲） | 刑支 | 落宫 |
|---|---|---|
| 戊（甲子） | 卯 | 震三 |
| 己（甲戌） | 未 | 坤二 |
| 庚（甲申） | 寅 | 艮八 |
| 辛（甲午） | 午 | 离九 |
| 壬（甲辰） | 辰 | 巽四 |
| 癸（甲寅） | 巳 | 巽四 |

寄天干同样核验，但必须注明寄干。击刑可取内耗、受约束、动作不顺之象，不能直接推出刑事案件或灾祸。地盘仪本身不自动套“运动中的天盘击刑”。

### 奇仪入墓

采用奇门常用墓宫口径：**乙/癸墓未在坤二；丙/戊墓戌在乾六；丁/己/庚墓丑在艮八；辛/壬墓辰在巽四。** 乙坤、丙乾、丁艮的三奇口径见《统宗》“奇门四十格”及《演义》三奇入墓说明；六仪墓位为本技能声明采用的常用口径，不能声称所有古本一致。

- 天盘干落对应墓宫才记“天盘某干入墓”，可取被收藏、难发挥、封存之象。
- 地盘干在墓宫记“地盘墓位”，用于底层收藏或闭塞条件，不直接等同人物天盘用神入墓，也不重复计为独立凶证。
- 当问题用到时干，可另外核验时柱干支是否为戊戌、丙戌、壬辰、癸未、丁丑、己丑等已选口径的干支入墓；这是时间层，不能替代落宫层。
- “乙加己日奇入墓”等传统**格名**不能单独证明乙实际落坤二。命名格局与按宫位核验的入墓分别记载。
- 墓不等于毫无作用；旺衰、用神角色及能否冲开要在整合时分析。没有相关支与规则，不擅言已经冲墓。

### 空亡与马星

读取本盘旬空及 `void_branches`，双支宫若只一支空保留支级信息，不强写两个支都空；具体用神宫可取虚悬、未实、缺位或暂不兑现。空并非一律没有，须与旺衰和问句整合。

马星按 `horse.basis` 与实际落宫；取动、奔波、迁移、变化。全盘可描述马星分布，事项应期只有相关用神/门/值使实际关联时才能使用。马空可取动而未定，但不能仅凭马空预告出行事故。

## 天盘干加地盘干：所有组合都要会分析

甲隐六仪，内置盘实际为乙丙丁戊己庚辛壬癸九干，形成 9×9 的 81 种有向组合。分析不以背出 81 个格名为终点：每个实际组合都要核验五行关系、五合、同干，以及双方各自的月令和墓刑状态，再接门星神。未在下列核验表中的组合直接按这些条件分析，不补造一个“古诀格名”。

逐组合顺序：

1. 明确上为天干、下为地干，主干或寄干；只解释实际存在的组合。
2. 同干则为局部干伏吟；异干看相生、泄耗、比和、上克下或下克上。天生地可取投入底层，地生天可取基础支持；上克下、下克上分别对应不同的作用方向，仍由事类决定具体象义。
3. 五合：乙庚、丙辛、丁壬、戊癸（甲己仅在甲的遁仪定位与取法明确时另议）。可取牵连、协作、合绊；**五合不自动合化**，也不自动代表爱情或成交。
4. 有核验过的格名则列其条件及传统倾向；名字里的刑、墓、反吟不替代真正的击刑、墓宫、整体反吟检查。
5. 看月令、宫生克及空刑墓迫能否让组合发挥，最后决定它在宫内结论中是主因、条件还是辅助取象。

## 复合格局：条件同时满足才命名

默认采用下列《遁甲演义》所列条件；《统宗》及其他本在若干九遁条件上不同，改用时注明。条件中的门、奇、神须在同宫；天/地干位置不能互换。

| 格局 | 本技能采用的条件 | 取象重点 |
|---|---|---|
| 天遁 | 生门 + 天丙 + 地丁 | 有通道与照应，利展开；《统宗》常见丙戊口径另列而不混用 |
| 地遁 | 开门 + 天乙 + 地己 | 建立基础、安置、经营、隐而能行 |
| 人遁 | 休门 + 天丁 + 太阴 | 私下沟通、细密筹划、和合 |
| 神遁 | 生门 + 天丙 + 九天 | 向上开展、扩大声势 |
| 鬼遁 | 杜门 + 天乙 + 九地 | 伏藏、保密、潜行筹划 |
| 风遁 | 开/休/生之一 + 天乙 + 巽四 | 顺势、流动、传播 |
| 云遁 | 开/休/生之一 + 天乙 + 地辛 | 隐蔽配合；同时可能乙辛逃走，须解释矛盾 |
| 龙遁 | 休门 + 天乙 + 坎一 | 流动中的承接、暗中筹谋 |
| 虎遁 | 休门 + 天乙 + 地辛 + 艮八 | 守势、据点、制约；乙辛组合的限制保留 |
| 三奇得使 | 天乙加地己或辛；天丙加地戊或庚；天丁加地壬或癸 | 奇遇六甲，有助发挥；乙辛、丙庚、丁癸各有相加格限制，不可只判得使吉 |
| 玉女守门 | 值使门落地盘丁所在宫 | 沟通、隐私、和合；是地丁条件，不是任意天丁遇任意门 |
| 三诈 | 吉门开/休/生 + 天奇乙/丙/丁 + 太阴/六合/九地 | 太阴为真诈、六合为休诈、九地为重诈；谋划、协作、潜行，不据名称指控欺诈 |

三奇得使中，本旬值符是否同临及有无不利相加格，是发挥条件而非另起一票。入墓、门迫、空亡等即使不取消格局的几何成立，也会限制作用，必须写入宫内结论。

三奇升殿、五假、天三门地四户等如要使用，先取得该门派的明确条件及所需字段。当前没有统一定义或没有月将等输入时，不能仅凭熟悉名称凑格局。这里不把未覆盖的所有术语逐一塞入正文“未核验”列表。

## 全盘时间格与主客

五不遇时：原时柱天干克原日柱天干，且阴阳同性，等价常用十组：甲日庚时、乙日辛时、丙日壬时、丁日癸时、戊日甲时、己日乙时、庚日丙时、辛日丁时、壬日戊时、癸日己时。应直接核验日时柱，不能把甲遁成戊后再计算，也不能把任意时干克日干都称五不遇。可取时机与主体不协调，整合时看有无局部承接条件。

主客：天盘可参客/动/后来，地盘可参主/静/原有。只有问题角色已对应主动者/静守者时才落到本人或对方。上下盘干克制方向提供主客关系的一部分，不能仅凭天盘干克地盘干或一条古代行军吉凶诀断出谁必胜。

## 程序核验与出处

`scripts/inspect_patterns.py` 只读取内置 kun2 转盘 JSON，输出可追溯的派生事实：月令口径、星/门/奇仪整体反伏吟、五不遇时、符使宫关系、每宫天地干组合及五合、生克、天盘六仪击刑、两层墓位、门迫/受制、九遁/得使/三诈/玉女守门。它不覆盖所有古籍术语、不做应期、不选用神，不替代四盘解读。

调用：`python scripts/inspect_patterns.py chart.json --output patterns.json`。外来盘式或不同中宫规则按人工方法核验，不能强套工具。

依据来源（古籍正文，2026-10-14 核对；现代人事取象与整合方法为本技能的解释约定）：

- [《遁甲演义》卷二各格、卷三反伏吟与击刑入墓等](https://zh.wikisource.org/wiki/遁甲演義)：天地相加方向、九遁、三诈、玉女守门、得使及相加格的条件与限制。
- [《奇门遁甲统宗》卷一“奇门四十格”“九星旺相”“迫”与凡例](https://zh.wikisource.org/zh-hans/奇門遁甲統宗)：星门本位、六甲遁仪、月令星法及格局须结合旺衰、事类、主客的原则。

来源并非一套完全一致的排盘与格局体系：本技能排盘仍采用 `chai_bu_v1.0.0` 拆补法，中五寄坤二、天禽随芮；不会因引用某古本格局而顺带更换其置闰、八神或中宫排法。遇异说先写采用条件，保持同盘同口径。
