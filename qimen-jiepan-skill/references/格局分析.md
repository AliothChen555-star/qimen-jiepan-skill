# 格局分析

先按原文读性质、格局与完整条件，再依本问综合；不把四盘压缩成五行相生相克。分析顺序见 [解盘流程](解盘流程.md)，来源编号见 [规则与出处](规则与出处.md)。

目录：四盘与本义；旺衰口径；反伏吟；迫刑墓；天地干格及例外；复合格；工具边界。

## 四盘与本义

天盘为九星及随星转动的奇仪，地盘为宫卦和原布奇仪，人盘为八门，神盘为八神。地盘本位星只供明确采用的相关原法使用，不另转一套盘。

以下是已核原文的简要摘义，不是完整事类断语。**本义、吉凶和分事用途在整体定势时就要参与，不能等到行业取象才读。** 生克、旺衰不能代替它们。

### 九星

分类据 TZ-1 总赋，所主参考 TZ-2、YY-3；病神用法另据 ZG-9。

| 星 | 原有分类 | 本义与分事要点 |
|---|---|---|
| 天辅 | 上吉 | 设教、修道、文教与谋事；具体吉凶仍核时令等条件 |
| 天禽 | 上吉 | 祭祀祈福、赏功、谋事等；寄芮不把两星合成一颗纯吉星 |
| 天心 | 上吉 | 谋事、用兵、疗病合药；医者用法有出处，不等于任何医疗资产上涨 |
| 天冲 | 次吉 | 征伐、报仇、行动；原书对商贾等另有不宜，不能见次吉就普断求财吉 |
| 天任 | 次吉 | 治民、请谒、通财等；分事宜忌不能省略 |
| 天蓬 | 大凶 | 险害、盗耗等不利性质；安边、固守等有特定用法，不直接作冒险获利星 |
| 天芮 | 大凶 | 病神、病患；兼有尊师受业之用，不能把病性改成求财利好 |
| 天英 | 小凶 | 火与文书等；献书等有用，商贾有不宜，不凭明丽就判上涨 |
| 天柱 | 小凶 | 固守、隐迹等；出行、商贾多有不宜，不只抽取表达、技术等中性类象 |

星的分类不是脱离事类的一票判决。原文对条件与轻重存在不同表述，按选定条文完整使用，不自创“凶星旺就变吉”“土旺所以芮星利好”之类规则。天芮与天禽同宫时两者都读，不以寄禽掩去芮病。

### 八门

依据 TZ-1、TZ-2 的执事与所主，保留原有事类宜忌：

| 门 | 原有性质及所主 |
|---|---|
| 开 | 吉门，开通、入官、谋事、交易等；受迫、失时等另核 |
| 休 | 吉门，休息、谒贵、接洽等；原有不宜行刑等限制 |
| 生 | 吉门，生发、谋事与财利等；不宜治丧，不能保证任何交易盈利 |
| 伤 | 凶门，损伤；捕猎、讨捕、索债等有特定用途 |
| 杜 | 闭塞、隐伏；逃藏、捕盗等有特定用途，不能泛改为项目顺利 |
| 景 | 文书、显露；上书献策等有用，不作普遍财利吉门 |
| 死 | 凶门，死丧、闭塞；埋葬、刑决等有特定用途 |
| 惊 | 凶门，惊恐、争讼；掩捕等有特定用途，不改写成一般活跃利好 |

### 八神

参照 TZ-2 类神，具体条件可对读 FQ-3 八神吉凶主断；不另引神五行连锁算法。

| 神 | 必须保留的性质 |
|---|---|
| 值符 | 尊贵、统领与吉助；有原文限制，不能据此宣布同宫凶格全部消除 |
| 腾蛇 | 虚耗、惊疑、缠绕、怪异，保留不利底色；不只写灵活、变化 |
| 太阴 | 阴佑、隐匿；阴私等须结合原有条件，不一概作贵人助成 |
| 六合 | 和合、交易、婚姻与媒介；有和象不保证事情成功 |
| 白虎 | 杀伐、伤病、争讼、道路等凶性；不只改写成勇猛执行 |
| 玄武 | 暗昧、盗失、欺诈等；不能据象确认现实犯罪或内幕 |
| 九地 | 伏藏、柔静等，按事项读吉凶；不自动等于稳健、安全或底部 |
| 九天 | 刚动、显扬、远行等；有原有条件，不等于任何走势向上 |

## 旺衰口径

默认节月：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。土旺十八日等细分法未启用。

表中的“我”是正在核验的五行，不是问事人。

| 我与月令关系 | 宫、门、干 | 九星默认 TZ-1 | 九星可选 YY-3 正文 |
|---|---|---|---|
| 同类 | 旺 | 相 | 旺 |
| 我生月 | 休 | 旺 | 相 |
| 月生我 | 相 | 死 | 休 |
| 月克我 | 死 | 囚 | 囚 |
| 我克月 | 囚 | 废 | 死 |

两种星法连旺、相也不同，不只是衰态异名。程序默认 `tongzong`；`yanyi_prose` 仅采用《演义》正文，不把其异文表格拼入。

月令和落宫生克分别记录。先保留星门神的性质及干格原断，再按所采用原文核其旺衰条件；得令不等于对本问有利。门干宫不随九星选项改变。《统宗》总赋、分事所主及《演义》的吉凶轻重说法有差别，不压成“旺就吉／旺就凶”的统一公式，也不按结果临时换说。

## 反伏吟

本位为一蓬休、二芮死、三冲伤、四辅杜、六心开、七柱惊、八任生、九英景。天禽中五按 kun2 寄坤二。对宫为一九、二八、三七、四六。

星、门、奇仪各自核验全部归本位为整体伏吟，全部到对宫为整体反吟。单个干同干只作局部干伏吟。

整体伏吟可取停留、重复，反吟可取翻转、往复。对求动、求静的意义不同。星和奇仪随同一次转动，分层事实不作为两份独立吉凶票。

## 门迫与受制

门克宫为门迫；宫克门为门受制。宫生门、门生宫、比和分别记录。

门迫覆盖开惊临三四、休临九、生死临一、伤杜临二八、景临六七。吉门受迫可限制通道，凶门迫宫可加强冲突，仍按事类判断。

## 墓位

工具沿用上游声明的奇仪墓表：乙癸墓未在坤二，丙戊墓戌在乾六，丁己庚墓丑在艮八，辛壬墓辰在巽四。整表尚未逐项统一核到同一原典；需要据某项作关键判断时先查对应原文。未核项只保留结构提示，不把“沿用”冒称已经核实原法。

天盘干入墓、地盘干墓位分别记录，不能自动赋予相同断义。时干入墓另按原时柱干支核验，不能用落宫墓位替代。

星门墓另用 ZG-4 五行表：

| 星门五行 | 墓支 | 宫 |
|---|---|---|
| 木 | 未 | 坤二 |
| 火 | 戌 | 乾六 |
| 土 | 辰 | 巽四 |

门星不能套阴干墓表。开门在艮八可同时有宫生、丑墓的结构；怎样影响本问，依星门墓的原有条件，不自行用一个相生取消墓位，也不直接把所有入墓解释成同一种结果。

格名含入墓不证明实际落墓宫。墓位成立后如何判断力量与解除，见 [空墓与应期](空墓与应期.md)。十二长生的其他状态未自动计算。

## 天盘干加地盘干

“X 加 Y”固定为天 X 加地 Y，不能倒读。内置九干构成 81 个有向组合。

每个实际组合核对主寄和天地顺序，读取已采用来源的格义、用途及条件。同干、五合和五行方向另列，不能替代克应原断。五合为乙庚、丙辛、丁壬、戊癸，不自动合化；甲的遁仪明确后才讨论甲己。

重点格局核验表：

| 格局 | 几何条件 |
|---|---|
| 青龙返首 | 天本旬遁仪加地丙；戊丙简法另标 |
| 飞鸟跌穴 | 天丙加地本旬遁仪；丙戊简法另标 |
| 青龙逃走／白虎猖狂 | 天乙地辛／天辛地乙 |
| 朱雀投江／腾蛇夭矫 | 天丁地癸／天癸地丁 |
| 太白入荧／荧入太白 | 天庚地丙／天丙地庚 |
| 大格、刑格、上格或小格 | 天庚分别加地癸、己、壬 |
| 伏干／飞干 | 天庚加地日干／天日干加地庚 |
| 伏宫／飞宫 | 天庚加地本旬遁仪／天本旬遁仪加地庚 |
| 岁月日時格 | 天庚加对应年、月、日、时柱干 |
| 悖格 | 天丙加对应年、月、日、时柱干 |

各柱为甲时按该具体甲柱的遁仪定位，不共用本时旬首。月格默认 ZG-4 月柱干法；YY-G 月朔干法另列，不混称。

已收录分项克应由 [pattern_readings.py](../scripts/pattern_readings.py) 维护，表名、领域、简释、条件和来源分列；壬辛、辛戊附核过的原文短句。它是选录，不是完整 81 格原文。关键条目应回查原文，简释不代替全部条件。

干表名不等于另一层条件。例如丁丁“奇入太阴”不证明神盘为太阴，己丁“朱雀入墓”不证明丁落实际墓宫。未收录克应必须查已选原典；不得以工具无条目为无凶格，更不能只用上下相生补出利好。

壬加辛按 MJ-2 为“螣蛇相缠”，吉门亦不能径作安稳；FQ-3 另名“白虎犯格”，断语有别。辛加戊按 MJ-2 为“困龙被伤”。保持各组合已采用的来源，不能为了缓解不利而临时改引异文；格名也不证明现实中已有欺骗、官司等事实。

## 格局如何发挥

核成立条件，同时读原有性质、事类用途、主客及例外。不能只保留几何或五行，删掉不利原断；也不能脱离条文范围把任何一个格名当全盘结论。

| 规则 | 采用的处理 |
|---|---|
| 回首、跌穴逢庚为本旬遁仪 | MJ-P 对其吉格取用有限制，工具保留成立并标出限制 |
| 乙辛、丙庚、丁癸得使兼不利相加 | YY-2 要再核本旬值符星同宫；工具分别记录是否满足 |
| 逃走、投江与猖狂、夭矫 | MJ-P 对主、客有不同用法；只在选定主客法后应用 |
| 空墓、迫刑 | 核实际对象及所用原文条件；不自行规定凶象受限即转吉，也不汇总凶票 |

默认不以格名作全盘最终结论。表中主客缓解条目不自动推出该角色获胜。

## 时间层与工具

五不遇时为原时干克原日干且阴阳同性。甲日辛时不成此格；不先遁甲再计算。

`inspect_patterns.py` 输出分层动静、五不遇、符使关系、逐宫干组合、分项克应、时间格、例外条件、刑墓迫制及支级触发。它不选用神，不自动确定主客或成事。

空马发挥和应期操作只在 [空墓与应期](空墓与应期.md) 定义。来源编号、版本与采用状态见 [规则与出处](规则与出处.md)。
