# 格局分析

先核验字段与成立条件，再按事类和角色判断如何发挥。全盘、用神选择、应期分别由各自专题负责。

目录：四盘；旺衰；动静；迫刑墓；天地组合；格局适用；复合格局；工具字段。

## 四盘与生克

天盘为九星及随星转动的奇仪，地盘为宫卦与原布奇仪，人盘为八门，神盘为八神。明确主客法所需的地盘星，是宫位的本位对应，不另转一套星门神。

| 五行 | 干 | 门 | 星 | 宫 |
|---|---|---|---|---|
| 木 | 甲乙 | 伤杜 | 冲辅 | 震三巽四 |
| 火 | 丙丁 | 景 | 英 | 离九 |
| 土 | 戊己 | 生死 | 任芮禽 | 坤二艮八中五 |
| 金 | 庚辛 | 开惊 | 心柱 | 乾六兑七 |
| 水 | 壬癸 | 休 | 蓬 | 坎一 |

生为木火土金水循环，克为木土水火金循环。分别核对符号对宫、宫对符号及符号彼此的方向。

八神取助阻方式：值符主导，腾蛇缠绕，太阴细密，六合协作，白虎急烈，玄武隐情，九地伏藏，九天扩展。神不单独证明现实行为。

## 旺衰口径

默认节月：寅卯木、巳午火、申酉金、亥子水、辰戌丑未土。土旺十八日等细分法未启用。

表中的“我”是正在核验的五行，不是问事人。

| 我与月令关系 | 宫、门、干 | 九星默认 TZ-1 | 九星可选 YY-3 正文 |
|---|---|---|---|
| 同类 | 旺 | 相 | 旺 |
| 我生月 | 休 | 旺 | 相 |
| 月生我 | 相 | 死 | 休 |
| 月克我 | 死 | 囚 | 囚 |
| 我克月 | 囚 | 废 | 死 |

两种星法连旺、相也不同，不只是衰态异名。程序默认 `tongzong`；`yanyi_prose` 仅采用《演义》正文，不把其异文表格拼入。

月令和落宫生克分别记录。旺衰是该层力量背景；对本问有利还是有害取决于它代表什么。门干宫不随九星选项改变。

## 反伏吟

本位为一蓬休、二芮死、三冲伤、四辅杜、六心开、七柱惊、八任生、九英景。天禽中五按 kun2 寄坤二。对宫为一九、二八、三七、四六。

星、门、奇仪各自核验全部归本位为整体伏吟，全部到对宫为整体反吟。单个干同干只作局部干伏吟。

整体伏吟可取停留、重复，反吟可取翻转、往复。对求动、求静的意义不同。星和奇仪随同一次转动，分层事实不作为两份独立吉凶票。

## 门迫与受制

门克宫为门迫；宫克门为门受制。宫生门、门生宫、比和分别记录。

门迫覆盖开惊临三四、休临九、生死临一、伤杜临二八、景临六七。吉门受迫可限制通道，凶门迫宫可加强冲突，仍按事类判断。

默认逐天盘六仪扩展法，同时标注是否为本旬遁仪。严格旬首法须同时满足本旬条件。

|---|---|---|---|
| 戊 | 甲子 | 卯 | 三 |
| 己 | 甲戌 | 未 | 二 |
| 庚 | 甲申 | 寅 | 八 |
| 辛 | 甲午 | 午 | 九 |
| 壬 | 甲辰 | 辰 | 四 |

寄天干照实际落宫核验。地盘干不自动套运动中的天盘击刑。取象为受约束、动作不畅，不能直接推出现实刑事案件。

## 墓位

奇仪采用原有常用口径：乙癸墓未在坤二，丙戊墓戌在乾六，丁己庚墓丑在艮八，辛壬墓辰在巽四。六仪表是本技能采用表，不宣称古本一致。

天盘干入墓、地盘干墓位分别记录。时干入墓另按所用原时柱干支核验，不能用落宫墓位替代。

星门墓另用 ZG-4 五行表：

| 星门五行 | 墓支 | 宫 |
|---|---|---|
| 木 | 未 | 坤二 |
| 火 | 戌 | 乾六 |
| 土 | 辰 | 巽四 |
| 金 | 丑 | 艮八 |
| 水 | 辰 | 巽四 |

门星不能套阴干墓表。开门在艮八可同时得宫生、逢丑墓；前者为生助关系，后者为发挥限制，合并说明其作用。

格名含入墓不证明实际落墓宫。墓位成立后如何判断力量与解除，见 [空墓与应期](空墓与应期.md)。十二长生的其他状态未自动计算。

## 天盘干加地盘干

“X 加 Y”固定为天 X 加地 Y，不能倒读。内置九干构成 81 个有向组合。

每个实际组合先核对主寄、五行方向、同干和五合。五合为乙庚、丙辛、丁壬、戊癸；不自动合化。甲的遁仪定位明确后再讨论甲己。

重点格局核验表：

| 格局 | 几何条件 |
|---|---|
| 青龙返首 | 天本旬遁仪加地丙；戊丙简法另标 |
| 飞鸟跌穴 | 天丙加地本旬遁仪；丙戊简法另标 |
| 青龙逃走／白虎猖狂 | 天乙地辛／天辛地乙 |
| 朱雀投江／腾蛇夭矫 | 天丁地癸／天癸地丁 |
| 太白入荧／荧入太白 | 天庚地丙／天丙地庚 |
| 大格、刑格、上格或小格 | 天庚分别加地癸、己、壬 |
| 伏干／飞干 | 天庚加地日干／天日干加地庚 |
| 伏宫／飞宫 | 天庚加地本旬遁仪／天本旬遁仪加地庚 |
| 岁月日時格 | 天庚加对应年、月、日、时柱干 |
| 悖格 | 天丙加对应年、月、日、时柱干 |

各柱为甲时按该具体甲柱的遁仪定位，不共用本时旬首。月格默认 ZG-4 月柱干法；YY-G 月朔干法另列，不混称。

常用分项克应由 [pattern_readings.py](../scripts/pattern_readings.py) 维护，当前收录 20 条扩展，包括乙丁相佐、丁丁奇入太阴等。表名、相关领域、可能取象、应用条件和来源分字段保存。

干表名不等于另一层条件。例如丁丁的表名奇入太阴不证明神盘为太阴；己丁的朱雀入墓不证明丁落实际墓宫。未收录的分项克应可按需要查原典，不补造格名。

## 格局如何发挥

依次区分几何成立、事类用途、角色作用及条件限制。它们可以同时保留，不必相互抵消。

| 规则 | 采用的处理 |
|---|---|
| 回首、跌穴逢庚为本旬遁仪 | MJ-P 对其吉格取用有限制，工具保留成立并标出限制 |
| 乙辛、丙庚、丁癸得使兼不利相加 | YY-2 要再核本旬值符星同宫；工具分别记录是否满足 |
| 逃走、投江与猖狂、夭矫 | MJ-P 对主、客有不同用法；只在选定主客法后应用 |
| 空墓、迫刑 | 分别说明限制哪个符号及作用；不能直接汇总为凶票 |

默认不以格名作全盘最终结论。表中主客缓解条目不自动推出该角色获胜。

## 复合格局

默认采用 YY-2 所选条件。门奇神须同宫，主寄照实际字段标明。

| 格局 | 条件 |
|---|---|
| 天遁 | 生门、天丙、地丁 |
| 地遁 | 开门、天乙、地己 |
| 人遁 | 休门、天丁、太阴 |
| 神遁 | 生门、天丙、九天 |
| 鬼遁 | 杜门、天乙、九地 |
| 风遁 | 开休生之一、天乙、巽四 |
| 云遁 | 开休生之一、天乙、地辛 |
| 龙遁 | 休门、天乙、坎一 |
| 虎遁 | 休门、天乙、地辛、艮八 |
| 三奇得使 | 天乙地己辛，天丙地戊庚，天丁地壬癸 |
| 玉女守门 | 值使门临地盘丁 |

不同古本九遁有异说，本表选定条件不代表采用该书全部排盘规则。五假、升殿、三门四户等未启用的规则须先取得条件和字段。

## 时间层与工具

五不遇时为原时干克原日干且阴阳同性。甲日辛时不成此格；不先遁甲再计算。

`inspect_patterns.py` 输出分层动静、五不遇、符使关系、逐宫干组合、分项克应、时间格、例外条件、刑墓迫制及支级触发。它不选用神，不自动确定主客或成事。

空马发挥和应期操作只在 [空墓与应期](空墓与应期.md) 定义。来源编号、版本与采用状态见 [规则与出处](规则与出处.md)。
