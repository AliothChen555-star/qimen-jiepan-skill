# 前置使用规则

用于新占问、已有盘追问、重复起盘、纠错、期限变化和固定盘连续预测。默认作为后台判断，仅把真正影响本问的选择简短告诉用户，不要求每次填写表单或确认接受风险。

这些是结合公开文献异说确定的本技能操作约定。传统出处见[来源登记](来源登记.md)的前置规则增补；不称所有流派共有的古法。实际解读接[六步流程](解盘流程.md)。

## 问题与用途

从对话中确定对象、事件、所求结果、身份关系和观察期限。把占问、择时、复盘、方法比较分开。能合理推定的内容说明采用口径后继续；真正会改变取用或结果范围的歧义才补问。

一个主问可以包含相关阶段和子问题。多件不同事项可依所选方法同盘分题，但每题分别绑定角色。代问先说明为谁问；未知年命不阻塞不需要它的方法，也不索取无关的完整生辰。

情绪紧张、希望有好结果或询问理由，不自动构成起盘失效。不能把解释错误归咎于用户心不诚。

## 随心起盘与取时

这里将“随心”用于明确疑问自然形成后可以问测，不要求先等吉时。它不表示看完盘后任选吉时，也不将随机报数直接等同于时家拆补法。

按以下优先顺序选择并记录主入口：

1. 用户给定的原盘或已经选定的时刻，沿用其依据和方法。
2. 用户明确指定且能记录的动念、发问、事件发生或预定事件时刻，说明属于哪一种入口。
3. 没有指定时刻，但能够可靠取得本次正式提问时间时，可按问时冻结。不要把平台没有提供的发送时间补造出来。
4. 以上均无可用时刻时，以本次实际接问的运行时钟起盘，注明默认 `Asia/Shanghai`。

有明确时刻用 `--datetime`，仅实际当前取时用 `--now`。起盘成功后，分析延迟、跨时辰、补背景或重试读取均不移动原时刻。若心动时间记不清，使用可记录的正式问时或接问时，不追索虚假的分钟精度。

出生盘、事件盘、问时盘、定期观察盘的用途分别声明；比较不同入口时各自命名，不能混成一张主盘。年、月、日、时家与拆补、置闰、飞转、太阳时等参数在读吉凶前选定，见[方法配置](方法配置.md)。

## 判断是否仍在重问同一件事

比较对象、事件阶段、所求结果、预测期限及关键条件。它们基本相同，只因不满意原断而不断换时刻、软件或措辞寻求另一结论，按重复求结论处理；不用累计次数、午夜或换设备作为开关。

以下通常承接原盘：追问理由或应期、补充身份、另一位解读者审阅、固定周盘的逐日细化。改正排盘错误属于纠错。新对象、新阶段、新方案或明确的新期限，可以另立关联问题。

同一时辰多人问事可分别记录对象及取用，不强制后面的人等下一时辰。若当前方法无法区分同宫同干的对象，如实说明区别未能从该符号取得，不虚构不同落点。

## 已经重复或触发问题后如何继续

| 情况 | 处理 |
|---|---|
| 只是没理解原断或要补细节 | 继续原盘，回答具体疑问 |
| 连起多盘、结论矛盾 | 核对各盘问题和方法，恢复已声明主盘；其余标为重复、补充或方法比较 |
| 没声明主盘 | 可采用最早可核对、输入与方法有效的记录恢复主线；这是连续记录约定，不保证最早盘更准 |
| 初盘丢失 | 说明记录缺口；有必要时透明地建立新观察起点，不假称新盘为初盘 |
| 输入、历法、宫位或计算出错 | 保存原版，生成更正版并说明错误与影响 |
| 盘正确但角色或解释有误 | 更正分析并保留原断，不为掩盖解释错误重起 |
| 合作方、方案或阶段实质改变 | 说明改变内容，关联新盘，不抹掉原问题 |
| 只是出现普通波动、心情改变或又一条同类信息 | 原窗口内继续观察，不自动废弃主盘 |
| 原窗口结束，继续问下一周期 | 原轮次结案，新期限单独起问 |

无需附加通用24小时、三天或七天冷却期。等待、焚香、付费、换账号、换解读者不作为本技能的解除程序。用户明确采用某师承约定时，可记录其出处和适用范围；不因此把正常补问一并拦住。

《周易·蒙》的解释、礼制卜筮和六爻重占规则各有语境。《卜筮正宗》较严格，《增删卜易》允许疑义未明再占；它们用于解释异说，不直接作为本技能的奇门次数限制。

## 盘面时效

分开四件事：排局时间与换局节奏、原问题预测窗口、事件前提是否延续、后来获得的信息。换时辰会生成另一时刻的盘，不自动注销原盘对原问题的解释。

- 明确问某日上午、本周或本月，就按原期限核对；到期后可复盘，不为追求应验无限延期。
- 问事件最终结果而未定日期，先确定签约、终止、阶段完成等结案标准。长期悬而未决时可另立阶段问题。
- 只有补充旧事实，更新分析；现实条件后来改变，记录事变。二者不能混称。
- 应期指某阶段可能发生变化的时点，不是整张盘的保质期。
- 事件改期须看原入口：问时盘的主问题可能仍延续，按预定时刻排的事件盘则需为新安排另立记录。

## 凶格、择时与仪式

五不遇、反伏吟、刑空墓迫等首先是需要解释的结构及用事条件，不能仅因不吉就把盘当作计算错误。若原法说行动不利，明确指出；用户要选下一步时间，再另做择时。

古籍特定术法确有仪式，不把这些要求推广到普通时家问事。外应只使用实际发生并记录的线索，不必每次出现特殊征兆才可以起盘。

## 金融连续预测

按[金融解盘](金融解盘.md)固定产品、涨幅口径、观察窗口和市场日历。原周盘加流日层属于连续推演，不是每天重新起盘。每日独立盘策略可以作为另一种事前声明的方法，不事后择优替换固定盘。

新一周、新一月属于新窗口；重大事件可以另加事件盘并说明其新问题。休市、停牌或净值待公布是数据状态，不自动记为零收益或原盘失效。记录原预测与后续修订时间，不覆盖原判断。

## 用户可见说明

只需解释本次选择，例如：“沿用原盘，补看座谈环节”“输入时区有误，另存更正版”“合作方已变，这次按新方案另立一问”。随后进入解盘，不先输出整套规章。
