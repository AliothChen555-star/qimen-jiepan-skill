# 起盘、读取与日期候选

派生输出必须与原盘使用不同文件。格局、日期候选入口会拒绝输出路径与原盘为同一路径、符号链接或硬链接；不通过覆盖原盘保存派生结果。

本技能使用拆补法时家转盘、中五寄坤二和天禽随芮。程序计算结构，不替代取用、条文适用性判断或真实预测效验。以实际读取的 `SKILL.md` 所在目录为技能根目录；以下路径和命令均相对该目录。

## 安装与日常运行分开

日常入口是 `scripts/qimen_cli.py`。它会复用已有的技能私有环境，但**不会创建环境、安装依赖或启动 `setup_env.py`**。当前解释器已有依赖时也可运行；缺少依赖则明确报错。

只有在准备或更新环境的任务中，才显式执行：

```text
python scripts/setup_env.py
```

该命令在技能根目录创建或更新 `.venv`，按 `requirements.txt` 的摘要安装依赖，不改系统 Python。当前清单锁定 `lunar-python==1.4.8`、`tzdata==2026.5`。已经能正常运行的环境无需每次重装。

Windows 使用 `.venv/Scripts/python.exe`；macOS/Linux 使用 `.venv/bin/python`。后文 `<私有Python>` 表示对应的已有解释器。只读审查、读取冻结盘和重复检查时加 `-B`，避免生成字节码。安装失败先保留错误和既定取时，不把失败期间经过的时间当成重新选盘理由。

## 显式选择取时

```text
<私有Python> -B scripts/qimen_cli.py chart --now --format json
<私有Python> -B scripts/qimen_cli.py chart --datetime 2026-09-14T14:30:00+08:00 --format json
```

`--now` 和 `--datetime` 是必选互斥参数。缺一不选或同时选择都会报错；只有 `--now` 允许读取当前时钟。显式时间必须包含偏移，程序将它作为绝对时刻转换到所选 IANA 时区，不把没有偏移的钟面当成确定时刻。

| 参数 | 默认与含义 |
|---|---|
| `--timezone` | `Asia/Shanghai`；这是方法默认值，不是自动定位结果 |
| `--time-mode` | `standard_time`；可选 `true_solar_time` |
| `--day-boundary` | `midnight`；可显式改为 `zi_start`，从当地23时换日 |
| `--horse-basis` | `hour`；可显式改为 `day`，不混用日马和时马 |
| `--longitude`、`--latitude` | 默认120、30；不是测得的用户位置，普通标准时不需要索取出生地或位置 |
| `--format` | `text` 或 `json`；完整留档采用 JSON |

这里的 `standard_time` 是程序参数名，实际使用所选 IANA 时区的地方民用钟面，包含该时区当时生效的夏令偏移；它不表示对所有国家强制使用固定的无夏令标准偏移。默认上海现代时刻通常没有这种差别。

真太阳时只在经度已明确且用户认可时启用。当前算法采用经度修正和 NOAA 均时差近似，不宣称高精度天文定时；太阳钟面与原始绝对时刻分别记录。日时柱依所选地方或太阳钟面及换日口径，年/月柱与节气交界按绝对交节时刻计算。日期范围为所选时区的1901—2099年；改口径需要保存版本，不能因解读结果不满意临时改法。

库调用同样要求显式输入：`cast_chart(含偏移时间)`，或 `cast_chart(use_current_time=True)`。测试可注入时钟；`cast_chart()` 不再暗取当前时刻。

## 冻结原盘与复核

起盘成功后先检查退出码、有效 JSON 和完整字段，再保存到当前任务输出目录。以 `input.captured_at_utc` 为原盘绝对起点；新模式同时保存 `input.chart_instant_utc`，它们必须一致。`input.datetime`、`captured_at`、历法时间与时区偏移也须相互一致。时间精度为整秒。

新盘带 `chart_schema_version` 和实际 `runtime`：Python、lunar-python、已安装 tzdata 版本、`zoneinfo` 搜索路径及优先策略。IANA 时区数据可能来自系统 `TZPATH`，也可能回退到 tzdata 包；仅见已安装的 tzdata 版本不能证明系统实际使用了它。需要严格复现时同时保留环境和实际时区数据来源，不把清单锁定当成完整环境证明。

补充背景、年命、追问和检查失败都不自动更换原盘。确认存在输入错误时，保留原版及原结论，另存修订盘、修改原因和影响；不静默覆盖。个人问事、年命和原始回答留在任务目录，不提交到公开技能仓库。保留原始 UTF-8 JSON，并记录哈希所用方式，避免中间格式转换改变时间字符串或文件摘要。

## 完整盘校验与结构派生

```text
<私有Python> -B scripts/inspect_patterns.py chart.json --output patterns.json
<私有Python> -B scripts/inspect_patterns.py chart.json --star-season yanyi_prose --output patterns.json
```

默认九星月令为 `tongzong`。选择 `yanyi_prose` 要在方法配置中整盘固定，不能按单宫吉凶来回切换。派生结果包含实际条件、方向和方法，不自动生成用神、主判或应期。

`inspect_chart` 默认完整校验：类型与字段、地盘整布、星干共同旋转、门神和符使、寄宫及显示值、时间元数据、历法与所声明规则的一致性。当前只接受内置 `chai_bu_v1.0.0`、`kun2` 的完整盘面。旧完整冻结盘可按兼容模式读取，新盘的运行信息不能缺失。

校验会用冻结时刻做纯计算比对；它不读取当前时钟、不联网、不安装依赖、不改写输入，也不生成替换原盘。比对使用同一历法提供者，证明内部一致性，**不等于独立历表已签核算法**。

`chart_validation.validate_structure` 及 `inspect_chart(..., validation="structure")` 只供明确标记的合成排布测试。CLI 不开放此降级选项；元数据缺失或矛盾不会自动降级。截图或其他排法应保留原材料，按已知字段作有限人工解读，不能伪装成已通过完整校验。

## 日期候选窗口

先按[空墓与应期](空墓与应期.md)确定是否有适用规则、对象、事件阶段和时间单位，再生成支级候选。候选本身也可用于检查窗口宽度，不能因某日匹配就宣布应验。

```text
<私有Python> -B scripts/timing_candidates.py chart.json --palaces 4 --unit day --days 30 --output timing.json
<私有Python> -B scripts/timing_candidates.py chart.json --palaces 4,9 --unit hour --days 7 --search-start 2026-10-20T00:00:00+08:00 --duration-mode elapsed_24h --output timing.json
```

只支持完整、已通过校验的标准时盘。支持外八宫、日/时两种单位和1—366天窗口；月级和真太阳时窗口不在此工具支持范围内。原盘起点和独立搜索起点分开：省略 `--search-start` 时从已验证的原盘绝对时刻开始；指定时必须带偏移，不改原盘。

| 窗口参数 | 含义 |
|---|---|
| `--duration-mode calendar_days` | 默认。推进当地日历日期并保留起点钟面；经过时区跳变时，不保证恰为24小时 |
| `--duration-mode elapsed_24h` | 在 UTC 上推进 `days × 86400` 秒，再转换回地方时 |
| `--end-gap-policy shift_forward` | 默认。日历终点不存在时按缺口幅度向前规范化并记录调整，例如00:30变为01:30 |
| `--end-gap-policy raise` | 日历终点不存在时明确报错 |
| `--calendar-end-fold 0` / `1` | 日历终点出现两次时，分别选较早或较晚的一次；默认0 |

分段在 UTC 上排序，保留重复时段，补入跨柱的真实时区跳变；每个日级段的日柱、时级段的时柱应保持恒定。所有端点均由 UTC 转回有效 IANA 地方时，区间左闭右开。

输出包含原盘 UTC 起点、搜索窗口、有效地方时/UTC 端点、实际秒数、候选区间并集秒数和 `coverage_fraction`。同段多个触发不重复累计；覆盖比例是筛选宽度，不能报告为成功概率、命中率或置信度。

## 故障与版本

| 现象 | 处理 |
|---|---|
| 找不到入口 | 从实际 `SKILL.md` 定位根目录；仓库外层和可安装子目录可能不同 |
| 缺少环境或依赖 | 明确报错；环境准备任务中才显式运行安装命令，日常入口不会自行联网安装 |
| 校验报某字段冲突 | 保留原 JSON 和错误，不绕过校验、不把它当有效原盘解读 |
| 外部排法或截图不完整 | 标明方法/字段未知并有限解读，不捏造完整 JSON |
| 不支持的时间口径或窗口 | 保留原盘，说明当前工具范围；不偷偷换成另一个时间或盘法 |

技能指令版本、原盘 `rule_version`、图式版本、派生程序版本和依赖版本分别记录。上游声明为 `https://github.com/AliothChen555-star/qimen-jiepan-skill`；本地 metadata 不是已核实的最新版本或安装来源。只有实际 Git 副本才能核对其远端与提交，不凭空补 commit。

维护时运行实际测试，不把旧文档中的测试总数照抄为本次结果：

```text
<私有Python> -B -m unittest discover -s evals -p "test_*.py" -v
```

程序、行为与真实预测评估的边界见[评估方法](评估方法.md)；回放状态以带产物记录的 `evals/replay-status.json` 为准。
