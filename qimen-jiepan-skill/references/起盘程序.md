# 起盘程序

本 Skill 自带 `scripts/qimen_cli.py` 和 `scripts/qimen/`。安装或更新 Skill 后，用系统 Python 创建 Skill 私有环境：

```text
python scripts/setup_env.py
```

该脚本在 Skill 根目录创建 `.venv`，仅在其中安装 `requirements.txt` 的依赖，不修改系统 Python。`qimen_cli.py` 也会在首次运行或依赖清单变更时自动完成同样的初始化。

调用：

```text
python scripts/qimen_cli.py chart --now --format json
python scripts/qimen_cli.py chart --datetime 2026-09-14T14:30:00+08:00 --format json
```

## 定位与版本

仓库根目录包含一个同名的 `qimen-jiepan-skill/` 子目录，后者才是可安装的 Skill 根目录。入口必须相对于实际读取的 `SKILL.md` 解析，不能因为当前工作目录不同就判断程序不存在。

上游仓库：`https://github.com/AliothChen555-star/qimen-jiepan-skill`。Skill 的 `metadata.version` 是指令版本；JSON 的 `rule_version` 是排盘规则版本，二者独立。可用 `git remote -v` 和 `git rev-parse HEAD` 核对 Git 副本；只复制了 Skill 目录时只能报告其声明版本，不能凭空提供 commit 或保证最新。

用户指定上游版本而本地有相似名称时，读取指定仓库实际文件；不要删除、覆盖其他技能。若需要持久安装，按用户授权安装到 `qimen-jiepan` 目录，保留其他技能，说明新会话需要刷新技能列表。安装到全局目录不是一次性起盘的前置条件。

## 时间与结果保留

首次按当前时间运行时使用 `--now`，并以 JSON 的 `input.captured_at` 为取时依据。先前已明确选定时间或复用成功结果时用保存的 JSON，重放才用 `--datetime`；不要因初始化花费时间或用户补充信息而擅自重选时辰。

只传时间、不传经纬度时为标准时；默认经纬度不是定位结果。指定真太阳时必须有用户认可的经度。`--now` 和 `--datetime` 二选一，显式时间包含时区偏移。

个人问事的完整 JSON 保存到当前任务的输出目录，不提交到公开技能仓库，也不把用户问事、年命等信息添加到源码。维护用的虚构评估场景可附完整冻结盘，并标明用途与来源。可以使用宿主文件工具或 UTF-8 重定向；先检查退出码，再把输出当作有效盘面。

## 故障分流

| 现象 | 处理 |
|---|---|
| 所选目录没有入口 | 核对仓库根目录与 Skill 子目录、实际版本和来源；不要直接安装另一排盘库 |
| `.venv` 未创建或依赖缺失 | 运行内置 `setup_env.py`；入口也会自动初始化 |
| 网络、DNS、套接字权限失败 | 保留原始错误，按宿主授权流程重试；不能将连接失败解释为包不存在 |
| 权限不足或初始化最终失败 | 明确尚未生成盘，告知具体原因；不绕到系统 Python 安装依赖 |
| 输出不是有效 JSON 或缺少关键字段 | 不解读不完整结果，定位错误并重放既定时间 |

`setup_env.py` 按依赖清单摘要更新私有环境。无需每次手动重装，也不要连带下载第三方排盘器。

## 原盘格局核验

起盘成功后可对保存的 JSON 运行：

```text
python scripts/inspect_patterns.py chart.json --output patterns.json
```

九星默认采用《统宗》法。需要《演义》正文法时显式选择：

```text
python scripts/inspect_patterns.py chart.json --star-season yanyi_prose --output patterns.json
```

核验工具使用标准库、相邻 `pattern_readings.py` 和本技能规则常量，读取原盘，不调用时钟、不重起、不改动原始 JSON。输出格局条件与分层派生事实，具体口径见 `格局分析.md`。无须再安装依赖；只接受完整的内置 kun2 盘，其他盘按明确规则人工核验。

## 日期候选

由解盘先确定事件阶段、目标宫和时间单位，再用私有 Python 换算候选。Windows：

```text
.venv/Scripts/python.exe scripts/timing_candidates.py chart.json --palaces 4 --unit day --days 30 --output timing.json
```

macOS 或 Linux 将解释器改为 `.venv/bin/python`。该脚本沿用原盘的时区、标准时与换日口径，换算填实、冲空、冲墓和相关马星同支窗口；不重新起盘，不自动选择成事阶段或最终应期。支持日、时两种单位和 1—366 天搜索范围；月级、真太阳时的日期换算另行核验。推演方法见 `空墓与应期.md`。

## 维护验证

用技能私有 Python 运行：

```text
.venv/Scripts/python.exe -m unittest discover -s evals -p "test_*.py" -v
```

macOS 或 Linux 将解释器改为 `.venv/bin/python`。当前 37 项测试检查规则与数据完整性，包含两套九星口径、独立星门墓、格局例外、原盘保留及日历候选。行为场景的实际回放另见 `evals/replay-status.json`；确定性测试不评估预测是否应验。
