# 空墓与应期

空、墓、冲合先作为条件记录，再判断它影响谁和哪种作用。应期是在已有结果判断之后，按需要寻找的触发窗口。

## 空亡

默认旬空来自起局时柱。保留实际空支；双支宫一支空时只记这一支。

依次判断：

1. 哪个角色或哪种作用落空？
2. 当前是助力难兑现、阻力暂弱，还是对象尚未落实？
3. 所问期限内有没有相关触发？
4. 触发后，原有门迫、刑墓或其他限制是否仍在？

空亡本身不等于最终成败。也不能只因“旺”或“动”就取消空亡。要使用这类解除规则，须有明确采用条件。

## 墓位与发挥

天盘干入墓、地盘干墓位、星墓、门墓分别读取。对应表在《格局分析》。

墓表示该层受到收藏或难以发挥的限制。旺衰说明力量背景，墓位说明发挥条件，二者可以并存。不要把墓直接译成死亡、牢狱或实际疾病。

检查对象、作用和阶段。有承接意向而受墓限制，可以判断有意但难以展开；已有明确冲支时，先判断该墓位出现松动候选。

## 解除条件的采用定义

| 机制 | 本技能用法 |
|---|---|
| 填实 | 后续选定时间层的支与原空支相同 |
| 冲空 | 后续选定时间层的支为原空支的六冲支 |
| 冲墓 | 后续选定时间层的支为该墓支的六冲支 |
| 出空 | 标明是哪一层的旬：时旬跨界按时序，日旬跨界按日序；不把原时旬剩余数直接当成天数 |
| 马星 | 相关用神与原盘马星有关时，记录动象或同支时点；马星不自动解除空墓 |

六冲为子午、丑未、寅申、卯酉、辰戌、巳亥。对宫关系不替代具体支冲。填实和冲空可以使原有助力或阻力发挥，并非一律转吉。

这些是候选触发的约定。跨过时点不直接代表成事；结果仍由所问角色、通道及其他限制解释。

## 从条件到应期

先用第五步综合判断所问结果及主要障碍，再选择时间判断方式。

1. 定阶段：起动、接触、转折或落实。
2. 定时间单位：按问句期限和事项节奏选择时、日或月，并说明理由。
3. 定对象：只对核心用神、相关门或值使提取触发。
4. 列候选：写支、机制及它解除或加强哪项条件。
5. 筛候选：直接作用于主要障碍者优先；不同作用可对应不同阶段。
6. 核日历：核验公历、时区和换日口径后再给窗口。

近期动象只支持相关阶段可能起动。录用、到账等最终落实，还需要相应宫内条件。只有月支线索时给月级窗口，不擅自细化为某日。

现状问题不强定应期。多个候选不能只凭听起来合理就任选一个。

## 日期候选工具

已有原盘、选定对象和时间单位后，可用私有 Python 运行 `scripts/timing_candidates.py`。它读取原盘并换算日历，不重新排盘。

```text
<技能私有Python> scripts/timing_candidates.py chart.json --palaces 4,9 --unit day --days 30 --output timing.json
```

工具支持标准时的日级、时级有限窗口。月级应期及真太阳时转换按明确口径另核。候选须按上面步骤筛选，不作为自动成事日。
