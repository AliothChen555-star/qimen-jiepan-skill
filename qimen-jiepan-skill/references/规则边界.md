# 规则边界

本项目 `chai_bu_v1.0.0` 为拆补法时家转盘。中宫地盘干寄坤二；中宫保留展示用天盘天干，九星、八门、八神留空；天禽随天芮及其寄天干转动。中宫展示不是另一个独立的天盘落点。马星默认按时支，也支持日支，查看 `horse.basis`。

排盘规则版本与解读/格局规则独立：`qimen_cli.py` 保留原始盘面，`inspect_patterns.py` 按 [格局分析.md](格局分析.md) 的明确口径核验派生条件。助手也可人工核验，但必须列实际字段、规则及条件；未核验的相关格局不得暗用，只在影响本问时局部注明缺项。

格局工具仅接受 `chai_bu_v1.0.0` 和 `kun2` 完整 JSON，不擅自转换飞盘、置闰盘或其他中宫排法。读取外来盘时以用户明确规则为准；不知道关键规则就说明影响范围，不拼盘、不重起以掩盖差异。

不同古籍有星旺衰称谓、九遁条件、入墓、击刑及主客异说。默认口径见格局参考；切换须声明依据。同盘不混口径；引用古籍格局不表示采用该古籍全部排盘规则。局部干伏吟、整体星/门/奇仪伏吟，门迫与门受制，格名入墓与墓宫入墓均分别核验。
