# 方法配置与异说

解盘前固定方法，不能看完吉凶再选表。下列是本技能的工程默认配置，不宣称古籍全都一致。理论比较可以并列异说；一份实际判断须标明采用哪一种，结论分开。

| 维度 | 默认及支持边界 |
|---|---|
| 排盘 | 时家转盘、拆补法 `chai_bu_v1`，规则版本随原盘保存；中五寄坤二、天禽随芮 |
| 时钟 | `Asia/Shanghai` 标准时，午夜换日；可显式选子初换日。时区按IANA，不推定用户位置 |
| 起盘依据 | 已有原盘或明确指定时刻优先；可靠问时可冻结使用，否则用实际接问时。异步消息与动念规则见[前置使用规则](前置使用规则.md) |
| 太阳时 | 仅用户认可经度后启用近似真太阳时；与原始绝对时刻、地方标准时分开记录 |
| 原盘 | 成功取得后冻结。补背景不重起；确认输入错误时另存修订，不覆盖原版 |
| 重复与时效 | 不设通用次数额度和冷却期；按对象、阶段、目标、期限、条件区分续问与新问，换时辰不自动注销原盘 |
| 日时干 | 依事类默认天盘；甲按具体甲柱解析对应遁仪；地盘只按所用方法读取 |
| 月令 | 节月五行简化；未启用土旺十八日，不冒充完整季土法 |
| 九星 | 默认 `tongzong`，《统宗》法；可整盘显式选 `yanyi_prose`，《演义》正文法 |
| 空亡 | 原时旬的具体空支；一支空不等于双支宫所有角色全空，日旬另用须注明 |
| 驿马 | 默认时支，可显式日支；不是自动解空、解墓的条件 |
| 击刑 | 输出逐天盘六仪结构匹配，严格旬首法另核 `is_current_xun`；不把扩展匹配都称原法成立 |
| 奇仪墓 | 沿用表保留为结构；逐项核实子集见规则卡，不把部分核实扩张为整表核实 |
| 十二长生 | 未启用统一自动计算；采用时注明完整表、阴阳顺逆、土法和具体支位，人工辅助不替代月令与九星专表 |
| 星门墓 | 按《旨归》卷四五行墓支，与阴阳干墓分开；结构匹配不自动决定强弱或解除 |
| 主客 | 无跨事类统一默认。按具体方法绑定动静、天地盘或方位身份，例外不能反向决定身份 |
| 分占 | 以[事类方法](事类方法.md)已声明的支持范围为准；现代身份转译另记 |

普通宫门干月令：同旺、月生我相、我生月休、我克月囚、月克我死。

九星《统宗》：同相、我生月旺、月生我死、我克月废、月克我囚。《演义》正文：同旺、我生月相、月生我休、我克月死、月克我囚。这里的“我”是被判断的五行，不是问事者。两表是不同来源配置，不能混成一表，也不能把星旺相套给门干宫。

来源和条件详见[来源登记](来源登记.md)、[规则卡](规则卡.md)。截图或外部盘无法识别完整方法时，先列已知与未知；与内置排法不相容的，不能强行导入再用新盘替换。

金融新分析使用 `FINANCE_MULTI_ROLE_V2_CANDIDATE` 的多角色证据与显式综合；旧 `FINANCE_FIXED_CHART_V1` 保留基线和复算。角色与产品主题见[金融综合解盘](金融综合解盘.md)。原盘时区、钟法、换日、马星保持不变，未来市场开盘时刻转换进原盘时钟；基金另用净值归属日锚点。流日只增加日期层，基础定位见[固定盘逐日推演](固定盘逐日推演.md)。方法、主题和历史幅度独立留档。
