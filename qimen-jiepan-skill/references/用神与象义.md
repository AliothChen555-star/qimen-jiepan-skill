# 用神与象义

本表提供默认分事入口。角色在全盘分析之后确定，取法不随宫位吉凶改变。古籍条目与现代问题的转译见 [规则与出处](规则与出处.md)。

## 人物定位

- 自问近期具体事项：日干通常为本人主用，年命作辅。
- 代问指定人物：优先用已知年命定位该人物；交代日干在本问中代表谁。没有年命时按身份事类取用，不把代问人和被问人混为同一身份。
- 年命是出生年天干的常用简称，不决定此时盘局数。已给天干且无冲突，不要求完整出生信息。
- 默认定位天盘干。参考地盘时另说其作用。采用天地盘主客法时按 [主客取法](主客取法.md) 定位。
- 甲日按该日柱的六甲遁仪处理；甲年命需有足以区分六甲的年柱或已声明取法。只有甲字时不擅自当戊。
- 中宫寄干以外宫实际主寄落点定位。相同年命或同宫角色不虚构两个宫。
- 日干与年命结论不同，保留主辅差别。未采用已给年命时说明它为何没有增加区分度。

## 分事默认表

| 问题与目标 | 核心角色 | 必要时加入 | 关系怎样接回目标 |
|---|---|---|---|
| 求职：获得岗位或录用 | 日干为求职者，开门为岗位及接纳条件 | 已知招聘方年命；时干为事项；问待遇时参考生门 | 接纳、接洽和落实分开判断 |
| 升迁：职位或权限改变 | 日干为本人，开门为职位 | 值符为主导或评定方，须声明为本问转译 | 上级支持与职位真正变化分开 |
| 辞职：获准离开 | 日干为离职者，开门为当前单位或主管 | 已知主管年命；时干为办理事项 | 对方生我可为挽留；克我可为压力或放行条件，仍看办理通道 |
| 合伙：关系与共同成果 | 日干为我，时干为伙计 | 六合为关系；财利问题加生门，涉及本金加戊 | 分别看双方得失及项目成果 |
| 贸易：资本与收益 | 日干为经营者，戊为资本，生门为收益 | 货物可取时干；对方年命或中介六合 | 投入、回流及收益不能合为一个“财” |
| 买货、卖货：货能否流转 | 日干为货主或买方，时干为货物 | 戊为资本，生门为收益 | 先声明买卖身份；不把同一时干同时当货和交易对手 |
| 求借、还款：资金能否交付 | 日干为本人，时干为借还事项，戊为钱款 | 已知对方年命；古籍借贷法见主客专题 | 钱款可得、对方意愿、交付落实分开 |
| 感情、人际：双方与关系 | 日干为自问者，对方优先用已知年命，六合为关系 | 明确采用的身份用神 | 生合可能是联结或牵绊，按相处、复合、分开等目标解释 |
| 风评：被评价者与公开形象 | 日干或明确选择的年命为人物，景门为名声 | 惊门为争议；六合为关系氛围 | 被看见、被接纳和争议程度分别判断 |
| 出行：能否成行或到达 | 日干为出行者，开门为行动通道 | 已知目的方；相关马星、九天 | 动意、实际行动与到达分开 |
| 竞争、争议：推进、获胜或结束 | 双方用已声明的人物或主客取法 | 事项对应门及已知裁定方 | 相生可为协商，冲克可为争夺或终止；先固定目标 |

这组取法是本技能的默认约定。部分条目源于分占古法，现代职位、录用等角色是转译，不代表所有门派一致。

同一个开门不能凭空分成当前单位与未来岗位两个独立落宫。问题同时包含旧、新对象时，利用已知年命、方向或身份区分；不能区分时就说明共享的事业条件，再按不同目标讨论。

时干可以因事类代表伙计、货物或事项。每个具体问题只给它一个主角色，其他关联另作辅助解释。没有必要的辅助用神不加入。

## 风评专题

未限定圈子时按近期整体人际口碑理解，不自动限定职场。未给期限不擅自写成精确天数。

景门看公开形象，惊门辅助看交涉或争议，人物宫看被评价者状态。宫位关系先给方向，宫内四盘再判断这种关系如何表现。

可取显露、保留、议论、评价分化等相关象义。隐情或口舌之象本身不能确认某人已经造谣。

## 八门与事类

休门可取休息、接洽；生门可取生长、财利；伤门可取行动、竞争；杜门可取阻隔、隐蔽；景门可取名声、文书；死门可取终止、静止；惊门可取突发、口舌；开门可取工作、交易。

门的名称是取象入口。适合隐藏的杜门、适合结束的死门，不应只因通常列为凶门就判所问不成。
