# 用神与象义

取用先固定问事角色，细节取象在整体、宫内、回归整体定势之后。星门神的性质、吉凶和格局原义由 [格局分析](格局分析.md) 维护，不能当成最后才读的细节。

股票、指数、基金、期货统一转 [金融解盘](金融解盘.md)，不直接把古代贸易条文换成证券涨跌法。

## 人物定位

- 自问近期具体事项通常以日干定位本人，年命可作辅；明确说明采用方法。
- 代问指定人物优先用已知年命；日干代表谁另交代，不混同代问者与被问者。
- 年命按已给出生年天干使用，不用它改变时盘局数。甲需足以分清六甲或明示取法，不能见甲就当戊。
- 默认天盘定位；地盘按实际干格或所采用分占法读取，不固定称过去、基底或第二个本人。
- 主寄按外宫实际落点，同干、同宫人物不虚造多个宫。日干与年命主辅有别，不按结果挑有利者。
- 需要天地盘主客时用 [主客取法](主客取法.md)，不临时换主客。

## 事类入口与转译范围

下表是已有事类用法的入口，涉及现代身份的对应属于转译，不能因写在表中便称为古籍逐字规定。原有分占能直接适用时按其完整条件；没有原文支持的角色不继续扩造。

| 问题 | 固定角色的入口 | 范围 |
|---|---|---|
| 贸易财利 | 戊资本、生门收益，主体日干；货物等依具体分占 | MJ-10、ZG-8 |
| 合伙 | 主体日干、伙计时干；涉及财利再看相应角色 | ZG-8；六合关系另按所问使用 |
| 访人、来访、借贷 | 按明确方位的天地盘主客法 | MJ-7、ZG-8，不补方位 |
| 求职、职位 | 日干为本人，开门对应工作或职位；问待遇才考虑财利 | 现代角色转译，不能把一个开门拆成两家单位 |
| 辞职去留 | 本人及单位角色先固定，具体断法核 ZG-7 | 不能自行加“克我即放行、生我即挽留”的通则 |
| 感情、人际 | 双方身份或已知年命先固定；关系可参考六合 | 不把所有生合、同宫直接断成关系成功 |
| 风评 | 被评价者先固定；景门公开形象、惊门争议作为现代转译 | 不由口舌、玄武直接断定他人造谣背叛 |
| 出行 | 人物、目的方及原分占的相关门、马 | 动象不保证成行或到达 |
| 竞争、争议 | 按身份、方位或已采用主客法固定双方 | 战争、访人等条文不任意跨用 |

每个具体问题给时干一个明确主角色，不在伙计、货物、市场、事项之间随结论切换。必要辅助用神才加入，不为凑出完整故事遍取全盘。

## 最后细节取象

先完成主势判断，再按用户需要细化人物、活动、行业或器物。以实际对象为起点，在传统象义中寻找对应，不从希望推荐的对象倒定唯一归宫。

宫卦与星门干神可以共同限定“像什么”，但这不是一条新的五行因果链。具体行业属于现代类比，不能由对应相像推成上涨、获利或成功依据。

例如离的明、文象可与教学内容类比，天辅有设教用途；天辅转到震宫不使震永久变为教育。震还有雷、动等其他象。应保留多种合理对应，不固化成行业专属宫位。

天芮兼有尊师受业等事类用法，病神、病损也有出处。问何种行业与问吉凶是两回事；不能以教学、医疗的具体对应把不利性质改成利好。

只展开能回答本问的细节。未知现实行为用候选对应表达，事后已知事实不追记为事前预测。主势不支持所求行动时，不用末端取象逆改结论。
