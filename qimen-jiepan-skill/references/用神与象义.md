# 角色绑定与取用边界

具体取用按[事类方法](事类方法.md)，取象按[取象规范](取象规范.md)。本文件只维护角色规则，不再把各事类入口当成完整断法。

## 绑定顺序

1. 列出现实对象与所求结果，区分人、事物、关系和阶段。
2. 按题型选完整方法，先记录出处与适用范围，再查看角色落宫的吉凶。
3. 固定主用和必要辅用的符号、层次及实际位置。日干自问定位是本技能常用入口；年命依具体方法作身份或辅证，不设跨事类万能优先级。
4. 时干每个子问题只有一个主要角色。合伙方法的伙伴、现代行情方法的标的、失物方法的物品不能在一条推导中互换。
5. 甲按具体甲子、甲戌、甲申、甲午、甲辰、甲寅分别遁戊己庚辛壬癸。不同柱为甲分别解析，不共用本时旬首。
6. 已绑定后不因空墓、凶格或不合预期换到年命、地盘、合干、对宫。补充身份后可新增有记录的辅证；若发现原角色理解错误，说明更正原因并保留原记录，不以“固定取用”维护已知错误。

## 层次与识别

默认天盘定位并不授权地盘代表过去、基底或第二个本人。天地盘专法按原文的比较对象使用；格局始终读实际天X加地Y。

同宫角色共享一次结构核验，不造第二宫；同干人物承认当前符号不能完全区分，必要时补实际身份或采用有出处的另一完整方法。未知年命不补造，只有会实质改变身份识别时才追问。

主干、寄干都按实际字段读取；不得用寄干掩掉主干，也不得把主寄两条结构当独立现实对象。甲己合等讨论先解析具体甲柱，五合不自动合化。

## 常用入口的限度

| 事类 | 可定位的入口 | 不允许直接推出 |
|---|---|---|
| 合伙 | 日干本人、时干伙伴；财利另读贸易方法 | 双方相合便一定签约或盈利 |
| 贸易 | 戊资本、生门收益，主体按该方法 | 生门即上涨、流水等于净利 |
| 开店 | 开门对应经营或店铺作为明示转译，主体另定 | 能开张就等于有利润 |
| 工作职位 | 日干本人、开门工作为现代身份转译 | 开门固定代表领导、同事或两家单位 |
| 工作压力 | 本人及工作情境的有限解释，具体原因待核 | 宫数换天数、空墓必在某日解除 |
| 感情人际 | 双方身份或适用年命，六合仅必要辅助 | 同宫生合即关系成功 |
| 风评 | 被评价者，景门公开形象、惊门争议为现代类比 | 他人已实施造谣或背叛 |
| 访人借贷 | 有明确方位与主客身份时使用所选专法 | 没有方位却补造天地盘主客 |

入口不是方法全套。完整条件未收录的题型可以有限解释，明确未能判断的结果；不能为保证覆盖率而新造通用规则。

## 专项定位速查

以下补充六步流程第二步的定位入口。它们不是新增的自动判定规则卡；完整断法按对应正文核读。现代转录来源的核读范围见[来源登记](来源登记.md)中 SQ 系列。

| 事项 | 主对象及辅助入口 | 先分清什么 |
|---|---|---|
| 普通自问 | 日干定位本人，时干定位本问事体；专项符号另选 | 时干不在同一条推断中同时充当产品、市场、客户和结果 |
| 求财、贸易 | 甲子戊为资本，生门为财利；买货法可用时干为货物 | 财本、经营收益、产品价格及个人收益分别判断，金融用专用方法 |
| 工作与官职 | 日干或依方法采用的年命；开门文职工作及单位，杜门武职工作及单位；年干上级、值符顶头上司（SQ-WORK） | 杜门推广为所有技术岗属现代转译，不作原书通则；单位和某个人不混用 |
| 婚恋 | 采用乙庚法时，乙女方、庚男方；六合媒介；已婚配偶可另用合干，年命作辅助（SQ-MARRIAGE） | 关系状态、媒人和婚姻证件不是同一对象；与该角色模型不合的关系按实际身份另选取法 |
| 健康问事 | 先定被问者，再看天芮病象、天心和乙奇医药角色，伤死等为相关辅助（SQ-HEALTH） | 这些是传统角色，不能直接由星门标签推出医学诊断或现实伤病程度 |
| 失物 | 日干失主、时干物品，必要时加物品专项符号；玄武、天蓬为盗失相关线索（SQ-LOST） | 失窃、遗忘、放错位置分别核，不因玄武就确认某人偷窃 |
| 行人、寻人 | 问时盘按六亲关系取年、月、时干，兼看年命；按走失时刻起局的入口另核（SQ-TRAVEL） | 时干不是所有走失者的统一用神；起盘入口会影响人物定位 |
| 官司诉讼 | 采用该法时值符为原告、天乙为被告、开门为法官，其他材料另定（SQ-LAWSUIT） | 原被告不等于动静主客；此表不自动扩展到体育、商业竞争 |

方位法须有真实方位，年命法须有可核出生年，不能临场猜测。“多维”用于同一对象的互证或说明差异，不给同源符号重复加权；年命和方位都没有通用于全部事类的“第一用神”地位。
