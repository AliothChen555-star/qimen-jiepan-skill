# 固定盘与流日裁决

方法 ID：`FINANCE_FIXED_CHART_V1`，版本 0.8.0。F01—F10 为本次登记的现代金融规则；传统财利格义提供来源，流日到价格方向的连接属于本方法。配置见 [finance_profiles.json](../assets/finance_profiles.json)。

## 时间层

原盘宫位、星门神、天地干、旬空、月令和马星全部冻结。每个自然日生成新日环境；周末也推进干支，再与产品日历相交，休市行不产生价格预测。跨旬只变日环境旬空，跨节只变日环境月令。

场内产品以该市场当地开盘的绝对时刻，转换到原盘时区和原换日／太阳时设置，确定当日干支。原盘坐标不随标的上市地点变化。交易时段若跨越原盘换日点，记录精确分界；本版日级主判使用开盘锚点，分界供解读当日后段时使用，不把它另算第二个交易日。需要分时涨幅的产品须另建分时模型。

场外基金按管理人的净值归属日，在估值时区取当地正午为锚点，再转换原盘时钟；不是按净值公布日取日。实际底层采价窗口另列起止时间和来源，跨市场／QDII 保存各底层市场采价信息。发布时间早于窗口开始才属于完整前瞻；在窗口中为 partial，结束后为 retrospective，未核窗口为 timing_unverified。后两类照样可以解读，真实前瞻评估分别计数。

日甲逐柱取遁仪：甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸。查外八宫实际天盘，不复用原时旬首。日支取本宫：子1、丑寅8、卯3、辰巳4、午9、未申2、酉7、戌亥6。两支同宫不代表同支触发。

## 原盘基调 B

依次判断，只用主对象宫主天干加主地干；寄干保留辅助解释。

| 规则 | 条件 | 处理 |
|---|---|---|
| F01 | 辛加丁，主角色未悬置 | B=+1 |
| F02 | 辛加戊；或戊加辛且为非身份用途的死／惊／伤门，该门未迫、未因实际空墓悬置；主角色未悬置 | B=-1；吉门分支不套凶断 |
| F03 | 前两项未生效，门不作为主对象身份，且门未迫、未因实际空墓悬置 | 生开休 +1；死惊 -1；伤杜景 0 |
| F04 | 门本身就是行业主身份 | 不把该门固有吉凶重复用作 F02/F03 方向 |

角色有已完整核定、绑定的实际空墓悬置时，该角色方向暂取 0。未知补充条件不变成全盘否决；无财利干格时正常进入门势。`role_context` 只填写已核实际作用，不照抄工具所有结构匹配。

## 日作用 D 与启动力

F05 的 A 为流日日干原落宫或日支本宫，B 为主对象宫：A生B、比和为扶助 +1；A克B、B生A 为压制／耗泄 -1；B克A 记中性 0。两条同向或一条中性取该方向；相反取相持；全中性取 0。流干自身五行、与对象天干的关系及五合另存解释，不另拼成新的十干克应。

F06：日支与已绑定的原空支完全相同，解除这一空支的悬置。F08：日支冲已明确的实际墓支，解除这一墓条件。其他独立悬置仍保留；只有全部相关悬置已解除，才恢复角色原有作用。填空既能恢复支持也能恢复压制。F07 六冲、六合只记动荡、牵制、聚合等形态，本身不定涨跌。

重算当日有效基调 B日，然后裁决：

| B日 | D | 初档 |
|---|---|---|
| +1 / -1 | 同向 | +2 / -2 |
| +1 / -1 | 中性 | +1 / -1 |
| +1 / -1 | 反向或相持 | 0 |
| 0 | 单向 | +1 / -1 |
| 0 | 中性或相持 | 0 |

F09：戊、生门及事前登记的关键辅助角色，未悬置且到主对象的关系与初档相反，强档 ±2 降为 ±1。同宫同象不重复当反证，不把个人获利直接改成资产涨幅。额外关键角色通过 `key_relation_roles` 事前指定，关系仍按原宫计算。

F10：主对象宫，或同向支持／压制辅助宫，由原月旺相进入日环境非旺相，则强档降一级。此处比较的是宫五行节月强弱；九星仍按整盘固定的星旺衰表解释，不混用。原马、日马及原星门反伏另列形态，不单独翻方向。F09/F10 合并最多把强档降成普通档，不多次相加。
