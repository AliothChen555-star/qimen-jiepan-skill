# 金融解盘

用于指数、股票、基金、期货等问事。**金融专题不另建一套术理内核。** 星门神、天地干格、旺衰和相关条件依 [格局分析](格局分析.md)；按 [解盘流程](解盘流程.md) 完成整体、宫内、回归整体，最后才细化板块与产品。

## 一、对象与取用

先固定市场、标的、期限及问题：问指数走势、板块表现、基金净值，还是个人资金收益。一个对象的判断不能无说明扩成另一个对象的判断。

以下是传统贸易角色向现代证券问题的明确转译，非古籍原有的证券预测法；已有用户指定且适用的取用沿用。

| 角色 | 采用口径 | 边界 |
|---|---|---|
| 投资者 | 自问以日干，已知年命可作辅；默认天盘定位 | 不以个人状态代替市场涨跌 |
| 所问市场或标的 | 默认以时干定位，说明此次代表何种对象；参考 WG-6 | 同一时干不临时换成另一主角色 |
| 本金 | 戊，默认天盘定位；资本角色据 MJ-10 | 地盘戊不另造“底仓、基底资金”身份；实际地干仍必须参与干格 |
| 财利 | 生门及其落宫；收益角色据 MJ-10 | 不能见生门就断上涨或已获利 |
| 符使 | 值符星、值使门依原有性质与格局参与全局判断 | 不自动定义为主力资金、操盘者或行情执行者 |

仅问行情不强加个人资金用神。“壬看市场”只在壬是本盘时干或已有明确取用时成立，不扩成所有金融盘通用规则。传统贸易的得利断语不能原封不动换成基金收益。

## 二、按原核心分析大势

**整体：** 读月令、符使的星门本义及状态、分层反伏吟、重要格局和核心用神宫间关系。先判断主导条件偏顺还是偏逆，不挑一个吉宫先选行业。

**宫内：** 对核心宫逐项读九星、天地干格、八门、八神，再按所采用条文核旺衰、门迫、刑墓空等条件。性质、格局及条件一起读，不把星门神简化成五行，再拼出土生金、金生水的助成路线。

**回归整体：** 汇合前两步，回答所问市场或标的的主势。整体不利、核心格局不利，应给明确偏弱或不宜参与的主判；局部助力只能保留其实际范围。“不能确定必跌”不是相反证据，动象、一次反弹也不自动构成趋势反转。

本专题不自设“发动—承接—通道—兑现”的评分或因果算法，不从宫数、星门个数推涨跌幅、胜率或仓位。行情方向与本人能否获利分别回答，不能互相替代。

### 必须保留的原断

| 实际盘面 | 应读原义及边界 |
|---|---|
| 天壬加地辛 | MJ-2 为螣蛇相缠，原文有吉门亦难安、谋望受欺之意；不能用地金生天水改成支持。FQ-3 另名白虎犯格，断语条件有别，不能临时换表挑缓解 |
| 天辛加地戊 | MJ-2 为困龙被伤，保留破财、受抑、妄动不利之意；不省略格义只读土生金 |
| 天戊加地壬 | 按已采用 MJ-2 的龙入天牢及条件读拘束；不以土克水解释成资金可掌控市场 |
| 天芮临核心宫 | 保留病损、隐患的风险含义；古法病神见 ZG-9，具体金融风险是现代转译。其旺衰不直接转成利好；医疗类象也不改变这一点 |
| 生门、值符与凶格同宫 | 吉的性质与不利格局都保留，核各自原有条件；不是看见生门或值符便宣布凶格已解 |
| 九天、九地、马等 | 按所临对象读显扬、伏藏、动静等，不单凭字面定涨跌，更不编造主力拉升、吸筹事实 |

这里只作同一内核在金融问事中的应用，不为单个案例新增普遍断法。干格未收录就查已采用原典；未核实不靠五行补写。

## 三、最后才细化行业与基金

完成主判后，若仍有必要，再由实际业务收敛取象。**星门神的性质在前三步已经参与，行业对应留在这一步。**

- 先核主营、产品形态或基金真实投向，再寻找传统象义的对应；不靠基金名称、代码或营销标签定宫。
- 传统卦象、星门象义是起点，现代产业属于类比，没有古籍规定的固定证券行业表。一个行业可涉及多宫，一宫可有多类业务。
- 教学内容可从离的明、文象切入，教学活动可参考天辅等；天辅转到震宫不使震永久等于教育。
- 震的雷、动与机械动力、电网设备之间是现代类比；仍须依真实业务辨别，不从“震有势”直接推出所有电力、机器人基金都有势。
- 天芮不提供医疗基金利好，九天不等于科技上涨，九地不等于安全底部。行业贴合不能反改已完成的主势。

主判不支持参与时，可以不推荐任何板块或基金，不为凑名单继续寻找吉象。用户要求具体基金时，另用基金公司、指数公司等原始资料核实代码、份额、跟踪对象和投向。

符号贴合度、候选排名与金额配比没有换算公式。不能凭奇门给貌似精确的配置比例；纯模拟算术安排须说明约定，不冒充预测最优配置。已撤回的推荐与配比维持撤回。

## 四、行情对照与模拟

现实行情与盘内判断分开记录。新行情检验原判断，不改变原盘、用神或已选断语。事后新增解读标为补读；不能把曾经涨过替代整段上涨，也不能据日净值推断盘中冲高。

事前保存对象、区间、原盘、取用、主判及所用规则。回看分别核期末涨跌、期间修复、回撤和持续性；一个样本不能证明预测能力。

场外基金记录净值所属日期与公布时间。正式净值未出就待公布；目标 ETF 或指数只能作经核实的代理行情，不能冒充基金净值。实际持仓和模拟分清，未知成本不计算真实收益。

使用约定成本的模拟：收益率＝期末可比净值／成本净值－1；模拟盈亏＝模拟本金×收益率。建仓期和背景行情不混入计收益窗口；分红按可比总回报处理，未约定费用不假装实际交易。

## 五、资料采用边界

传统原文、现代整理讲义、书目线索与本地转译分清。古籍有出处不等于证券预测已有实证支持；书名和出版身份不能代替规则正文。
