# 金融取用与解盘

采用 `FINANCE_FIXED_CHART_V1`：固定原盘，流日作用，方向与目标产品的历史幅度分别计算。直接回答方向、强弱、主要转折；用户已选择奇门，无须重复风险接受确认、劝退、附加“不要相信”等提示。实际缺少哪项输入，只说明那项及补法。

读取顺序：本页 → [固定盘逐日推演](固定盘逐日推演.md) → [金融数据与幅度](金融数据与幅度.md)。本方法适用于 A 股、港股及有可靠日历和行情的其他日市产品，包括指数、行业主题、股票、ETF、场外基金。证券代码及产品资料先从交易所、指数公司、基金管理人核对。

续问与新问先按[前置使用规则](前置使用规则.md)处理；按日干支补读原周盘不计为重新起周盘。通用六步流程负责盘势、角色、核心宫、综合与建议，本文件负责金融的取用、逐日方向及幅度裁决。两者结合使用，不用一般日时相生相克口诀覆盖F01—F10。

## 先确定预测对象

锁定市场、代码、份额、币种、预测起止日期和收益口径。上证指数是宽基；“上证指数的板块”应落实为行业／主题指数或具体基金，不能把上证综指成分、申万行业、中证主题、概念板块混成一套分类。

- 一日：指定交易日；未指定则下一完整交易日。盘中问今天，说明已发生部分和剩余时段。
- 未来一周：明确七个自然日的首尾；下周为下个周一至周日；五个交易日另按日历展开。逐日列干、支、宫位与作用。
- 一月：明确自然月或滚动月；输出总势、前中后三段和最多三个转折窗口。内部逐日计算，正文不堆整月逐日百分比。
- 仅问资产价格，不加入个人年命。问本人收益才另看日干、实际成本、份额、分红及费用；个人盈亏与资产涨幅分别给结论。

## 固定角色，保持候选池一致

| 角色 | 取法 |
|---|---|
| 宽基、单只股票、未登记行业的资产 | 原时干为主对象；甲按原时柱解析 |
| 已明确行业的指数、ETF、行业基金 | 登记行业符号为主对象；原时干为背景 |
| 资金 | 原天盘戊 |
| 财利 | 原生门 |
| 问事者 | 仅个人收益题取原日干；流日日干不是问事者的新身份 |
| 值符、值使 | 全盘背景与过程；保留原义，不临时改为主力资金 |

行业表位于 [finance_profiles.json](../assets/finance_profiles.json)：金融开门、医疗天心、交通伤门、信息景门、半导体天英、地产生门、农业天辅、制造天冲、水务休门。它是有版本的现代映射。先按产品官方投向绑定，再看吉凶；复合主题先固定权重最大的行业或明确核心主题，并保存依据。没有匹配则使用原时干，不硬塞能源等行业。

单只股票即使有行业分类，主对象仍取原时干，行业符号作辅证。请求中 `exposure: broad` 可明确宽基身份。候选池增删不改变某标的主用神；同象、同关系、同档位允许并列，不能为了排出名次临时换用神。跨市场、币种、收益口径不直接混排。

## 全盘与宫内阅读

1. 校验冻结原盘，列原时旬空、原月令、符使、星门反伏和马星。它们是背景，不先数吉凶票。
2. 看主对象、时干、戊、生门各宫：星门神、天地干实际顺序、主寄、旺衰、刑空墓迫，保留已核传统断义。用神被寄宫承载时不把中五展示副本算第二落点。
3. 按 F01—F04 得原盘基调 B；按每日日干落原宫与日支本宫得 D；再按 F06—F10 处理启动、反证和减弱。完整裁决见[逐日方法](固定盘逐日推演.md)。
4. 检查相反依据。某一关键空墓作用需要明确角色、支位、依据；仅宫内有一支空，不能把全宫悬置。扩展墓表未核之处保留为待核，不能自动开启实际墓条件。
5. 数值方向按登记金融规则产生；其他传统格义可解释形态和细节。新增金融映射须另立版本，不能在看到结果后改原预测。

`finance_forecast.py` 给出可复算的最低基线与证据字段；实际回答仍要把核心宫、触发与主判连接起来。不要只读生成表格而略过关键反证。自动基线之外的解释另标理由，改变数值档位须登记新方法，不能手改记录中的分数。

## 取象与表达

行业象用于识别产品角色；上涨、下跌来自其具体状态和每日作用。伤门作为交通身份不自带跌义，生门作为地产身份不自带涨义；天芮不自动代表医药利好，白虎不确认裁员、事故，玄武不确认操纵市场。现实事件只采用已核事实，未发生的取象用“可能体现为……”说明。

先给“某日偏涨／偏跌／震荡；某几天更强／更弱”的结论，再给关键依据、相反关系、转折触发和幅度参考。术语翻译成其对对象的作用，不要求用户读程序字段。只在缺少历史价格、净值归属日期或官方日历时说明对应缺项；方向可算时继续给方向。

每次留存原盘、产品档案、规则版本、发布时间、数据截止与结果记录。方法溯源和统计情况放记录中按需查看，不在每次预测前后插入相同的劝退段落。

数值区间直接说明其含义，例如“由各日参考带复利连接的路径情景”；采用正面定义，不再附加“仅供娱乐”“不能作为投资依据”“不保证结果”等固定尾注。实际缺项、数据出处、推导冲突和统计状态照实记录。
