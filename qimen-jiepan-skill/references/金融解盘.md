# 证券与金融的现代应用边界

金融问题分三种任务：传统符号解释、现实行情核验、明确标记的实验性预测。古代贸易有出处，不等于证券涨跌模型已被验证。不得把传统不利自动改写成下跌、卖出或不宜参与，也不能见吉格就说上涨。

## 对象与方法

先固定市场、标的、个人资金还是经营财利，以及期限、价格或净收益口径。仅问市场不强加个人本金；价格上涨不等于本人净收益，风险是否可接受又是另一问题。

| 角色 | 默认入口及性质 |
|---|---|
| 投资者 | 自问日干，适用年命作明确辅证 |
| 市场或标的 | 预先选定时干为明示现代约定，每个子问题只代表一个主要对象 |
| 本金 | 戊，来自贸易资本角色的现代移用 |
| 收益 | 生门，来自贸易财利角色的现代移用 |
| 符使 | 依原义参与背景，不自动等于主力资金或操盘者 |

这些入口是应用约定，不是古籍直接规定现代基金、指数或股票的结果法。现代讲义和仅查到书目的资料核读范围见[来源登记](来源登记.md)，不能从书名补造未读正文。

## 按核心流程解释

按[解盘流程](解盘流程.md)固定角色、核盘、查完整条件、保留原有星门神与干格性质，再说明对所选对象的有限解释。不能用地生天抹掉壬辛等不利原断，也不能脱离条件把任何凶格当整段行情的否决。

传统“不利”可以按来源表述为该占法中的不利线索；要输出实际方向，必须另有明示的现代映射、结果定义和评价记录。未知不等于必跌或必涨。行业类比留到最后，天芮不等于医疗利好、九天不等于科技上涨、九地不等于安全底部。

## 实验性预测

用户明确希望作预测实验时，事前固定标的、起止时点、收益定义、方向标签、基线、费用与失败标准，保存原盘、取用和主判断。将结果标为未经效验验证的实验性推断，不编命中率、收益率、仓位或金额配比。

判断价格、个人净收益和行为适宜性分别记录。不同规则缺少可说明的合并依据时，不靠投票或虚构权重产生唯一方向。原版与改版、不同参数及多次运行分批，不能事后挑最好结果。

## 现实资料核验

具体产品和行情必须查基金公司、交易所、指数公司等直接资料，核代码、份额、跟踪对象及投向。净值所属日期和公布时间分开；ETF或指数代理不能冒充基金净值。未知成本不算真实收益。

约定模拟的收益率是期末可比净值／成本净值－1；分红用可比总回报，费用按约定列明。现实行情只检验原判断，不改盘或重新挑取用。事后补读另存，不把区间曾上涨替代期末上涨，也不据日净值编盘中路径。

真实预测效力须连续事前登记后检验。程序回归、文献核读、行为评估和真实结局分开，见[评估方法](评估方法.md)。
