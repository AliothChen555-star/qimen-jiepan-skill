# 首批事类方法与组合题边界

## FINANCE_FIXED_CHART_V1：金融日周月

金融预测进入[金融解盘](金融解盘.md)。宽基、股票默认原时干；登记行业指数及基金用行业主对象，戊和生门分别核资金财利。原盘固定，逐日干支对照，F01—F10 裁决方向，产品历史波动换算幅度。专用 `finance_forecast.py` 与 `finance_record.py` 保存和复算金融记录，普通记录接口继续用于下面的一般事类。

本版先支持有明确原文的合伙求财、贸易、开店三个文本方法，另提供有限往访关系法及现代工作压力入口。共同依据是 [《奇门旨归》卷八](https://www.shidianguji.com/zh/book/CADAL02031557/chapter/1l6y1gptn8mqj)；完整机器索引在 [rules.json](../assets/rules.json) 的 methods。前三项按传统文本登记；金融另用下列有版本的现代方法。

## 先分结果，再绑定角色

同一提问含“合伙开店、一个月签协议、半年盈利”，至少拆为合作助益、协议签署、开店经营、半年净收益四项。合伙关系顺利不等于合同已签，开店条件有利不等于净利润正；主判不能把这些阶段串作必然因果。

每个分项固定一套方法、一个时干主角色及适用来源。不同专法可在分项中采用不同角色，但不得混在同一条推导里。年命未知时采用下列方法本身所给角色，不编造年命，也不为避免不利而改年命或主客。甲柱按该具体甲柱解六仪。

《旨归》含飞布体系，本技能按已声明兼容选择借用以下分类角色及条文，不据此改变内置排盘；不声称复现该书全套占法。用户明确要求原书飞布全法时，当前转盘输出不能冒充。

## ZG8_PARTNERSHIP：合伙求财

**角色。** 天盘日干落宫为我，天盘时干落宫为伙伴；生门另看利益是否益我。甲按日、时各自具体柱解析。已知年命可作另行明示辅助，不能压过本法角色。

**顺序。** 先核两人实际落宫、星门干神与所涉奇门吉格的完整条件，再比较时宫到日宫、日宫到时宫。最后独立核生门与我，不把利益关系省略。

| 条文条件 | 本法允许的结论 | 必须保留的限制 |
|---|---|---|
| 时干乘奇门吉格，且时宫生日宫 | 伙伴对我有益 | 不能只见宫生就宣告完整条件已齐 |
| 日干乘奇门吉格，且日宫生时宫 | 我对伙伴有益 | 不是“我吃亏”的自动同义词 |
| 二宫比和 | 原法取公平、少猜忌 | 同干同宫时承认分辨有限，不虚构另一宫 |
| 时宫凶神凶格并克日宫 | 对我不利 | 凶与克是本条组合条件，不拆成无条件否决 |
| 生门生我/不生我 | 对利益助益另核 | 不把合伙公平替代盈利判断 |

**反证。** 若伙伴关系有益而资本或收益受阻，分项分别成立。不能用无关凶宫把正证删去，也不能因有益便掩盖已核凶格。没有原文支持的凶票计数、权重、主客解救不加入。

**时间。** 本条没有现代合同签署日或固定一个月公式。可在明确“此盘对本次拟议合作”的范围下解释助益；若只能读一般关系，首句就应说“一个月能否签署尚未判定”，不能首句断签不成、末尾再说期限未定。

**三例。** 条件齐全且时宫生我：支持伙伴益我；只有生我但吉格限制未知：助益方向可见、完整有利条件未知；时宫有凶格却不克我：不冒称命中本条“凶且克”的完整不利条件，但凶格原义仍保留。

## ZG8_TRADE：贸易资本与收益

**角色。** 天盘戊为资本，生门为利息或经营收益。这里甲子戊是特定资本符号，不把它替换成当前旬首，也不将戊资本作为所有甲的通用解法。先定义用户所说收益是收入、毛利、净利还是回本，不能互换。

| 条文条件 | 原法含义 | 处理 |
|---|---|---|
| 生门宫得奇门吉格且生戊宫 | 获利 | “倍利”不换算为现实倍数或收益率 |
| 二宫比和 | 中利 | 不伪造利润金额 |
| 生门宫克戊宫，再乘凶神凶格 | 折本 | 不只看相克就省去凶神凶格 |
| 戊宫生生门宫 | 添加资本仍得利息 | 保留为正面分项，不能以任意全盘凶票抹去 |
| 生门墓绝，再有凶神凶格 | 耗本 | 墓与绝分开核；程序未实现绝不能宣称已算 |

条文中更早的“生门宫为体、门星为用”属于求财谋望的另一段；不能悄悄与贸易资本利润法交叉串成新算法。内外远近速迟也有阳遁、奇门等条件，不把“一内一外必迟”直接改成几个月。

本条没有固定半年收益计算。一般获利象与指定半年净利是不同结论；没有期限支持时分开报告。证券价格涨跌不由本条资本收益宫关系直接推出。

**三例。** 生门吉格条件齐且生戊：文本支持获利；戊生生门：支持需追加资本仍可能得利的原义，不能误读为无利；生门墓结构存在但墓对象或“绝”未核：不能宣告“墓绝且凶”分支全成立。

## ZG8_SHOP：开店肆

**角色。** 开门主店铺经营，天盘日干主我。开门五行为金，墓位按门星五行墓金丑艮八；不能套天干阴阳墓表。

依次核开门旺相、奇门吉格完整适用、开门宫对日干宫的指定关系，再核开门的墓、返吟、空亡及凶格。开门旺相且带奇门吉格并生我为原法有利；比和且不克制为次吉。本版保留同段前置的旺相与奇门吉格检查，比和次吉也不免检，不把单一吉格名称当作完整适用。开门入墓、返吟或空亡为原文不利；开门宫凶神凶格再冲克日宫为更不利。

“返吟”须先说明本条应用的是相关门返吟还是工具整盘状态，不能任意把其他层反吟代替。空亡是支位或整宫口径先固定，边界不明则该条件未知。店面、租赁、开业、经营与净利分别判断，不以书店符合天辅文教象增加盈利证据。

**三例。** 旺相吉格并生我：支持经营条件有利；仅开门名称为吉但受迫：完整有利条件未齐；天辅文教贴合书店且开门受损：行业类象不能解除经营不利。

## 组合题的综合

每个分项都列正证、反证和未知，先核对象同一、阶段同一、条件齐备，再决定能否合并。没有覆盖某个分项的完整方法时，直接写这个分项未判，不能让其他三个方法代判。

一个月协议与半年收益都未判时，仍可明确说明合作助益、投入关系和经营条件的传统解释；不能因没有日期抹掉已有原义，也不能为了回答“能否”而虚构期限法。任何新应期法都须先登记事类、对象、触发、时间单位与阶段。

## MJ7_VISIT：有限往访关系法

据 [《秘笈大全·奇门主客占验论》](https://www.shidianguji.com/zh/book/SDZJ0630/chapter/1lx9g1z6nblei)：我往访则我客彼主，天盘星为我、同位本位地盘星为彼；彼来访则天盘星为彼、地盘星为我。必须明确来去与方向，天盘星是来去方所落星，地盘星是该宫本位星，不另转地盘。

只比较这两个真实对象的五行：彼生我益我、我生彼益彼、彼克我损我、我克彼损彼、比和无损益。这不授权全宫任意星门干串生克。原条另列阳日阴日法未在本入口叠用。此入口只支持益损关系，不冒称已有完整能否见到、寻人或应期法。

## MODERN_WORKLOAD：工作压力的有限入口

工作压力、项目挤压、主管催促是现代问题，本轮没有核到能直接给出持续天数的完整事类古法。可明示以日干表本人、时干固定表一项明确工作事项，核相关宫的传统受限、重复、急迫等性质；不能由此声称已确定现实压力成因，也不能把“工作”随意改为官鬼、开门、值符轮流择用。

用户问多久，应先辨目标是忙碌减轻、项目交付、加班结束还是主观压力缓解；只有适用的完整应期方法才能据此选具体窗口。**宫数不直接换天数，冲墓、填空、驿马不自动等于压力结束；病占、行人应期不能移植。** 当前入口允许明确未判持续时长，同时给出有限传统解释及需核实的现实节点。不得把该入口未知误写成已经核实的古法，也不得由压力类象作疾病诊断。
